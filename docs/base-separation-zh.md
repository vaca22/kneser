## 1. 问题

[paulsen-continuation-zh.md](paulsen-continuation-zh.md) §5：`D(b) := K(b) − R(b)`（固定 z）
在上半 Shell–Thron 区内非零，趋向实轴时塌缩。两种可能，且必居其一：

1. `D` 在 (1, η) 上为零 ⟹ Schwarz 反射给 `D ≡ 0` ⟹ 与区内非零矛盾
   ⟹ **K 作为基底的函数不解析，(1, η) 是自然边界**；
2. `D` 在 (1, η) 上**非零但指数小** ⟹ 没有矛盾，K 解析，只是
   **Kneser 沿基底的延拓在 (1, η) 上不等于正则解**。

$$\Lambda(b) = \exp\!\big(4\pi^{2}/\log\lambda_{\rm up}(b)\big)$$

## 2. Λ 不是拟合常数，是被结构强迫的

这一点此前没有写下来，而它决定了整件事该怎么问。

`1 < a < η` 时主不动点吸引，乘子 `λ ∈ (0,1)` 实。Koenigs 坐标 `κ` 满足 `κ(aᶻ) = λκ(z)`，
Abel 坐标 `α = log κ / log λ`。**同一映射的两个 Abel 函数之差是 1-周期函数** `P(α)`。
把 `P` 的第一 Fourier 模写回 `κ` 坐标：

$$e^{2\pi i\alpha}=\kappa^{2\pi i/\log\lambda},\qquad
\big|\kappa^{2\pi i/\log\lambda}\big|=\exp\!\Big(-\frac{2\pi}{\log\lambda}\arg\kappa\Big)$$

`log λ` 是实的，所以指数纯虚，模完全由 `arg κ` 决定；绕不动点一周 `arg κ` 变 `2π`，
给出因子 `exp(4π²/log λ) = Λ`。

**结论：任何非零的周期差，其第一 Fourier 模的大小必然正好是 Λ。不可能是别的量级。**
这和抛物点处 Écalle–Voronin 不变量 / horn map 的指数小分裂是同一个机制。

于是正确的提问不是"D 怎么衰减"，而是：

$$E(b) := D(b)/\Lambda(b)\ \text{是否收敛到 } (1,\eta) \text{ 上一个非零解析函数。}$$

"D 在 (1,η) 上恒零"就是"E → 0"。

## 3. 仪器：一个把所有构建都锁在 12 位的 bug

第一轮跨精度审计（三条竖线 × digits {12,14,16} × idelta {0.10,0.15}，122 点）撞上了一堵墙：
**请求更多位数反而让残差变大**。`1.05+0.08i` 处 12/14/16 位的残差是
`1.08e-11 / 2.74e-9 / 1.74e-7`，到 14 位残差已经超过被测量本身。

诊断分三步：

1. **残差轨迹**：三个位数下前 15 轮**逐点相同**（loop 0 都是 0.0084，loop 5 都是 0.00025），
   之后各自撞上一个**硬地板**。所以迭代没问题，是每轮注入了一个固定大小的误差。
2. **Taylor 系数衰减**：`|c_k|` 按 `2^{-k}` 干净下降，然后压平在
   `1.3e-12 / 3.3e-10 / 2.0e-8`——噪声进在**圆周取值**里。
3. **地板的标度**：地板之比 254 与 61，而 `depth_d` 是 36/40/43，
   `|λ_dn|^4 = 253.4`、`|λ_dn|^3 = 63.5`。**吻合到 1%。**
   即注入误差 `ε₀ ≈ 3e-34` 被 `|λ_dn|^{depth_d}` 放大，且**与工作精度无关**。

**原因**：`build_complex` 调用 `choose_fixed_points(name, k_up=..., k_dn=...)` 时
**没传 dps**，而该函数的默认值是 `dps=30`——不动点的精度被写死在 30 位，
不管请求多少位。排斥侧的超函数是 `E^{depth}(L + λ^{z-depth})`，
`depth ∝ digits`，于是 `L` 的误差被 `|λ|^{depth}` 放大，
**请求的位数越多，放大得越狠**。

修复是一行（`src/kneser/_cbuild.py`）：

```python
dps = 2 * digits + 20
ku, Lu, lamu, kd, Ld, lamd = choose_fixed_points(name, k_up=k_up, k_dn=k_dn, dps=dps + 20)
```

A/B（`1.05+0.08i`，8 位构建的系数作种子）：

| digits | 旧（dps=30） | 新 | |
|---|---|---|---|
| 8 | 9.72e-10，27 轮，24s | 9.72e-10，27 轮，23s | 低位数**不变** |
| 12 | 1.08e-11，**120 轮吃满上限**，144s | **5.67e-14**，14 轮，17s | 快 8.5×，好 190× |
| 16 | **崩溃**：`theta iteration diverging` | **7.24e-18**，27 轮，46s | — |

⚠ `kneser/build.py`（实基底主路径）**没有这个 bug**：它在 `with mp.workdps(p.dps)` 里算不动点。
本 bug 只影响 `_cbuild.py`，即复基底与区内延拓。
回归测试 `tests/test_base_plane.py::test_cbuild_residual_improves_with_digits`；全套 118 项通过。

⚠ 另有一个**独立的、修复前就存在的**问题：`1.3+0.5i` 从正则解的系数作种子时，
digits ≥ 12 会 `theta iteration diverging`（新旧代码表现完全一致，不是本次引入）。
阶梯式续种（前一个点作种子）不受影响。未追查。

### 4.3 `D` 有确定的非零极限

`Re b = 1.10`，digits=20，`y` 推到 0.0005：

| y | Re D | Im D | `\|D\|` | arg Λ | arg E | `\|E\|` |
|---|---|---|---|---|---|---|
| 0.0040 | −9.762e-11 | −3.0908e-10 | 3.2413e-10 | −0.33432 | −1.54240 | 1.40893e-02 |
| 0.0020 | −5.252e-11 | −3.1971e-10 | 3.2399e-10 | −0.16718 | −1.56644 | 1.40855e-02 |
| 0.0010 | −2.953e-11 | −3.2265e-10 | 3.2400e-10 | −0.08359 | −1.57847 | 1.40863e-02 |
| 0.0005 | −1.797e-11 | −3.2352e-10 | 3.2402e-10 | −0.04180 | −1.58449 | 1.40873e-02 |

- **`|D|` 收敛到 5 位有效数字**：3.2402e-10。
- `Re D` 线性趋于一个**很小但非零**的值：拟合 `Re D(y) = −6.5e-12 − 2.3e-8·y`

- `arg Λ = −83.6·y` **精确线性趋于 0**，所以 `arg D → arg E`；

⚠ **一个被证伪的猜想**：`arg D(0)` 看着像 `−π/2 = −1.5708`，那会给出漂亮的
"`R` 恰是两侧 Kneser 极限的平均"。**不是**：外推值 −1.5905 与 −π/2 差 0.020，
而 `Re D(0) ≈ −6.5e-12` 明确非零（约为 `|D|` 的 2%）。别再引用这个猜想。

### 4.4 结论

`D` 在 `(1, η)` 上**有极限且极限非零**。二选一里成立的是第 2 支：

> **`K(b)` 在基底方向解析，`(1, η)` 不是自然边界；
> 但 Kneser 延拓在 `(1, η)` 上的边界值 _不是_ 正则解，
> 两者差 `Λ(b)·E(b)`，`E` 非零。**

三个极限值（`z = 1/2`），外加一个来自文献的独立点：

| Re b | `\|E\|` 极限 | `\|D\|` 极限 | 来源 |
|---|---|---|---|
| 1.05 | ≈ 6.02e-03 | ≈ 1.009e-08 | 本文，θ-映射＋Cauchy，20 位 |
| 1.10 | ≈ 1.4086e-02 | ≈ 3.2402e-10 | 同上 |
| 1.15 | ≈ 2.280e-02 | ≈ 7.08e-12 | 同上 |
| **√2 = 1.41421** | **≈ 7.155e-02** | **≈ 1.18900e-48** | **Paulsen 2019 §5**，double-dagger track，120 位 |

前三点上 `|E|` 随 `Re b` 光滑递增（逐差 8.07e-3、8.71e-3，二阶差 6.4e-4），像一条解析非零曲线。

**第四点是独立验证，不是本文测的。** Paulsen 2019 §5 为了说明 `κ_{√2⁺}` 终究不是实函数，
把 `n` 提到 120 后给出

```
Im κ_{√2+}(1/2) ≈ −1.18899697185401045226976795872715599664e-48
```

（他与 `ψ₁⁻¹(1/2+k)` 的实部吻合到 49 位，所以 `|D| ≈ |Im D|`；这与本文 §4.3
测到的"`D` 近乎纯虚、`Re D` 小两个数量级"一致。）`b=√2` 时 `L=2`，
乘子 `λ = L·ln b = ln 2 = 0.6931472`，于是

```
Λ = exp(4π²/log λ) = exp(−107.71358) = 1.6618e-47
|E| = 1.18900e-48 / 1.6618e-47 = 0.07155
```

把前三点线性外推到 `Re b = 1.4142`（逐差 ~8.7e-3 / 0.05，5.28 步）得 ≈ 0.069，**与 0.0715 差 4%**。

这是一次跨方法、跨作者、跨七年的独立检验：他用围道积分 + 120 位，本文用 θ-映射＋Cauchy + 20 位，
测的是同一个 `z = 1/2`，落在同一条 `|E|` 曲线上。它同时消掉了 §4.5 第 3 条的顾虑。

### 5.1 Paulsen 2019 §5 的 Proposition 4（决定性的一条）

全文本地快照：`docs/_generated/literature/Paulsen-2019-Tetration-for-complex-bases.pdf`
（作者上传到 ResearchGate 的预印本，22 页；出版版 Adv. Comput. Math. 45 (2019) 243–267，
DOI 10.1007/s10444-018-9615-7，Springer 付费墙，无任何 OA 副本——
Unpaywall / OpenAlex / Semantic Scholar 三家均判 `closed`、无仓储副本）。
⚠ `docs/_generated/` 在 `.gitignore` 内，这份 PDF **不入版本库**（版权）；
本文引用它时一律给出节号和逐字引文，以便无此文件时也能核对。

第 5 节 **Within the Shell-Thron region**，Proposition 4 逐字（记号对照：
`κ_b` = 本文的 `K`，`f_b(z) = ψ₁⁻¹(z+k_b)` = 本文的 `R`，`s₁` = 本文的 `λ_up`）：

> For real `1 < b < e^{1/e}`, let `σ₁(z)` be the Schröder function for the attractive fixed point `L₁`,
> and `ψ₁(z) = ln(σ₁(z))/ln(s₁)`. Let `k_b = ψ₁(1)`, so that `f_b(z) = ψ₁⁻¹(z + k_b)` will be real
> whenever `z` is real ... Then `lim_{ε→0⁺} κ_{b+εi}(z)` **does not converge to** `f_b(z)`
> for all `1 < b < e^{1/e}`.

**证明是解析反证，不是数值**：若在某开子区间上二者相等，则 `f_b` 作为 `b` 的全纯函数必须
延拓过 Shell–Thron 边界；但它的 Taylor 级数在边界上发散，且即使能延拓，在 `b = e` 处它
只用了一个复不动点故不是实函数——而 `κ_b` 跨边界全纯且 `κ_e` 在实轴上实。矛盾。

⚠ 注意这条命题的量词：它排除的是"在某个**开区间**上恒等"。它**没有**对每个单独的 `b`
给出 `D(b) ≠ 0`，也没有给任何下界。本文 §4.3/§4.4 的逐点测量在这个意义上是补充，不是重复。

他给的数值就是 `√2`（已并入 §4.4 的表）：与 `ψ₁⁻¹(1/2+k)` 吻合到 **49 位**，
`n` 提到 120 后虚部现身 `−1.189e-48`。原文的评语是引 Sherlock Holmes
——"when you have eliminated the impossible..."——即：先由 Prop. 4 知**必然**不等，
再回去把那个差找出来。**他没有问它为什么正好是这个量级。**

### 5.1.1 同节另外两条本仓库没有的事实

1. **b-平面上从 `b = e^{1/e}` 起有一道"轻微割线"**：对 `1 < b < e^{1/e}`，
   `lim_{ε→0⁺} κ_{b+εi}` 与 `lim_{ε→0⁺} κ_{b−εi}` 不同，且互为共轭
   （`κ_{√2−} = conj(κ_{√2+})`）。所以 `√2` 由此多出两个 tetration，
   在 Kouznetsov–Trappmann 的四个正则超指数之外。
2. **区内有无穷多条"自发割线"**：`κ_i` 在 `z ≈ −3.8101919687 + 0.1456703034i`
   和 `−6.5906468833 + 0.2732864288i` 处为零，故在 `z ≈ −4.810…`、`−7.591…` 处必有割线；
   因为上半平面的拟周期 `2πi/ln(s₁)` 虚部为负，这串割线向左上无限延伸。
   区外也有，但要穿过 `z = −2` 的割线到另一叶才看得见。
   ⚠ 这一条对本仓库的 `_cbuild` 有直接后果：区内构建的收敛域不是想当然的。

### 5.2 Paulsen 2019 里**没有**的

- 全文检索 `4π²` / `exp(4\pi` / "exponentially small" / Écalle / Voronin / horn map：**零命中**。
- 唯一提到 `2πi/ln(s₁)` 的地方（§4 初值、§5 自发割线）用的是**拟周期**本身，
  不是"周期函数差的第一 Fourier 模模长"这条推理。
- `1.189e-48` 被当作一个具体数字陈述，没有与任何尺度比较，也没有第二个基底的同类数据。

所以 §2 的 Λ 机制、§2.1 的回归、§4.4 的 `E` 曲线，相对这篇仍然是新的。
⚠ 但"相对这篇是新的"不等于"文献中首创"——我没有检索指数小分裂/horn map
那一支文献里是否有人对 Abel 函数差做过同样的观察。这仍是一个未关闭的归属风险。

### 5.3 其余检索结果（上午那轮，结论不变）

**Paulsen & Cowgill（2017）** —— 全文已取得
（作者本人挂在 `myweb.astate.edu/wpaulsen/tetration2.pdf` 的预印本，原站已下线，
经 Internet Archive 快照 `20250802055918` 取回）。两条关键事实：

1. 该文**只处理 `b > e^{1/e}`**，并在第 1 节明确把区内切掉：
   > "It should be noted that if `e^{−e} ≤ b ≤ e^{1/e}`, then there is a real fixed point of `b^x`,
   > and therefore **a unique real analytic solution** can be found to the tetration problem
   > using standard power series techniques. ... Hence, this paper will only be concerned with
   > the case `b > e^{1/e}`."

   即：区内用正则迭代，**是另一条构造**，该文不考虑 Kneser 延拓到那里会落在哪。
2. 它所依据的唯一性判据是 Trappmann–Kouznetsov，
   _Uniqueness of holomorphic Abel functions **at a complex fixed point pair**_,
   Aequationes Math. **81** (2011) 65–76。

**第 2 条是对 §5.4 那条结构性观察的文献确认**：判据的名字里就写着"复不动点**对**"。
在 `(1, η)` 上起支配作用的不动点是**实**的，判据的前提根本不成立。
所以"Kneser 的两端极限刻画在实段退化"不是我的推测，而是判据适用范围的边界。
⚠ Paulsen 2019 Prop. 4 的反证走的是另一条路（`f_b` 在 b-方向不能跨边界延拓），
与这条退化观察互相独立，但指向同一个结论。

**其余检索（结论不变）**：

- Kouznetsov–Trappmann 的 base `√2` 论文（Math. Comp. 79 (2010) 1727–1756）
  处理的正是 `(1, η)` 内的基底，但走的是正则迭代的四个分支，
  **不涉及**沿基底延拓过来的 Kneser 解。（AMS 页面 JS 渲染，未取得全文。）
  Paulsen 2019 §5 明确指出 `κ_{√2±}` 是在这四个之外**另外两个** tetration。
- 2026 年 Janis Justus 的两篇 Zenodo 预印本用 "Paulsen–Cowgill/Kneser branches"，
  但自述**只限 `b > e^{1/e}`**。
- Paulsen 有后续作 _Analyzing the function `z↑↑a` for fractional `a`_,
  Adv. Comput. Math. 52:2 (2026-04)。**未查**，可能与本仓库的 half_exp 直接相关。

### 5.4 一条结构性观察（推理，非定理）

区内复基底 `arg λ_up > 0`：正则超函数 `R` 满足 `R → L_up`（`Im z → +∞`），
因为 `Re(z log λ) = x·ln|λ| − y·arg λ → −∞`。
但在实段上 `arg λ_up = 0`，这一项与 `y` 无关，`R` 沿虚方向**恰好周期**
（周期 `2πi/log λ` 纯虚），**不趋于任何极限**。

即：Kneser 的"两端极限"刻画在 Shell–Thron 区内处处非退化，
**唯独在实段 (1, η) 上退化**。这正是问题偏偏在这里难的原因，也解释了
为什么 `R` 只满足上端条件而不满足下端条件（`Im z → −∞` 时 `λ^z → ∞`，离开吸引盆）。

这条观察还提示一个**本轮没做的、可能更灵敏的实验**：`R` 沿虚方向以 `T = 2πi/log λ` 严格周期，
而 `K` 若不等于 `R` 则不周期，且周期缺陷被放大 `1/Λ` 倍——把一个 `10⁻⁸` 的问题
变成 `O(1%)` 的问题。⚠ 可行性未验证：`sexp_from_coeffs` 只是 0 处的 Taylor 级数，
`z = 0.5 − 2.1i` 远在收敛半径外，而函数方程只平移实部、够不到。需要先解决求值问题。
