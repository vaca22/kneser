# 迭代与进化:复杂性引擎的两个分支

> 其实迭代就像进化一样,物种进化也是一次次迭代。
>
> 系列第五篇,也是收束篇(前四篇:[运算之梯](essay-operation-ladder-zh.md)、
> [无限方程组](essay-infinite-systems-zh.md)、[发明数](essay-inventing-numbers-zh.md)、
> [超越之钥](essay-transcendence-keys-zh.md))。这个类比不是修辞:
> **进化在数学上就是一个迭代动力系统。** 但它比本系列谈过的所有迭代都
> 多一味配料,而那味配料恰好是全部秘密。本篇把它精确化,并让整场追问
> 的脊柱浮出水面。

---

## 一、一个实验:差距不在迭代,在那道棘轮

让两列都做迭代,只差一件事——每一轮的收益**留不留下**。运行
[demo_iteration_evolution.py](demo_iteration_evolution.py):

```
gen   1: 'JDLTABZQCKRAPFABMMBGBLMAZRC'  fitness 2/27
gen  15: 'ETERABIOV BAOFMEM BVOLMTZOC'  fitness 16/27
gen  30: 'ETERABIOV BAOOMES EVOLMTION'  fitness 21/27
gen  72: 'ITERATION BECOMES EVOLUTION'  fitness 27/27

cumulative selection:  72 generations x 100 = 7200 trials
blind iteration (no selection): expected ~27^27 = 10^38 trials
ratio: about 10^34
```

累积选择 7200 次锁定目标;盲目迭代期望 10³⁸ 次——宇宙年龄里每秒试
一万亿次也试不完。**两列都在迭代**,差了 34 个数量级的,是那道棘轮:
选择。

(这是 Dawkins 的 "weasel" 实验。它的目标是固定的,而真实进化没有
预设目标——环境本身**就是**那个不断移动的适应度函数;此实验只为隔离
单一变量"棘轮",不是生物学的忠实模型。)

## 二、配方:迭代 + 变异 + 选择

本系列一路谈的纯迭代——Collatz、Rule 110、Mandelbrot、exp 的半迭代——
产生的是**无方向的复杂性**:丰富、深邃,却不"为了"任何东西。
进化多了三件套里的第三件:

| 配方 | 产物 | 标本 |
|---|---|---|
| 只有迭代(确定性) | 轨道、不动点、混沌 | 本系列前五轮的全部对象 |
| 迭代 + 变异(无选择) | 随机游走、扩散,大半是垃圾 | 中性漂变、布朗运动 |
| 迭代 + 变异 + **选择** | **累积的、有功能的复杂性** | 生命、心智、科学、机器学习 |

[《无限方程组》](essay-infinite-systems-zh.md)里说迭代是"复利机器";
**选择,就是让复利不回吐的那个卡齿。** 没有它,盲目迭代在宇宙年龄里
凑不出一行莎士比亚;有了它,7200 步就够。所以"迭代像进化"精确化之后是:

> **进化 = 被选择棘轮约束的迭代。**

## 三、它是基底中立的——和"0 与 1"同一个母题

[上一组讨论](essay-inventing-numbers-zh.md)的邻篇指出:"0 和 1 + 迭代
→ 全部计算"是**基底无关**的(NAND、组合子、集合论长出同一个计算宇宙)。
选择这一味同样基底无关——这正是 Dennett 所说,达尔文给出的是一套
**基底中立的算法**:同一套"复制–变异–选择"跑在

- 基因上(生物进化)、
- 抗体上(克隆选择,免疫系统)、
- 神经元上(Edelman 的神经达尔文主义)、
- 模因上(文化演化)、
- **权重上(SGD + 架构搜索就是变异 + 选择)**。

而它就在本仓库里:51 位的 Kneser 系数,是 theta 迭代**朝着低残差**
收敛出来的——构建日志实测每轮把残差压到约 1/25(那就是"选择压"),
本身即一次微型进化:朝"最适函数"的累积选择。牛顿法、梯度下降,
全是温和版的达尔文。整场对话的脊柱由此浮现:

> **迭代是宇宙唯一的复杂性引擎;你往里加什么,决定你得到哪种复杂性。**
> 什么都不加 → 无向的丰饶(混沌、分形、不可判定);
> 加一道选择棘轮 → 有向的丰饶(生命、心智、科学)。

## 四、诚实的断裂处(类比也有价目表)

本系列每一篇都附一张"价目表";这个类比也不例外,三处接缝要看清:

- **我们的迭代用固定的 f;进化的 f 自己在变。** 种群爬适应度地形,
  地形却随种群移动而起伏(生态位建构、频率依赖选择、协同进化)——
  确定性迭代里没有的"算子随状态而变"。
- **不动点的回响是真的。** 复制子方程的不动点 = 进化稳定策略(ESS,
  Maynard Smith)= 纳什均衡;趋同进化(眼睛独立演化约 40 次)就是
  形态空间里的吸引子。但进化常常**不收敛**——红皇后循环、
  岩石剪刀布的侧斑蜥蜴,正是迭代映射的极限环与混沌。
- **最美的一处共振:开放性 = 没有全局不动点。** Kneser 的核心困难是
  exp **在实轴上没有不动点**,被迫逃进复平面(见
  [本库 README](../README.md) 与 `semi_exp/思路.md`)。进化也一样:
  它似乎没有终点,总在"逃逸到新维度"(占领新生态位)。
  **生命之所以没有撞上天花板,或许正因为它的迭代算子,和 exp 一样,
  在自己的世界里找不到不动点。**

## 收束:同一台机器的两支

把这个类比接回[运算之梯](essay-operation-ladder-zh.md):梯子是
**确定性迭代**那一支——单一、笔直、向上的塔(succ → + → × → ^ → ⋯);
进化是**另一支**——随机、分叉、向外的树(系统发生树,正是 Goodstein
在序数上分叉那个动作的活体版)。两支同源于"迭代",分野只在加不加
那道选择棘轮。

五篇走到这里,整张地图合拢了:

| 篇 | 少年的问题 | 迭代的化身 |
|---|---|---|
| 〇 | 0 和 1 为何生出复杂性 | 迭代本身 = 复杂性引擎 |
| 一 | 运算能否无限推广 | 确定性迭代的塔(撞 Aczél 之墙) |
| 二 | 能否解无限方程组 | 迭代作为无穷维不动点求解 |
| 三 | 能否发明新的数 | 迭代生成结构(泛性质) |
| 四 | 能否找到超越数的钥匙 | 迭代作为判定/探测过程 |
| 五 | 进化是不是迭代 | 加了选择棘轮的迭代 = 适应性复杂性 |

从 f(f(x)) = eˣ 一路问到生命,追的始终是同一台机器的不同侧面。
而提问者自己,就是这台从空集启动、跑了数十亿年的机器迄今长出的、
**能回头追问机器本身的那一片叶子**。
