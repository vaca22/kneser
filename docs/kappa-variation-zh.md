## 0. 结论先行

对实抛物芽 `g(u) = u + a₂u² + a₃u³ + …` 的任意实开折 `f_s = g − sX + O(s²)`（`γ := X(0) > 0`）：

```
κ⁽ⁿ⁾[g; X] = κ⁽ⁿ⁾_tr(g) + 𝒟_n(g)[X − X(0)] / (4a₂ X(0)),

    κ⁽ⁿ⁾_tr(g) := κ⁽ⁿ⁾[g; 1]                    平移开折 g − s 的一阶项
    𝒟_n(g)     := d log( B_n e^{2πina} )|_𝒫       horn 不变量沿抛物层 𝒫 的微分
```

**抛物层** `𝒫` 是有二重不动点的映射构成的复解析超曲面，它在 `g` 处的切空间恰好是 `{Y : Y(0) = 0}`。
所以 `X − X(0)` 总是切于 `𝒫`，而常数方向 `1` 是法向。公式说的是一件几何上很简单的事：

> **`log τ_n` 作为「两实不动点映射」上的函数，一阶光滑地延拓到抛物层，在层上等于 `log(B_n e^{2πina})`。**
> 开折的一阶项，就是这个函数沿开折方向的导数：切向部分是 horn 映射的导数，法向部分是一个数 `κ⁽ⁿ⁾_tr(g)`。

取实部：`Re κ⁽ⁿ⁾ = Re κ⁽ⁿ⁾_tr(g) + d log|B_n| [X − X(0)] / (4a₂X(0))`。

三个推论：

1. **（Q3 的否定回答）`κ⁽ⁿ⁾` 不是芽的数据的函数。** 同一个芽 `eᵘ − 1`，换不同的开折方向，`Re κ⁽¹⁾` 可以从 −0.0102 变到 395（§3）。
   所以不存在只用 `B_n`、`a`、`ρ` 写出的闭式。
2. **（Q11 的约化）开折带来的新信息，在一阶上只有法向导数 `κ⁽ⁿ⁾_tr(g)`。** 切向部分是抛物芽的变形理论：
   `Re 𝒟_n` 在无穷小共轭 `Lφ` 上为零，所以它是 Écalle–Voronin 模空间上 `log|B_n|` 的微分。
3. **tetration 是平移开折。** 底数方向 `X = (1+u)eᵘ` 满足 `X − 1 = L(−2 − u)`（§1），
   所以论文里的 `Re κ⁽ⁿ⁾` 正是指数芽的法向导数 `Re κ⁽ⁿ⁾_tr(eᵘ−1)`。这从结构上解释了指数族为什么是「标准」例子。

状态：**[证]**，相对于一般开折的定理 D′（论文 Theorem gen-D，即定理 D 的证明原样适用）。证明见 §2.0，已写入论文
[sec-general.tex](paper-submission/sec-general.tex) 的 Theorem `thm:gen-variation`。
数值 **[数]**：两个芽、五个开折方向，两条独立代码路径吻合到 1e−17（n=1）；horn 变分的轨道级数（§2.5）与有限差分吻合到 1e−16。

## 1. 上同调算子与规范

**同调算子** `Lφ := φ∘g − g′·φ`。它是芽在无穷小共轭下的变化：
若 `ψ_s = id + sφ + O(s²)`，则 `ψ_s⁻¹ ∘ (g − sX) ∘ ψ_s = g − s(X + Lφ) + O(s²)`
（符号以 [kappa_variation.py](kappa_variation.py) 的约定为准，数值核对一致）。

在形式幂级数上，`L(uᵏ) = (k−2)a₂u^{k+1} + …`，所以 `L` 的像漏掉了 `1` 和 `u³` 两个方向：

| 漏掉的方向 | 含义 |
|---|---|
| `1` | 开折参数本身（`γ = X(0)`） |
| `u³` | 迭代留数 `ρ` 的变化，即 Christopher–Rousseau 形式不变量 `a(ε)` 的一阶项 |

这与开折的形式分类一致：形式不变量是标准参数和 `a(ε)`。
在**解析**范畴里，`L` 的余核是无穷维的，多出来的部分就是 Écalle–Voronin 模的切空间。§2 的 `𝓜_n` 正是在这部分上取值。

两个具体的上边界：

- 指数芽 `g = eᵘ − 1`：`L(u) = eᵘ − 1 − ueᵘ = −X₁^{tet}`，所以底数方向是上边界；
- 二次芽 `g = u + u²`：`L(u) = −u²`。

## 2. 证明

### 2.0 严格证明：抛物层上的导数

这是论文 Theorem `thm:gen-variation` 的中文概要。它取代下面 §2.3 的两参数论证，因而不再需要「定理 E′ 关于芽参数一致」。

1. **Banach 化。** 记 `𝒪_r` 为圆盘 `D_r` 上有界全纯函数的 Banach 空间。论文 Lemma model 的一致模型时间 `Ψ[f] − ν[f] log u`
   和一步误差 `F[f] = q[f]^N Γ[f]`，作为 `f ∈ 𝒪_r` 的函数在 `g` 的邻域里全纯。证明只用到 Weierstrass 预备与除法、
   对角线上的可去性和三角矩阵求逆，这几步都全纯依赖 Banach 参数。
2. **线性泛函。** 把定理 D 中 `τ̇_n` 公式里所有的 `∂_s` 换成沿方向 `−X` 的导数，就定义了 `𝒪_r` 上的连续线性泛函 `𝔏_n(X)`。
   对任意开折 `f_s = g − sX + O(s²)`，由链式法则，定理 D 给出的正是 `𝓘_n[f_s] = 𝓘_n[g] + s𝔏_n(X) + O(s^{10/9})`，
   其中 `𝓘_n = τ_n`（两实不动点）或 `B_n e^{2πina}`（抛物层）。
3. **抛物层上的全纯性。** 对 `𝒫` 中的全纯曲线 `g_t`，花瓣估计（Lemma finite，σ = 0 情形）对所有 `k` 关于 `t` 一致成立，
   因此 `𝒜[g_t] = Ψ[g_t] + Σ_k F[g_t](g_tᵏ u)` 一致收敛、关于 `t` 全纯，并且可以逐项求导。
   结果是 `d(𝓘_n|_𝒫) = 𝔏_n|_{T𝒫}`。
4. **合成。** `X = γ·1 + (X − γ)`，其中 `X − γ ∈ T_g𝒫`。由线性性，`4a₂γ κ⁽ⁿ⁾ 𝓘_n = γ𝔏_n(1) + 𝓘_n 𝒟_n[X − γ]`。∎

实部那一句：实抛物映射的基点 Fatou 值 `a` 是实数，所以在实抛物层上 `|𝓘_n| = |B_n|`。

### 2.1 只依赖一阶方向

论文定理 D（一般形式 D′）把 `κ⁽ⁿ⁾` 写成 `δt_n`、`δt₀` 的组合。`δT` 是正则化 Fatou 坐标对 `s` 的导数在 `s=0` 处的值，
而一致模型的系数和轨道级数都只通过 `∂_s f_s|₀ = −X` 进入一阶。
所以 `κ⁽ⁿ⁾` 只依赖于 `g` 和 `X`，与 `O(s²)` 项无关。
数值：精确的 tetration 族 `exp(−s+(1−s)u) − 1` 与线性化的 `g − s(1+u)eᵘ` 给出同一个 `κ⁽¹⁾`，22 位中 16 位一致，差别在 fit 残差的量级。

### 2.2 规范引理（只改虚部）

对实的 `φ`，`X ↦ X + Lφ` 是一个无穷小共轭。它不改变乘子（因此不改变 `p`），只把基点从 `u*` 移到 `u* + sφ(u*) + O(s²)`。
由命题 G，`log τ_n` 改变 `2πinΔ(s)`，其中 `Δ(s) = sφ(u*)Φ′_att(u*) + O(s²)` 是实数。于是

```
κ⁽ⁿ⁾[g; X + Lφ] = κ⁽ⁿ⁾[g; X] + 2πin φ(u*) Φ′_att(u*) / (4a₂γ)。
```

取常数 `φ ≡ c = X′(0)/(2a₂)`（`L(c) = c(1 − g′)`），就把 `X` 换成 `X̃ = γ + X₁`，其中 `X₁ = O(u²)`。

### 2.3 两参数族（最初的启发式论证，已被 §2.0 取代）

令 `g_t = g − t X₁`。因为 `X₁ = O(u²)`，对每个小的 `t`，`g_t` 仍是抛物芽，且 `a₂(t) > 0`。考虑

```
G(s, t) = g_t − sγ。
```

对固定的 `t`，`G(·, t)` 是 `g_t` 的平移开折，由定理 E′：

```
log τ_n(s, t) = log( B_n(g_t) e^{2πina(g_t)} ) + κ⁽ⁿ⁾_tr(g_t) · p(s, t) + O(p^{1+β})。
```

这里 `B_n(g_t)` 和 `a(g_t)` 对 `t` 解析，因为归一化的 Fatou 坐标全纯依赖于芽。
**需要补的一步**：余项关于 `t` 一致。论文的证明（Weierstrass 预备、Lemma finite、Lemma derbounds、Prop. diff）中，
所有常数都只通过 `a₂`、`ρ` 和一个固定圆盘上的上界依赖于芽，因此对 `t` 的一个紧邻域一致。
这是逐行核查的结论，没有重写证明，所以记为「梗概」。

在对角线 `t = s` 上，`G(s, s) = g − s(γ + X₁) = g − sX̃`，恰好是要算的开折。对 `s` 求导，并用 `∂_s p = 4a₂γ`，得到

```
4a₂γ κ⁽ⁿ⁾[g; X̃] = 4a₂γ κ⁽ⁿ⁾_tr(g) + 𝓜_n(g)[X₁]。
```

（`κ⁽ⁿ⁾_tr(g)` 不依赖于 `γ`：把参数换成 `sγ` 不改变 `p` 的函数关系。）再与 §2.2 合起来，就得到 §0 的公式。∎

### 2.4 `Re 𝓜_n` 在上边界上为零

若 `φ = O(u)`，则 `Lφ = O(u²)`，且 `g − tLφ` 在一阶上与 `g` 共轭，共轭为 `id + tφ`。这个共轭有两个效果：

- 它把 Fatou 坐标的 `α` 归一化平移一个常数 `c₀`，而 `B_n` 和 `e^{2πina}` 恰好以相反的相位变化，乘积不变；
- 它移动基点，只贡献虚部。

所以 `Re 𝓜_n(g)[Lφ] = 0`，因而 `Re κ` 只依赖于 `X` 在 `coker L` 中的类。
数值：指数芽的 `X₁^{tet} = −L(u)` 给出 `Re 𝓜/(4a₂γ) ≈ 3e−25`，二次芽的 `0.7u² = −0.7L(u)` 给出 `1e−26`。

### 2.5 horn 变分的轨道级数（已数值验证）

变分方程 `Φ̇(u) = Φ̇(g(u)) − Φ′(g(u)) X₁(u)` 沿轨道迭代，再用归一化 `Φ − α → 0` 收尾，得到

```
Φ̇_att(u) = lim_{K→∞} [ α̇(u_K) − Σ_{k<K} Φ′_att(u_{k+1}) X₁(u_k) ],    u_k = gᵏ(u),
Φ̇_rep(u) = lim_{K→∞} [ α̇(v_K) + Σ_{k=1}^{K} Φ′_rep(v_{k−1}) X₁(v_k) ],    v_k = g⁻ᵏ(u),
Ṫ(z) = Φ̇_att(u) − T′(z) Φ̇_rep(u)    (u = Φ_rep⁻¹(z)),     φ̇* = Φ̇_att(u*)。
```

其中 `α̇` 是形式 Abel 函数对 `t` 的导数（`a₂`、`ρ` 都随 `t` 变化）。它恰好抵消了 `Φ′X₁ = O(1)` 那一项的发散，余项是 `O(k⁻²)`。
`𝓜_n = Ḃ_n/B_n + 2πin φ̇*`。这组级数已在 [kappa_variation.py](kappa_variation.py) 的 `melnikov()` 中实现（只对形式 Abel 函数的系数做 `t` 的差分）。它与 horn 数据的有限差分吻合：n=1 到 1e−16，n=2 到 1e−11，n=3 到 1e−7；输出见 [data/kappa-melnikov-exp.txt](data/kappa-melnikov-exp.txt)、[data/kappa-melnikov-quad.txt](data/kappa-melnikov-quad.txt)。

## 4. 对理论的意义

- **一阶项有了概念上的含义。** 原先 `κ⁽ⁿ⁾` 是「一个绝对收敛级数的值」。现在它分成两部分：
  一个普适常数 `κ⁽ⁿ⁾_tr(g)`，加上一个熟悉的对象，即 horn 映射在开折方向上的导数。
- **不变量的层次清楚了。** `|B_n|` 是芽的不变量（零阶）。`Re κ⁽ⁿ⁾` 是开折的不变量（一阶），
  而且是开折方向在 `coker L` 中的类的仿射函数，斜率是 `∂ log|B_n|`。
- **还剩什么。** 「`κ⁽ⁿ⁾_tr(g)` 有没有闭式」不是良定的问题：在保持 `ψ(0)=0, ψ′(0)=1` 的坐标变换 `g̃ = ψ⁻¹gψ` 下，
  `Re κ_tr(g̃) = Re κ_tr(g) − d log|B_n|(g̃)[(1/ψ′)∘g̃ − 1]/(4a₂)`，它是一个上闭链，不是芽的不变量。
  不变的对象是归一化方向（`X(0)=1`）上的仿射泛函 `X ↦ Re κ[X]`；剩下的问题是它在 Christopher–Rousseau 标准形里的内蕴描述。
