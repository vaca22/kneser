## 2. 三个新引擎

### 2.1 a = η：抛物引擎（`_general.ParabolicEngine`）

令 w = e(1+u)，则 E_η 化为 u ↦ e^u − 1，抛物不动点在 u = 0。吸引花瓣（u < 0）上的
Abel 函数有渐近展开

```
α(u) = −2/u + (1/3)·ln(−u) + Σ_{k≥1} c_k u^k,   c₁ = −1/36, c₂ = 1/540, …
```

系数由 α(f(u)) = α(u) + 1 形式地逐阶解出（三角方程组，对角元 k/2），取 40 项，
在 |u| ≤ 0.02 处求和（c₄₀ ≈ −140，仍是渐近级数，这个半径下截断误差远低于 30 位）。
求 F(z)：把 z 推到 z+n 使 |u| 落进求和范围，Newton 反解 α(u) = z+n，再做 n 次
f⁻¹(u) = ln(1+u)。抛物反向迭代的误差放大只是多项式级的（∏1/(1+u_k) ~ n²），
所以 dps = digits + 10 就够。归一化 sexp(z) = e(1 + F(z + z₀))，F(z₀) = 1/e − 1。

验证：函数方程残差 0；17 位与 30 位引擎在 [−1.9, 5] 上差 ≤ 3e-23；sexp(10⁶) = 2.7182764
（e − 2e/10⁶ 级别地逼近 e，符合 −2/z 首项）；复高度 z = 0.5 + 0.3i 上函数方程残差 1e-29。

**这条最重要**：上一轮从 η 两侧外推得到的极限，现在有了 η 处的直接计算可比：

| z | 下方（正则）外推 | **η 抛物引擎** | 上方（Kneser）外推 |
|---:|---|---|---|
| 0.5 | 1.2571530750542 | **1.2571530750541726** | 1.2571531394179 |
| −0.5 | 0.62207798171893 | **0.622077981718926** | 0.62207763065418 |
| 0.25 | 1.1395937099882 | **1.13959370998821** | 1.1395937772325 |
| 1.5 | 1.5880085877572 | **1.58800858775722** | 1.5880085708649 |

下方外推与抛物解在全部打印位数（13–14 位）一致——正则迭代 a → η⁻ 的极限就是
抛物解，这一点现在是"到精度极限的数值等式"而不只是外推。上方 Kneser 侧仍只有
7–8 位（从 0.015 之外外推），一致但分辨率不够；要更近的 Kneser 基底必须换算法
（见 §4）。

### 2.2 复正则引擎（`_general.GeneralRegularEngine`）

对任意复基底 a ∉ {0, 1}，在主不动点 L 处做正则迭代，Schröder 反级数 u(s) 用
复系数同一套递推。吸引情形（|λ| < 1）用反向迭代 F(z) = E^{−n}(L + u(λ^{z+n}))，
排斥情形用正向 F(z) = E^{n}(L + u(λ^{z−n}))。

**归一化是关键差别。** 实基底 1 < a < η 时 z₀ 是实数，很好找；一般情形 F(z₀) = 1
的根是复数，Newton 从实起点找不到（会被困在实轴），从复起点找到的又可能不唯一。
所以改成不用 Newton 的构造：

* 吸引情形：1 的前向轨道 1, a, a^a, … 收敛到 L；迭代到 |w − L| 足够小后用级数反解
  s = u⁻¹(w − L)，则 z₀ = log s / log λ − m。这是**规范**的：sexp 就是"经过 1 的那条
  收敛到 L 的轨道"的插值，与实情形的定义完全平行。slog 用同一构造（先前向迭代
  再反解），所以 slog∘sexp = id 精确到周期 2πi/log λ 的选取。
* 排斥情形：1 的反向轨道应当在"最靠近 L 的对数分支"下收敛到 L。但 log 1 = 0，
  而对所有实验过的排斥基底（0.01、−0.5、−1、−2、−1+0.5i、3+2i）离 L 最近的分支
  恰好都是 0，反向轨道第二步就死在 log 0。此时正则超函数 F 是整函数、永不为 0，
  F(z₀) = 1 的根**成簇**（base −1 在 0.01 − 0.28i 附近 Newton 从四个起点收敛到四个
  互不相同的根），没有任何一个能称为"a↑↑0 = 1 的那条塔"。库对这些基底明确报错，
  引擎本身仍可通过 `_newton_root` 做研究用途。

验证（吸引情形，float64 与 hp 双路径）：整数高度 sexp(−1)=0、sexp(0)=1、sexp(1)=a、
sexp(2)=a^a 到 1e-14；函数方程与 slog 往返 1e-12；半迭代 f(f(x)) = a^x 到 1e-12
（例：base 0.5，f(0.3) = 0.6268 − 0.2446i，f(f(0.3)) = 0.81225 = 0.5^{0.3}）；塔极限
sexp(z→∞) = L 到 1e-12；i↑↑∞ = 0.43828 + 0.36059i。

**为什么这些基底的半高塔是复数，而不是库的缺陷。** 0 < a < 1 时 λ = L·ln a < 0，
λ^z 在非整数 z 处必为复数；实解析的实值解要求 λ^z 实，不可能。这与"e^{−e} < a < 1
的塔振荡收敛"是同一件事：振荡就是 (−1)^n，它的连续化 e^{iπz} 离开整数点就离开实轴。

### 2.3 拒绝的基底与理由

* a = 0, 1：0^x、1^x 没有塔（1↑↑z ≡ 1 但 slog 不存在）。
* a = e^{−e}：中性不动点（λ = −1），既非抛物（λ = 1）也非双曲，本轮未实现。
* 排斥主不动点的基底（0 < a < e^{−e}、a < 0、Shell–Thron 区外的复数）：§2.2。
  实 a > η 是例外，因为 Kneser 用的是复共轭不动点对而非实轴上的东西。

## 3. 一个值得记下的结构性事实

把所有区域并排看：库里现在有四种构造（Kneser θ-映射、实正则、抛物 Fatou、复正则），
它们在各自区域内是"唯一自然"的，而在区域交界处的行为是：

* η 处：正则 → 抛物 严格连续（到精度极限），Kneser → 抛物 数值一致到 7 位；
* 1 处（a → 1⁺ 与 a → 1⁻）：两侧都是正则引擎、都收敛到 L → 1，但 λ 的符号相反
  （a → 1⁺ 时 λ → 0⁺，a → 1⁻ 时 λ → 0⁻），非整数高度的值一侧实一侧复：a↑↑½ 在
  a = 1 处不连续地从实变复。0.9↑↑½ = 0.9087 + 0.028i 的虚部虽小但不为零。
* e^{−e} 处：吸引 → 排斥，规范性从有到无。

所以"a 取任意数"的诚实答案是：**a↑↑b 作为 (a, b) 的二元函数不是单个解析对象**，
而是被 Shell–Thron 边界和实轴切开的几块，每块各有自己的规范构造；Paulsen（2019）
用复基底解析延拓把 Kneser 块延拓到了区外，但那个延拓在 1 < a < η 上给出的不是
正则解——这是文献里已知的、也是本轮数值所暗示的图景（η 处 Kneser 侧只能到 7 位
一致，正是因为我们无法把 Kneser 构造推近 η）。

> **补充（2026-09-17，对外验证）**：上面这段"图景"现在有了外部证据，而且方向比预期更强。

## 4. 换构造：复基底的双不动点 Kneser 延拓（0.3.2）

§2.2 的结论是"排斥情形没有规范归一化"——那是正则迭代的结论。换一个定义就有了：
Trappmann–Kouznetsov 刻画 Kneser 解的条件是 F(z) 在 Im z → +∞ 趋向上不动点、
Im z → −∞ 趋向下不动点，实基底时两者共轭。复基底时把"共轭"去掉，让两个不动点
各自独立，就是自然的延拓。模块 `_cbuild.py`：

* 不动点选取：每个半平面各取 |λ| 最小者（arg λ > 0 给上、< 0 给下）。实基底 > η 时
  这正是共轭对 (k=−1, k=0)；越过实轴后连续变成 (k=0, k=1)。两者都必须排斥
  （|λ| > 1），这恰好覆盖 Shell–Thron 区外的全部基底。
* 上下半平面各做一套 θ-映射（正频/负频模式各自衰减），实轴带用函数方程，
  Cauchy 积分取复系数。isuperf 的对数分支每步取"离不动点最近"的那支——固定分支
  会让下不动点的 θ 跳到 20，沿采样线继承分支序列则在负实轴附近更糟，两者都试过。
* 硬闸：|w| > 10¹⁰⁰ 即中止（防止再吃 60 GB）；残差比历史最小值大 10 倍即判发散。

库的行为：区外复基底首次调用自动建 8 位表并缓存（`cbase-*.json`），只提供 `sexp`，

**分支的正确处理（0.3.3，决定性的一步）。** 上表"未达"的负实轴邻域后来全部打通了，关键是
两个诊断：

1. isuperf 的多值性不只差周期。对 −1+i 在下采样线 t = 0.383 处，两条反向链都收敛到 L_dn
   （|w−L| 均 5e-19），分支序列却从 [0,−1,…] 变成 [−1,0,…]，θ 跳了 2.0+0.9i——不是周期
   (−2.77+1.98i) 的整数倍。整函数 F 的原像不由平移相联系，Abel 函数有无穷多张**互不平移**
   的叶。所以"每步取离不动点最近的分支"会在采样线中途换叶；正确做法是沿采样线**解析延拓**：
   每一步选使链值最接近上一个采样点同一步链值的分支（按值比较，不按分支编号）。
2. 上半平面的采样线高度不能太低：δ_up = 0.05/0.1 时上线 θ 绕过 Abel 函数的一个分支点，
   wrap ≈ 0.79 持续不降；δ_up = 0.3 则正常。下半平面相反，δ_dn = 0.1 好于 0.3。
