# ↑↑ 的性质清单：哪些是定理、哪些是本仓库的数值、有没有周期

> 汇总 kneser 0.3.3 所覆盖的全部基底区域里 a ↑↑ z 的性质。标注 **[定理]** 的来自
> Kneser (1950)、Trappmann–Kouznetsov (2010)、Paulsen–Cowgill (2017)；标注 **[数值]**
> 的是本仓库在 galic 上验证过的结果（脚本在括号里）。周期性一节的数据来自
> `docs/demo_periodicity.py`。

## 1. 定义层面（所有区域都成立）

* 函数方程 a↑↑(z+1) = a^{a↑↑z}，锚点 a↑↑0 = 1、a↑↑1 = a、a↑↑(−1) = 0。**[定义]**
* z = −2 处对数奇点；实基底的实定义域是 z > −2。复基底延拓表当前限 Re z > −1.5。
* 逆函数 slog 与连续迭代群性质 exp_a^{[s]}∘exp_a^{[t]} = exp_a^{[s+t]}，
  半迭代 f(f(x)) = a^x。**[数值]** 各区域均验证到 1e-12（`tests/test_*`）。
* 基底共轭对称：a↑↑z 对 (a, z) 同时取共轭仍成立。**[数值]** 3±0.3i、3±2i、−1±2i 精确到 1e-10。
* 无闭式、超越：Kneser 常数 f'(0) = 0.8763361322248131、a* = 3.92334123872694829、
  a** = 17.5683909975713055 在 {e, π, ln2} 上 PSLQ 全阴性。**[数值]**（`demo_constants_pslq.py`、
  `base-landscape-zh.md`）

## 2. 周期性：有，分三种

| 区域 | 周期 | 数值证据 |
|---|---|---|
| 1 < a < η（正则） | **精确周期** P = 2πi/ln λ，纯虚 | base 1.3：P = −6.59938506i，\|sexp(z+P) − sexp(z)\| = 1e-26；半周期差 0.3–4，故无更小周期 |
| Shell–Thron 区内复基底 | **精确周期**，复数 | base i：λ = −0.5664 + 0.6885i，P = 2.7739274 − 0.1409950i，差 1e-27 |
| a > η（Kneser）与区外复基底 | **无精确周期**；上半平面渐近周期 2πi/log L₊，下半平面 2πi/log L₋（实基底时互为共轭） | base e：P₊ = 4.4469507 + 1.0579400i；Im z = 0.2 处 \|sexp(z+P₊) − sexp(z)\| = 0.034，随 Im z 按 e^{−2·Im L·Im z} 衰减（研究纪要命题 C） |

推论：
* 正则区与区内复基底的 slog 只在模周期意义下唯一。库按"离实轴最近"选叶，所以
  slog(i↑↑i) 返回 19.417 + 0.013i 而不是 i，二者在 sexp 下同值。
* Kneser 区没有周期正是它区别于 exp 的核心：exp 是 2πi-周期的，e↑↑z 不是。
* "有周期"和"塔收敛"是同一件事的两面：周期存在 ⇔ 只用一个不动点 ⇔ |λ| < 1。

## 3. Kneser 区实基底的解析性质 **[定理]**

* 实解析、严格单调，z → +∞ 超指数增长；在割掉 (−∞, −2] 的平面上全纯。
* Im z → ±∞ 分别趋向共轭不动点对 L、L̄；这两条渐近条件决定唯一性（Trappmann–Kouznetsov）。
* 半指数满足 x < f(x) < e^x，f(x) → ln(sexp(−½)) = −0.6960… 当 x → −∞。
* 基底 a = e 时 sexp'(0) = sexp'(−1) = 1.0917673512583（函数方程求导，一般地
  sexp_a'(0) = ln a · sexp_a'(−1)）。

## 4. 正则区与抛物点 **[定理 + 数值]**

* 1 < a < η：sexp 单调递增收敛到吸引不动点 α_a = −W₀(−ln a)/ln a；slog 只在 x < α_a 有定义。
* a = η：抛物解 sexp(z) → e，首项 e − 2e/z；它是正则解 a → η⁻ 的极限（**[数值]** 13 位吻合），
  Kneser 解 a → η⁺ 的极限与之一致到 7 位（外推分辨率极限）。
* e^{−e} < a < 1 与区内复基底：非整数高度必为复数（λ 为负或复，λ^z 离开整数即离开实轴），
  整数高度精确回实值。

## 5. 基底方向的性质 **[数值]**

* a ↦ a↑↑z 在 η 处两种构造严格接合（值、一阶导、二阶导按外推模型误差逐阶恶化，无折角）。
* a = 1 处半高塔从实突变为复（0.9↑↑½ 虚部 0.028，1.2↑↑½ 为实）；e^{−e} 处规范性从有到无。
* 负实轴是基底平面上的割线：(−1)↑↑½ 从上/下逼近得 0.9045 ± 1.6030i。
* 半指数斜率 f_a'(0) 随 a 单调上升，在 a* = 3.9233… 处恰为 1；a↑↑½ 在 a** = 17.568…
  处恰等于 ln a；大基底时 a↑↑½ 增长慢于 ln a（比值在 10–20 之间穿过 1，到 100 为 0.915）。
* a↑↑b 作为 (a, b) 的二元函数不是单个解析对象，被 Shell–Thron 边界和实轴切成几块，
  每块各有自己的规范构造（Kneser θ-映射 / 实正则 / 抛物 Fatou / 复正则 / 双不动点延拓）。

## 6. 没有的性质

* 高度方向没有加法型恒等式：不存在 a↑↑(s+t) 的乘积或复合公式（那是 exp 独有的）。
* 基底方向没有换底公式。
* Kneser 区 sexp 不是周期函数，也不是任何初等函数的迭代。
* 对 a ≤ 1 的实基底不存在实解析的单调塔；0 < a < e^{−e} 与 |a| < 0.8 的负基底目前连
  复值的双不动点解也未构造出来（`base-plane-zh.md` §4、§5）。
