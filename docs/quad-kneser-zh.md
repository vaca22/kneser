## 0. 结论

1. **c > 1/4 的采样点上得到 Kneser 型数值解。** 两个共轭排斥不动点之间的 θ 迭代收敛，数值解在实轴上取实值，上下共轭对称（c = 0.5 和 0.35）。
2. **圆弧采样与连续穿过主心形区边界相容。** 只用中性带两侧的点做插值，预测被留出点的误差为 6×10⁻⁹ 到 1.7×10⁻⁸，与同侧插值的精度相当。
3. **阶梯外推支持边界值与缝合解 K^W 一致。** 在心形区内令 `c = c_r + iy`、`y → 0`，分离系数 `ĉ₁ = c₁/Λ` 的外推值与缝合侧 `τ₁` 的比较如下：
   - λ = 0.1 时，二者之差是一个稳定的 9.0×10⁻⁹ ≈ 0.25Λ。它的复数值与论文一阶修正公式 `Λ[−4π²|τ₁|² − 2πiτ₁ − 4πiτ₂τ̄₁/τ₁]` 吻合到修正项本身的 0.3%，**连 O(Λ) 修正都对上了**。
   - λ = 0.2 时，`ĉ₁` 吻合到 2.5×10⁻⁹，`κ₂ = c₂/c₁²` 吻合到 3×10⁻⁷（40 位）；λ = 0.1 时 `κ₂` 吻合到 4×10⁻⁸（35 位）。

4. **定理 G 的数值探索目前只覆盖局部采样（§5）。** 构造只在尖点右下方的楔形区域内收敛：198 个网格点中收敛 60 个。
   在 θ = 0.25π、0.4π 两处，采样与全纯穿过心形区边界相容（跨边界插值误差约 10⁻⁷，跨边界变化约 10⁻¹）。
   离尖点更远的区域，构造本身不收敛：向上走的部分失败可以通过提高 θ 线绕开；向左走原因不明。所以那里给不出结论。

这些数值数据本身不确立解析延拓或边界值认同。后续独立证明已补上倾斜区域的轨道标记、拟共形输运比较和完整外侧区间覆盖，得到 F、G 的二次族类比，见 §5.5。当前 θ／Taylor 数值算法的全域收敛仍未建立。

## 1. 对应关系

| tetration `b^w` | 二次族 `w² + c` |
|---|---|
| 实底数 `b > η`：一对共轭排斥不动点，实轴逃逸 | 实参数 `c > 1/4`：不动点 `1/2 ± i√(c − 1/4)`，乘子模 `2√c > 1` |
| Shell–Thron 区（有吸引不动点） | Mandelbrot 集的主心形区 |
| 尖点 `η = e^{1/e}` | 尖点 `c = 1/4` |
| 中性端点 `e^{−e}`（乘子 −1） | `c = −3/4`（乘子 −1） |
| 归一化 `sexp(0) = 1`；`−2` 处是对数奇点 | 归一化 `F(−3) = 0`，即 `F(0) = f³(0)`；`−3` 处是平方根分支点（`F = 0` 是临界点） |
| Kneser 解在 `ℂ \ (−∞, −2]` 上全纯 | 预期在 `ℂ \ (−∞, −3]` 上全纯（未证） |

**归一化的选择。** 对实数 `c > 1/4`，实解 `F` 递减到 0 之后，再往回一步就是 `√(−c)`，因此 `F` 在 `F = 0` 处有平方根分支点。
取 `F(−3) = 0` 是当前构造的归一化选择；即使 −3 是预期的分支点，也不能据此断言 0 处的 Taylor 收敛半径恰为 3，还需要排除更近的奇点。这个归一化对 `c` 连续，跨过 1/4 后在 `c < 1/4` 一侧给出基点 `w₀ = f³(0) ∈ (0, p)`，正好满足 (H4)。

**方向。** 由一般陈述 W1′(2)，`Im c > 0` 时吸引不动点 `p` 的乘子满足 `arg λ_p > 0`，所以 `p` 是「上方」不动点。这与 `_cbuild` 的选取规则（上方取 `arg λ > 0`）一致。

## 2. 构造

做法与 `kneser/_cbuild.py` 相同：

- 上半平面：`F = superf_up ∘ (id + θ_up)`；
- 下半平面：`F = superf_dn ∘ (id + θ_dn)`；
- `|Im z| < 0.1` 的带内：用函数方程从当前 Taylor 级数推出；
- 在单位圆上做 Cauchy 积分，更新 Taylor 系数。

需要改的地方：

- 逆 Schröder 级数满足 `2Lu + u² = u(λs)`，即 `u_k = Σ u_i u_{k−i}/(λ^k − λ)`；
- 逆映射 `±√(w − c)` 的分支选择：取离上一个采样点同一步的链值最近的那支；
- 排斥一侧的反向迭代步数改为自适应。从 `p` 附近出发、目标是 `q` 时，需要先逃离 `p`，固定步数不够。

| c | 上方 \|λ\| | 下方 \|λ\| | 迭代轮数 | 残差 |
|---|---|---|---|---|
| 0.5 | 1.414（排斥） | 1.414 | 10 | 2×10⁻¹⁴（12 位） |
| 0.09 + 0.05i | 0.227（吸引） | 1.81 | 13 | 8×10⁻¹⁴（12 位） |
| 0.0475 + iy（λ=0.1 阶梯） | ≈0.1 | ≈1.9 | 40–56 | ~5×10⁻²⁷（25 位） |
| 0.09 + iy（λ=0.2 阶梯） | ≈0.2 | ≈1.8 | 30 | ~5×10⁻²⁷（25 位）、2×10⁻⁴²（40 位） |

c = 0.5 时，`F` 在实轴上的虚部约为 10⁻⁴⁵，并且 `F(±0.3i)` 互为共轭。在心形区内，从线性种子出发同样收敛。
`_cbuild` 的文档说在 Shell–Thron 区内线性种子会发散，这里没有遇到这个问题。

## 4. 竖直阶梯：边界值 = K^W

在心形区内取 `c = c_r + iy`，`c_r = (1 − (1−λ)²)/4`，并在 `λ = 0.1`（`c_r = 0.0475`）和 `λ = 0.2`（`c_r = 0.09`）两处做阶梯。
上方表示满足 `K = R ∘ (id + θ_up)`，所以 `P = R⁻¹∘K − id = θ_up + 常数`，分离系数可以直接从 θ_up 的 Fourier 模读出：`c_n = a_n e^{2πnδ}`。
由于 `K(0) = f³(0) = w₀`，平移已经确定，`ĉ_n = c_n/Λⁿ`。
缝合侧用 `generality_check.py quad`，取同一基点 `GC_W0 = f³(0)`。采样线放在 `Im = −0.5` 和 `−1.0`：λ 小时吸引周期 `h` 只有 2.7–3.9，T 的全纯带很窄。两线核对的误差为 10⁻⁵²。

|---|---|---|---|
| 0.1 | 3.580×10⁻⁸ | 0.010243893233648 + 0.056919566227631i | 1.12245372671 + 0.05416166021i |
| 0.2 | 2.224×10⁻¹¹ | 0.0076798316662245 + 0.0581876465003169i | 0.81083478269 + 0.08819254538i |

**ĉ₁ 的外推**（对 y 做 Neville 多项式外推，取最小的 k 个点）

| λ | y 范围 | k=2 | k=3 | k=4 | k=5 | k=6 |
|---|---|---|---|---|---|---|
| 0.2 | 0.16 … 0.00125 | 1.5e−5 | 5.3e−7 | 4.3e−8 | 7.4e−9 | 2.5e−9 |
| 0.1 | 0.04 … 0.0003125 | 3.2e−6 | 6.5e−8 | 9.8e−9 | 8.9e−9 | 9.1e−9 |

λ = 0.1 时，偏差从 k = 4 起就**停在 9.0×10⁻⁹，不再减小**。这不是外推误差，而是边界值与 τ₁ 之间真实存在的 O(Λ) 差别。按论文 §W2 末尾的一阶公式计算：

```
实测   (ĉ₁/τ₁ − 1)/Λ = 0.227175 − 0.111999 i
预测   −4π²|τ₁|² − 2πiτ₁ − 4πiτ₂τ̄₁/τ₁ = 0.227866 − 0.111543 i
```

二者相差约 0.3%，换算成 ĉ₁ 的相对精度约为 3×10⁻¹¹。
这为从心形区内部趋于实轴的边界值与缝合解 K^W 一致提供了数值证据，并检验到了 O(Λ) 修正项；有限阶外推并不证明极限存在或函数层面的认同。
λ = 0.2 时 Λ 只有 2×10⁻¹¹，O(Λ) 项在外推精度以下，看不出来。

|---|---|---|---|---|
| 0.2 | 40 位，y = 0.01 … 0.00125 | 9.7e−5 | 3.7e−6 | 3.1e−7 |
| 0.1 | 35 位，y = 0.01 … 0.000625（5 点，k=5 时 4.2e−8） | 8.9e−5 | 3.2e−6 | 2.5e−7 |

### 4.1 关于精度

`c₂ ~ Λ²τ₂` 非常小（λ = 0.1 时约 5×10⁻¹⁸，λ = 0.2 时约 10⁻²⁴），所以 25 位的构造不够用：

- λ = 0.2、25 位时，κ₂ 完全是噪声（例如 −13.9 − 0.14i）；
- λ = 0.1、25 位时，κ₂ 的外推稳定在偏离 3.9×10⁻⁵ 的位置。但同一个 y = 0.005 用 35 位重算，κ₂ 本身就变了 7.8×10⁻⁵，所以这个偏差是数值误差，不是真实差别。ĉ₁ 在 25 位和 35 位之间只差 10⁻¹³（相对值），不受影响。

λ = 0.1 的 35 位阶梯（y = 0.01 … 0.000625，残差约 10⁻³⁶）：κ₂ 外推到 1.122453711 + 0.054161622i，与 t₂/t₁² = 1.122453727 + 0.054161660i 相差 4.2×10⁻⁸（k = 5），约为 1.2Λ。

## 5. 全上半平面与单值性（定理 G 的数值探索）：仅有局部采样

**问题。** 论文定理 G：Kneser 族在整个上半 b 平面单值全纯。二次族的对应目标是整个上半 c 平面上的单值全纯族。逐点算法不记路径并不意味着其输出就是某一解析芽的单值延拓；即使处处收敛且连续，也还需要证明参数全纯性、局部表示在重叠区域的认同与沿路径延拓的一致性。有限网格更不能确立这些性质。

**结论：当前构造仅在尖点附近楔形区域的一部分采样点收敛。这提供局部数值证据；无论区域内外，都尚未确立单值性。区域外的构造失败也不构成非单值性的反证。**

### 5.2 失败的性质

- **向上（`Im c` 增大，在心形区外）：是方法的限制，可以绕开。** 把 θ 线的高度 δ 从 0.1 提高到 0.2、0.3、0.4，沿 `Re c = 0.5` 往上走能到的 `Im c` 依次为 0.45、0.5、0.55、≥0.55。同一个 c 在不同 δ 下给出的 `a₁` 完全一致。
  这和 `_cbuild` 在 tetration 左半平面遇到的问题相同：θ 线绕住了 Abel 函数的一个分支点，θ 就不再是 1-周期的。
- **向左（`Re c ≲ 0.05`，心形区内部）：原因不明。** 在 `c = 0.05 + 0.2i`，θ 迭代收敛到一个**不是解**的不动点：残差恒为 0.04588，150 轮都不变。
  改变 δ（0.05–0.4）、增加 Taylor 项数（48 → 160）、用相邻已收敛点的系数作种子，都没有改善。
  这说明问题不在截断，而是迭代锁在了一个自洽但错误的构型上（可能与带内平方根分支的选择，或 F 的奇点位置有关）。**没有查清。**

### 5.4 构造改造的候选方案（尚未实现）

当前 `quad_kneser.build` 同时固定时间展开中心 `z = 0`、单位 Cauchy 圆和 `F(0) = f_c³(0)`。需要先区分局部表示失效与所跟踪解本身的障碍。可尝试：

1. **移动时间变量的 Taylor 中心。** 改用 `F(z₀ + ζ)` 的级数，随参数选择中心与积分半径，并在相邻圆盘的重叠区域比较函数值及函数方程残差。此处移动的是时间变量 `z` 的展开中心；换中心能否避开奇点并改善非中性区域的收敛，仍需实验。它不能消除 §5.6 的 Schröder 共振障碍。
2. **固定 θ_up 的常数模。** 在选定并连续跟踪的上方 Abel 分支上，以 `a₀_up = α` 代替强制 `F(0) = f_c³(0)`。若 `F_s(z) = F(z+s)`，则 `θ_up,s(z) = s + θ_up(z+s)`，常数模变为 `a₀_up + s`；这给出局部时间平移的规范。代码需调整整个时间平移及上下表示，而非只覆盖一个 Fourier 系数。与现有阶梯数据比较时，还须在可用的局部区域换回相同基点归一化。有限时间平移也不能产生共振点不存在的可逆 Schröder 芽。
3. **分别选择 δ_up、δ_dn。** 根据两侧 Abel 坐标的可用区域调整采样线，检验分支链、周期闭合及上下表示的一致性。提高共同 δ 的有限成功不能保证整个上半参数平面可覆盖。

实验应先复查已收敛基准与 `c = 0.05 + 0.2i` 等失败点，再比较不同参数路径到达同一终点的结果。收敛判据需要加入多个点的函数方程残差、表示重叠误差与精度／截断稳定性。这些检验可以扩大数值覆盖并定位障碍；全局延拓及单值性的证明仍需要前述几何与区间证书。

### 5.5 F、G 的证明与可重放证书

2026-10-04 的证明稿见 [`proofs/quadratic-continuation.tex`](proofs/quadratic-continuation.tex)。该稿的 Quadratic F、Quadratic G 以原归一化 `F_c(0) = f_c³(0)` 陈述和证明，结论针对正则高度芽及指定的延拓图卡。

- 在整个上半 c 平面，设 `a² = 1/4 − c`、`Re a < 0 < Im a`，则不动点弦坐标中的映射恰为 `S_a(ζ) = ζ + a(ζ² − 1)`。弦及其像构成 Jordan 月牙域，且 `S_a` 在整个下半 ζ 平面单叶。
- 用 `ζ = tanh x + s a(tanh² x − 1)` 构造显式拟共形平坦模型，严格证明所有这些未指定临界轨道标记的商面都是 `ℂ*`。固定内部移动标记可以得到全域参数族，但它不等于原归一化的延拓结论。
- **完整外侧覆盖及中性弧穿越。** `R = |a| > 1/2` 时临界值 `c` 严格位于月牙域内部；`0 < R ≤ 1/16` 用解析首穿越估计；余下 `1/16 ≤ R ≤ 1/2`、`0 ≤ s = −Re(a)/R² ≤ 1` 用 Arb 区间覆盖。4,013 个闭参数盒全部通过，最大轨道索引 21。独立程序在 90 位精度重放全部盒，并用 282 个有理数横向分片验证精确覆盖，没有剩余盒。不同首入口图卡由解析接缝一致拼接。
- **主心形区的输运及认同。** 从 `λ_* = i/2`、`c_* = 1/16 + i/4` 出发，显式构造整个吸引盆上的不变 Beltrami 场；主解为奇函数，保持临界点 0，并把多项式精确输运到 `w² + λ/2 − λ²/4`。证明带标记输运族与直弦族在开参数集上一致，再沿整条中性弧传播一致性，得到整个上半 c 平面的单值全纯族（G）。
- **尖点标记与缝合分支（F）。** 在固定点对的对数坐标追踪第一次穿越，用可求和的导数误差控制回拉，并证明倾斜直线无关性和参数全纯性。下方绕行给出吸引时间虚部 `−h/2`，明确选出接缝 `T − ih`；商面之间的适当映射度数为 1，认同指定的 `K_c^W`。再沿实 `0 < c < 1/4` 的全纯缝合族传播，得到全区间边界值认同。
- 尖点倾斜区域得到显式步长、导数及拟共形估计。伴随脚本 [`certify_quad_geometry.py`](certify_quad_geometry.py) 在整个 `0 ≤ |ε| ≤ 1/128` 上核验常数，14 项 Arb 检查通过，结果见 [`proofs/quadratic-geometry-certificate.json`](proofs/quadratic-geometry-certificate.json)。这不是完整 F、G 的证书。

### 5.6 原 θ／Taylor 算法的全域收敛命题不成立

证明稿的 “The present theta/Taylor iteration cannot converge on all of H” 节给出严格反证，不是数值发散报告。取 `c = 1/4 + i/2`，上方固定点 `L = i/2`、乘子 `λ = i`。代码的逆 Schröder 级数必须满足

`(i^k − i) u_k = Σ_{j=1}^{k−1} u_j u_{k−j}`，`u₁ = 1`。

前三阶被迫为 `u₂ = (−1+i)/2`、`u₃ = (−1−i)/2`、`u₄ = (1−5i)/4`；第五阶于是要求 `0 = (3−5i)/2`。连形式级数都不存在，删去中性带拒绝条件也不能修复。任意非零线性缩放只把右端乘以缩放因子的五次方。

更一般地，单位根乘子 `λ^q=1` 若可线性化，就使二次多项式的 q 次迭代共轭于恒等映射；其次数为 `2^q`，矛盾。这样的参数在开放上侧中性弧上稠密。因此移动时间 Taylor 中心或固定 θ 常数模，保留原两侧 Schröder 表示时，均不能给出整个上半参数平面的直接求值算法。

精确有理数检查脚本为 [`certify_quad_theta_obstruction.py`](certify_quad_theta_obstruction.py)，输出 [`quadratic-theta-obstruction.json`](proofs/quadratic-theta-obstruction.json)，全部 9 项检查通过。该反证不否定 F、G：中性点的商面构造不要求固定点的 Schröder 线性化。把非中性数值输出取参数极限以得到中性值，是另一个需要证明一致性与误差控制的过程。

证明稿另给出**条件式局部收敛定理**：完整函数球上的导数界 `q<1`、中心缺陷 `d≤(1−q)R` 及逐轮总误差 `η_n→0` 蕴含收敛。误差必须覆盖正则函数与逆支、Fourier 截断与求积、圆周求积、Taylor 截断和舍入；还须独立证明固定点是所要求的分支。目前这些假设没有在二次族整个非中性区域上验证，不能称为已证全域收敛。全域数值方案还必须替换中性端的表示。

## 6. 没有做的

- 当前 θ／Taylor 算法仍未改造为全上半参数平面的数值求值器；§5.4 的移动中心与常数模方案尚未实现。
- 中性带内部仍没有 θ 迭代数值数据；证明稿的商面构造不使用中性乘子的算术性质。
- 尚未证明每一个数值迭代输出都选中证明稿的指定分支；数值比较仍按 §3–4 的检验范围理解。
- 尖点本身、实端点 `c = −3/4` 的边界延拓及全局高度奇点集未在此次 F、G 中证明。整个上半参数平面的参数芽结论不等于一个共同的全局高度定义域。
