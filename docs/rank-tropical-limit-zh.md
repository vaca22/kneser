## 0. 结论

记 `S_s(z) = b[s]z`（`S_s(0) = 1`，`S_s(z+1) = S_{s−1}(S_s(z))`），
`p_s` 为 `S_{s−1}` 的吸引不动点，`λ_s = S_{s−1}'(p_s)`，`L_s = |log λ_s|`。

1. **[推+数] 极限是折线，速率是 `log 2 / L_s`。**
   ```
   S_s(z)  →  F_b(z) = min(1 + z, b),
   固定紧区间上  ‖S_s − F_b‖ = (log 2)/L_s · (1 + o(1))
   ```
   软化折线自己满足 ‖Σ − F_b‖_∞ = log 2 / L，只在转折点取到 **[证]**。
   闭式对数离软化折线的最大值是 `u_0/L` 乘一个趋于 1 的因子（§2.10）**[证]**，
   即 `∼ 1/(s log(s/a))`，比 `1/L` 高一阶小。阶梯在 Koenigs 圆盘里贴着闭式对数
   （第 16 级已到 `10^{−7}`），转折点上的缺口因此就是 `log 2 / L_s` 减去这一项。
   ⚠ 上一轮写的「在 0 处跳变」是错的：转折点在 `z = b−1`。
   后来写的 softmin 误差 `∼ s^{−1.3}` 也撤回：那是 `1/(s log s)` 在第 16–48 级上的样子。

2. **[数+推] 有限阶就是这个折线的 log-sum-exp 光滑化（Maslov 去量子化）：**
   ```
   S_s(z)  ≈  −(1/L_s) · log( e^{−L_s (1+z)} + e^{−L_s b} ),      L_s = |log λ_s| ≈ log s / (b−1)
   ```
   温度 `ħ_s = 1/L_s → 0`。阶数趋于无穷 = 热带极限（`+` 变 `min`）。
   这个单参数公式的误差比阶梯离极限的距离小一个数量级以上，且衰减快得多。
   它的斜率与底数无关（§2.5）：`S'(b−1) → 1/2`，`−4 S''(b−1)/L_s → 1`，
   关于拐点对称的两点斜率之和趋于 1。同一个 `L` 决定整列导数：第四阶在第 24 级
   已是 `0.997 × L^3/8`（§2.6）。把速率律原式延到 `s+1/2` 和 `s+it` 之后，
   后继方程的缺陷与整数阶同量级，整数性不进入误差。第 24 级离开 `1/2`
   的整列导数，就是闭式对数在偏移 `u_0 = 0.145` 处的逻辑斯蒂（§2.7）。
   `s u_0 → 1/(b−1)`（§2.8）。后继缺陷的峰是
   `log 2 · (L_s − L_{s−1}) / L_s²`，在 `z = b−2`（§2.9）**[证]**。
   软化折线随 `L` 上升且不超过 `F_b`，所以收到折线（§3）**[证]**。

3. **[推+数] 速率律**：`s · λ_s^{b−1} → (2−b)/(b−1)`，
   ```
   s · λ_s^{b−1} = a + 1/log s + (1 + log a)/log² s + O(log⁻³ s),     a = (2−b)/(b−1)
   ```
   在约化映射上检验到 `s = 10⁷`（四个底数）。

4. **[推+数] 转折点处的缺口**：`g_s = b − S_s(b−1)` 满足 `g_s · L_{s−1} → log 2`，
   所以 `g_s ~ (b−1) log 2 / log s`——**对数慢**。

5. **[证] 不动点方程本身不足以决定极限**，`F_b` 是满足条件的凹不动点中**最大**的；
   在凹性下，`G = F_b ⟺ G(b−1) = b`（§3）。所以「极限是 `F_b`」等价于
   **一个数** `g_s → 0`。

6. **[数] η 以上同一个极限**（§6）：`b = 1.5`（到 40 级）、`1.6`（到 24 级），
   四级用 Kneser 解、五级起用正则迭代。最大偏差同样落在 `z = b−1`，
   `g_s L_{s−1}` 单调升向 `log 2`，`b = 1.5` 的速率律差值 `0.036 → 0.006`（16 → 40 级）。
   **热带极限与 η 无关**：η 只是第 4 级的临界点，不是阶数极限的临界点。

7. **[证] 临界底数**（§7）。记 `C_s` 为第 `s` 级塔收敛的底数集合（`b_c(s) = sup C_s`）。
   对**任何**每级在 `[1, ∞)` 上递增的阶梯：
   - `C_s ⊂ C_{s+1}`（一旦有界，以后各级都有界），
   - `C_s ∩ [2, ∞) = ∅`（`b ≥ 2` 时每一级塔都发散——用整数超运算 `2[s]n` 从下面压住）。

   所以 `b_c(s)` 单调不减、`≤ 2`，**收敛**到某个 `b_∞ ≤ 2`。
   这把仓库原来的上界 `b_c8 < e` 改进到 `≤ 2`，且对一切阶梯成立。
   **`b_∞` 不普适 [数]**：种子阶梯里凹种子停在 `b_∞ < 2`（如 1.7305、1.8215），
   其余趋于 2。**「不越过 `1+z`」不是判据**：`b = 1.65 > b_c5` 时四级运算仍在
   `1+z` 之下，五级塔却发散。能用的是命题 D（§7）：`[1, 1/(2−b)]` 上的线性包络
   迫使下一级塔收敛，从而给出 `b_c(s+1)` 的下界。
   速率律闭式对数对每个 `b ∈ (1, 2)` 在足够高的级上满足这条包络，
   模型的 `b_∞ = 2` **[证]**。解析阶梯在 `b_c8` 以上还没有一级满足同一条包络，
   区间仍是 `[1.83976, 2]`。

对「`n` 能否延拓到复数」的含义见 §5。

## 2. 推导 [推]

### 2.1 两变量约化

`S_s(1) = b` 且 `U_s(w) = w(1 + O(w))`，而 `z ≥ 1` 时级数自变量 `|C_s λ_s^z| ≲ ε_s` 很小：

```
S_s(z) = p_s − ε_s λ_s^{z−1} (1 + O(ε_s)),     z ≥ 1,    ε_s = p_s − b.
```

下一级的不动点 `p_{s+1} = b + ε_{s+1}` 在 `z = p_{s+1} ≈ b > 1` 处，于是

```
(R1)  ε_{s+1} = ε_s (1 − λ_s^{β + ε_{s+1}})
(R2)  λ_{s+1} = ε_s λ_s^{β + ε_{s+1}} L_s          β = b − 1
```

### 2.2 Koenigs 级数的闭式

同样的线性化给出 `T_{s+1}(p+t) − p = κ(1 − e^{−L_s t})`，`κ = λ_{s+1}/L_s`。
Schröder 方程 `U(λσ) = T(p + U(σ)) − p` 在 `λ → 0` 时的解是

```
U(σ) = −(1/L) log(1 − L σ)       （代入：左边 = λσ + O(λ²σ²L)，右边 = λσ）
```

即 `u_k ≈ L^{k−1}/k`。实测（`b=1.3, s=48`）：`u₂ = 4.941` 对 `L/2 = 4.94…`，
`u₃ = 32.55` 对 `L²/3 = 32.7`。这一步是整篇的关键：**系数随 `L` 增长，
级数的非线性在 `|w| ~ 1/L` 处不消失**——这就是 §0 第 4 条那个 `log 2` 的来源。

### 2.3 softmin

把闭式代入 `S_s(z) = p_s + U_s(C_s λ_s^z)`，用 `S_s(0) = 1` 定 `C_s`、
`p_s → b`、`L_{s−1} ≈ L_s`：

```
S_s(z) ≈ b − (1/L) log(1 + e^{L (b−1−z)}) = −(1/L) log(e^{−L(1+z)} + e^{−L b}).
```

在转折点 `z = b−1`：`S = b − log 2 / L`，即 §0 第 4 条。

### 2.4 速率律

令 `q = λ^β`。(R2) 在准平衡下给出 `ε = β q^{1/β−1}/|log q|`；(R1) 给出
`Δ log ε = −q`。连续化后 `(1−β) y' − y'/y = −e^{βy}`（`y = log λ`），
逐阶匹配 `q_s = a_s/s`：

```
a_s = (1/β − 1) + 1/log s + (1 + log(1/β − 1))/log² s + …
```

### 2.5 拐点的斜率 [证：对软化折线；数：对阶梯]

记 `β = b−1`，`Σ(z) = b − (1/L) log(1 + e^{L(β−z)})`。对 `z` 求导：

```
Σ'(z) = 1 / (1 + e^{L(z−β)}) = (1/2) (1 − tanh(L(z−β)/2)).
```

这与底数无关，温度 `1/L` 只负责把图像在拐点附近拉开。由此

```
Σ'(β) = 1/2,     Σ''(β) = −L/4,
Σ'(β+t) + Σ'(β−t) = 1,
b − Σ(β+t) = (b − t) − Σ(β−t).
```

最后一条是亏量的反射：拐点右边低于 `b` 多少，左边就低于直线 `1+z` 多少。
`Σ'(β+t) + Σ'(β−t) = 1` 是因为 `1/(1+e^u) + 1/(1+e^{−u}) = 1`。

阶梯取 `L = L_s = |log λ_s|`（[`demo_kink_slope.py`](demo_kink_slope.py)）。
`b = 1.3`：

| s | `S'(b−1)` | `(1/2 − S') L_s` | `−4 S''(b−1) / L_s` |
|---|---|---|---|
| 6 | 0.4027 | 0.286 | 1.123 |
| 12 | 0.4482 | 0.283 | 1.032 |
| 24 | 0.4722 | 0.215 | **1.013** |

第 24 级、三个底数的曲率比：`b = 1.2` 为 `1.0095`，`1.3` 为 `1.0127`，`1.4` 为 `1.0146`。
斜率本身按对数慢地走向 `1/2`（`b` 越大、`L_s` 越大，走得越快：第 24 级分别是
`0.460, 0.472, 0.482`）。斜率轮廓的误差从两翼先消失：`b = 1.3`、第 24 级，
`u = L_s(z−β) = −2` 处误差 `−5×10^{−4}`，拐点处仍有 `−0.028`。

### 2.6 同一个温度决定整列导数；整数阶并不特殊 [证：对软化折线；数：对阶梯与缺陷]

由 §2.5，`Σ'(z) = σ(L(z−β))`，`σ(u) = 1/(1+e^u)`。链式法则给出

```
Σ^{(n)}(β) = L^{n−1} σ^{(n−1)}(0).
```

`σ(u) − 1/2 = −(1/2) tanh(u/2)` 是奇函数，所以 `σ` 在 0 的二阶及以上偶阶导数为零。前四项是

```
σ(0) = 1/2,   σ'(0) = −1/4,   σ''(0) = 0,   σ'''(0) = 1/8,
```

因而 `Σ'''(β) = 0`，`Σ''''(β) = L^3/8`。

阶梯取 `L = L_s`（[`demo_kink_jet.py`](demo_kink_jet.py)）。`b = 1.3`，表中是 `S^{(n)}(b−1) / L_s^{n−1}`：

| s | 一阶（`1/2`） | 二阶（`−1/4`） | 三阶（`0`） | 四阶（`1/8`） |
|---|---|---|---|---|
| 12 | 0.4482 | −0.2580 | 0.0390 | 0.1203 |
| 16 | 0.4599 | −0.2553 | 0.0281 | 0.1230 |
| 24 | 0.4722 | −0.2532 | 0.0183 | 0.1246 |

四阶与 `1/8` 的比是 `0.962 → 0.984 → 0.997`。偶阶导数先贴上。斜率缺口 `0.028` 和三阶导数 `0.018` 是同一件事：转折点还在半斜率点右边 `u_0 = 0.145` 处（§2.7），逻辑斯蒂在那里的泰勒余项就是这两个数。

把 §2.4 的两项速率律原式用到实数和复数 `s`（主对数，`Re s > 1`），得到 `Σ_s`。后继缺陷

```
Δ(s) = max_{z ∈ [−0.5, 1.5]} |Σ_s(z+1) − Σ_{s−1}(Σ_s(z))|
```

底数 1.3：

| s | 速率律 | 温度冻结 `L(s) = L(s−1)` | `s + 1/2` |
|---|---|---|---|
| 8 | 0.0588 | 0.0160 | 0.0445 |
| 24 | 0.00162 | 0.000113 | 0.00153 |
| 96 | 7.3×10⁻⁵ | 5.2×10⁻⁷ | 7.2×10⁻⁵ |

半整数阶与整数阶同到百分之几。`s = 24 + it` 在 `t = 0, 1, 2, 5` 上是 `0.001616, 0.001612, 0.001598, 0.00151`。缺陷随 `Re s` 下降，不看 `s` 是不是整数。温度一旦冻结，缺陷就小一个数量级以上：折线是后继方程的精确解，单温软化几乎继承这一点，主要误差来自 `L(s) − L(s−1)`。这条误差的主项是 `log 2 · (L_s − L_{s−1}) / L_s²`，峰在 `z = b−2`（§2.9）。上面的网格从 `−0.5` 起，底数 1.3 的峰在 `−0.7`，所以表里的数比峰小。`s² Δ` 不收敛，主项是 `1/(s log² s)`。

这是软化族里的复数阶，不是阶梯本身的解析延拓。第 24 级软化误差是 `0.0122`（§1.1），后继缺陷 `0.00162` 比它细。

### 2.7 转折点还没落到半斜率点上 [证：对闭式对数；数：对阶梯]

§2.6 里离开逻辑斯蒂原点的那几项，来自闭式对数的半斜率点还在转折点左边。记 `M = L_{s−1}`，`λ = λ_s`，`C = C_s`，

```
Φ(z) = p_s − (1/M) log(1 − M C λ^z).
```

它的导数是被温度比拉开的逻辑斯蒂：

```
Φ'(z) = (L_s / M) · σ(L_s (z − z_{1/2})),     σ(u) = 1/(1 + e^u).
```

`z_{1/2}` 是斜率等于 `L_s/(2M)` 的点。`Φ(1) = b` 把它定死。令 `ε = p_s − b`，`β = b − 1`，转折点相对半斜率点的偏移是

```
u_0 = L_s (β − z_{1/2}) = −log(e^{M ε} − 1) + (b − 2) L_s.
```

*证.* 令 `A = −M C`。则 `Φ'(z) = (L_s/M) · (A λ^z)/(1 + A λ^z)`，半斜率点满足 `A λ^{z_{1/2}} = 1`，所以 `u_0 = −log(A λ^β)`。`Φ(1) = b` 给出 `A λ = e^{M ε} − 1`，因而 `A λ^β = (e^{M ε} − 1) λ^{β − 1}`。取对数即得。∎

右边两项都是几的量级，差是零点几。`b = 1.3`（[`demo_kink_next.py`](demo_kink_next.py)）：

| s | `−log(e^{Mε}−1)` | `(b−2)L_s` | `u_0` | `S'(b−1)` | `(L_s/M) σ(u_0)` | `\|S−Φ\|` |
|---|---|---|---|---|---|---|
| 8 | 3.3545 | −2.8367 | 0.5177 | 0.42540 | 0.42600 | 9.2×10⁻⁵ |
| 16 | 4.7116 | −4.4901 | 0.2216 | 0.45995 | 0.45996 | 1.7×10⁻⁶ |
| 24 | 5.5521 | −5.4071 | 0.1450 | 0.47217 | 0.47217 | 2.2×10⁻⁷ |

从第 12 级起，由 `C_s` 算出的 `u_0` 和由 `ε` 算出的 `u_0` 逐位相同。另两个底数在第 16 级：`b = 1.2` 时 `u_0 = 0.2927`，斜率 `0.44255` 对 `0.44255`；`b = 1.4` 时 `u_0 = 0.1645`，斜率 `0.47441` 对 `0.47446`。

所以转折点上的整列导数就是这条逻辑斯蒂在 `u_0` 的展开：

```
S^{(n)}(b−1) = (L_s / M) · L_s^{n−1} · σ^{(n−1)}(u_0).
```

`b = 1.3`、第 24 级，`n = 1…4`：阶梯给出 `0.47217`、`−0.25317`、`0.01832`、`0.12460`，公式给出同样四个数。§2.6 的表就是这一行。Koenigs 系数 `u_k · k / M^{k−1}` 对 `k = 2, 3, 4, 5` 是 `1.00001, 1.00001, 1.00002, 1.00002`，对数就是 Schröder 逆。

软化折线是同一公式取 `p → b`、`M → L_s`、`u_0 → 0`。`u_0 → 0` 已经含在 `g_s L_{s−1} → log 2` 里：

```
b − Φ(b−1) = (b − p_s) + (1/M) log(1 + e^{−u_0}).
```

速率律的主项把 `−log(e^{Mε}−1)` 中的 `a log s` 和 `(b−2)L_s` 消掉，`u_0` 是消完剩下的量。直接把两项律的 `ε` 代进去会跳过 `1/s` 这一项（第 24 级得到 `0.018`，阶梯是 `0.145`）。带着阶梯自己的 `ε` 往上走，`s u_0 → 1/(b−1)`（§2.8）。

### 2.8 偏移就是温度的一步 [证：在约化映射上；推+数：极限]

在 (R2) 下，§2.7 的 `u_0` 就是温度的前差，加上两项更小的修正。令 `x = L_{s−1} ε_s`。

```
u_0(s) = (L_{s+1} − L_s) − ε_{s+1} L_s + log(L_s / L_{s−1}) − log( (e^x − 1)/x ).
```

*证.* `−log(e^x − 1) = −log ε_s − log L_{s−1} − log((e^x−1)/x)`。
(R2) 写成 `L_{s+1} = −log ε_s + (β + ε_{s+1}) L_s − log L_s`，解出 `−log ε_s` 代入
`u_0 = −log(e^x−1) + (β−1) L_s`，`L_s` 的系数是 `−(β+ε_{s+1}) + (β−1) = −(1+ε_{s+1})`。∎

`ε_s L_s` 和 `log((e^x−1)/x) ∼ x/2` 都比 `1/s` 小：速率律给出 `ε_s ∼ s^{−a}/L_s`，而 `1 < b < η` 时 `a = (2−b)/(b−1) > 1`。`log(L_s/L_{s−1}) ∼ (L_s − L_{s−1})/L_s`。于是

```
u_0(s) ∼ L_{s+1} − L_s,     s (L_{s+1} − L_s) → 1/(b−1),
```

后一个极限是 `L_s ∼ log(s/a)/(b−1)` 的差分。修正 `log(L_s/L_{s−1})` 贡献 `1/log(s/a)`：

```
s u_0(s) = 1/(b−1) + 1/log(s/a) + o(1/log s).
```

阶梯本身到第 24 级（[`demo_u0_rate.py`](demo_u0_rate.py)）：

### 2.9 后继缺陷的主项是 `log 2` [证]

记 `u = N(β − w)`，`ψ(u) = log(1+e^u) − u e^u/(1+e^u)`。对温度求导：

```
∂Σ_N(w)/∂N = N^{−2} ψ(u).
```

`ψ'(u) = −u e^u/(1+e^u)²`，所以 `ψ` 在 `0` 取唯一最大值 `log 2`，并且 `ψ > 0`。

*证.* `∂/∂N` 作用在 `N^{−1} log(1+e^u)` 上，`u = N(β−w)` 也含 `N`。两项合并就是 `−N^{−2} ψ(u)`。`ψ'` 由商的求导得出，符号与 `−u` 相同。∎

后继缺陷 `Δ = Σ_L(z+1) − Σ_N(Σ_L(z))` 对 `N` 的导数是 `−N^{−2} ψ(N(β − Σ_L(z)))`。`ψ` 在内层落到转折点时取最大，那里

```
z = b − 2 + O(e^{−L}/L).
```

把 `N` 从 `L` 降到 `L − dL`，一阶项是 `log 2 · dL / L²`，二阶是 `O(dL²/L³)`，相对误差 `dL/L → 0`。同温（`N = L`）时折线是后继方程的精确解，软化只剩指数小项：`L = 8` 上最大 `4.2×10^{−5}`，`L = 16` 上最大 `7.0×10^{−9}`，都比 `e^{−L}` 小。

速率律 `L_s ∼ log(s/a)/(b−1)`，差分 `L_s − L_{s−1} ∼ 1/((b−1) s)`，于是峰高

```
Δ ∼ (b−1) log 2 / (s [log(s/a)]²).
```

底数 1.3，在 `z = b−2` 上实测与一阶项的比（[`demo_kink_jet.py`](demo_kink_jet.py)）：

| s | 24 | 48 | 100 | 500 |
|---|---|---|---|---|
| `Δ / (log 2 · dL / L²)` | 1.049 | 1.014 | 1.004 | 1.0004 |

§2.6 里 `s² Δ` 从 `0.93` 降到 `0.67`，是因为主项比 `1/s²` 大一个 `s/log² s`。那句「预因子还没稳住」撤回。这是软化族自己的后继缺陷，不是 §1.1 里阶梯对软化的距离。

### 2.10 离软化折线多远 [证：闭式对数；数：阶梯贴在上面]

§1.1 的 softmin 误差就是闭式对数与软化折线之差。令 `v = L_s (z − β)`，`M = L_{s−1}`，`ε = p_s − b`，`u_0` 如 §2.7。由 `A λ^z = e^{−(v+u_0)}`，

```
Φ(z) − Σ(z) = E(v) = ε + (1/L) log(1 + e^{−v}) − (1/M) log(1 + e^{−(v+u_0)}).
```

*峰的位置.* `E'(v) = −σ(v)/L + σ(v+u_0)/M`。`σ(v+u_0)/σ(v) = (1+e^v)/(1+e^{v+u_0})` 从 1 严格降到 `e^{−u_0}`。阶梯上 `L > M` 且 `e^{−u_0} < M/L`，所以恰好一个零点 `v_*`。`v → −∞` 时 `E → −∞`（因为 `1/M > 1/L`），`v → +∞` 时 `E → ε`，这个零点是最大值。

*高度.* 令 `κ = (L − M)/(u_0 L)`。`κ → 0` 时临界点处 `σ(v_*) → 1`，

```
max E = ε + (u_0 / L) (1 − κ − κ log(1/κ)) + o(u_0 / L).
```

`κ ∼ (b−1)/log(s/a) → 0`，而 `κ log(1/κ) → 0`。`a > 1`（也就是 `b < 3/2`，正则区 `b < η` 整个落在这里）时 `ε = o(u_0/L)`。再由 §2.8 的 `s u_0 → 1/(b−1)` 和 `L ∼ log(s/a)/(b−1)`，

```
max |Φ − Σ|  ∼  u_0 / L_s  ∼  1 / (s log(s/a)).
```

括号里的因子掉得很慢：第 24 级还在 `0.62`，所以 `s^{1.3}` 乘上第 16–48 级的误差几乎是常数。那是窗口，不是指数。

峰的横坐标 `z_* = β + v_*/L` 随 `κ → 0` 滑向转折点（`v_* ∼ log κ → −∞`，但除以 `L` 之后回到 `β`）。第 24 级、底数 1.3，`z_* = 0.036`。

*和折线的距离.* 软化折线满足

```
‖Σ − F_b‖_∞ = log 2 / L,
```

只在 `z = β` 取到：`z ≤ β` 时 `F − Σ = L^{−1} log(1 + e^{L(z−β)})`，`z ≥ β` 时 `F − Σ = L^{−1} log(1 + e^{L(β−z)})`，两边都 ≤ `log 2 / L`。转折点上

```
log 2 / L − (b − Φ(β)) = E(0) = O(u_0 / L) = o(1/L).
```

`Φ` 在 `−∞` 的斜率是 `L/M ≠ 1`，所以这个范数是在固定的紧区间上取的：那里 `‖Φ − F_b‖ = (log 2)/L · (1 + o(1))`。

*阶梯.* 模型映射 `t ↦ (λ/L)(1 − e^{−L t})` 的 Koenigs 逆满足 `u_2 = (L/2)/(1 − λ)`，`λ → 0` 时收到 `L/2` **[证]**。阶梯的系数更贴：第 24 级 `u_k k / M^{k−1} = 1.00001`（§2.7）。圆盘内 `|S − Φ|` 第 16 级是 `10^{−7}`。固定区间的左端还有一条 `O(1/(s log s))` 的尾巴，比转折点缺口 `log 2 / L` 小，并且在变小（底数 1.3，`[−1, 2]` 上 `|S − Φ|` 从第 8 级的 `0.030` 降到第 20 级的 `0.005`）。因此在 §1.1 的网格上，阶梯离折线的距离就是 `log 2 / L_s` 加上这一项。

三个底数上 `E(v_*)` 与网格上的 `max(Φ − Σ)` 前四位相同（[`demo_tracking_error.py`](demo_tracking_error.py)）。底数 1.3：

| s | `max(Φ−Σ)` | `E(v_*)` | `1 − κ − κ log(1/κ)` 那行 | `log 2 / L` |
|---|---|---|---|---|
| 8 | 0.06361 | 0.06368 | 0.06327 | 0.171 |
| 16 | 0.02122 | 0.02123 | 0.02108 | 0.108 |
| 24 | 0.01222 | 0.01223 | 0.01217 | 0.0897 |

第 24 级缺口 `g_s = 0.0816`，而 `log 2 / L − g_s = 0.0081`，等于 `E` 在 `v = 0` 的值。softmin 误差吃掉的就是这一截，不改变主项 `log 2 / L_s`。

## 3. 不动点方程不决定极限 [证]

**命题 A.** `F_b(z) = min(1+z, b)` 满足 `F(z+1) = F(F(z))`、`F(0) = 1`、`F(1) = b`。

*证.* `F(F(z)) = min(1 + min(1+z, b), b) = min(2+z, 1+b, b) = min(2+z, b) = F(z+1)`。∎

**命题 B.** 设 `G` 在 `[−1, ∞)` 上凹、不减，`G(−1) = 0`、`G(0) = 1`、`sup G = b`。则

1. `G ≤ F_b` 于 `[0, ∞)`，`G ≥ F_b` 于 `[−1, 0]`；
2. `G = F_b`（于 `[−1, ∞)`）当且仅当 `G(b−1) = b`。

*证.* (1) 凹函数在弦 `[−1, 0]`（斜率 1）之外位于其延长线下方、之内位于其上方：
`z ≥ 0` 时 `G(z) ≤ 1+z`，`z ∈ [−1,0]` 时 `G(z) ≥ 1+z = F_b(z)`；再加 `G ≤ sup G = b`。
(2) 若 `G(b−1) = b`：弦 `[−1, 0]` 与弦 `[0, b−1]` 的斜率都是 1，凹函数相邻两弦斜率相等
⟹ 它在 `[−1, b−1]` 上是直线 `1+z`；`z ≥ b−1` 时由不减，`b = G(b−1) ≤ G(z) ≤ b`。
反向显然。∎

**命题 C（满足方程的凹不动点有一整族）.** 设 `h` 在 `[0, 1]` 上凹、不减，
`h(0) = 1`、`h(1) = b`、`h(z) ≤ 1 + z`。令

```
G_h(z) = 1 + z   (z ≤ 0),      h(z)   (0 ≤ z ≤ 1),      b   (z ≥ 1).
```

则 `G_h` 凹、不减，满足 `G(z+1) = G(G(z))`、`G(0) = 1`、`G(1) = b`、`sup G = b`。

*证.* 凹：三段在接点处斜率不增（`1 ≥ h'(0+)` 由 `h ≤ 1+z`，`h'(1−) ≥ 0 `）。
方程：`z ≤ −1`：两边都是 `2+z`；`z ∈ [−1, 0]`：`G(z) = 1+z`，两边都是 `G(1+z)`；
`z ≥ 0`：`G(z) ∈ [1, b]`，故 `G(G(z)) = b = G(z+1)`。∎

`h` 可取弦 `1 + (b−1)z` 与 `min(1+z, b)` 之间的任何凹函数；**`F_b` 是这一族的上包络**
（`h = min(1+z, b)`），下包络是 `h = 1+(b−1)z`。所以单靠 `Σ` 的不动点方程、规范化与凹性，
**选不出**极限——阶梯选中的是上包络，由命题 B，判定它的恰好是转折点上的一个数
`g_s = b − S_s(b−1) → 0`（§1.1 的最后一列）。

**软化折线收到 `F_b` [证].** `ψ` 同 §2.9。`∂Σ/∂L = L^{−2} ψ(L(β−z)) > 0`，
所以 `L` 增大时 `Σ` 逐点上升。又

```
Σ(z) = −(1/L) log( e^{−L(1+z)} + e^{−L b} ) ≤ min(1+z, b) = F_b,
```

因为两个指数之和至少是较大的那个。转折点缺口恰是 `log 2 / L → 0`。单调、有上界、缺口消失，极限是 `F_b`。

**阶梯上还差一步.** 速率律给出 `ε_s → 0`，所以不动点 `p_s → b` [推]。闭式对数在转折点的缺口

```
b − Φ(β) = −ε_s + (1/M) log(1 + e^{−u_0})
```

在 `u_0 = O(1/s)`（§2.8）时趋于 `log 2 / M → 0` [推]。阶梯的 `g_s` 与它只差 `|S − Φ|`，第 24 级是 `2.2×10^{−7}`（§2.7）。整段 `S_s → F_b` 还差 `‖S_s − Σ‖ → 0`：§1.1 第 48 级软化误差 `0.00506`，离折线 `0.0665`。凹性缺陷是同一件事，`Σ'' ≤ 0`。

## 4. 与已有工作的关系

- **Nixon**（arXiv:1503.07555、2106.03935）：逐级构造了这条链，**没有讨论 `n → ∞`**。
- **Rubtsov–Romerio "omegation"**（Tetration Forum 附件 aid=222，§5）：形式上定义
  `a[ω]n = lim_s a[s]n`，只在**整数** `n` 上讨论（`a[ω]0 = 1`、`a[ω]1 = a`、`2[ω]2 = 4`）。
  `F_b` 在整数点上与之相容（`F_b(0)=1`，`F_b(n)=b`，`n≥1`），但连续高度上的极限、
  转折点、softmin 结构、速率——**在已查到的资料里没有出现**。
  ⚠ 这是「未查到」，不是「不存在」。
- **Maslov 去量子化 / 热带几何**：`−ħ log(e^{−x/ħ} + e^{−y/ħ}) → min(x, y)` 是标准的；
  新的只是**它从超运算阶梯里自动长出来**，而且 `ħ` 由阶数给定：`ħ_s = 1/|log λ_s|`。

## 5. 对「`n` 能否延拓到复数」的含义

1. **在阶数上做 Koenigs 走不通**（[essay-rank-1000-zh.md](essay-rank-1000-zh.md)
   第二轮的结论仍然成立，但理由要改写）：后继算子 `Σ` 的这个不动点 `F_b` 不解析
   （转折点处不可微），逼近是**对数**慢的（转折点上 `~ 1/log s`），没有乘子。
   这比抛物型（`~ 1/s`）还退化。
2. **但主阶有一个天然的复化**：到主阶，阶数**只通过一个数** `ħ_s = 1/|log λ_s|` 进入，
   而 `ħ(s) = (b−1)/(log s − log a − …)` 对 `s` 是解析的。于是
   ```
   b[s]z  ≈  −ħ(s) · log( e^{−(1+z)/ħ(s)} + e^{−b/ħ(s)} ),       s ∈ ℂ
   ```
   是一个**渐近意义上**的复数阶超运算——像 Stirling 级数之于 Γ。
   它**不唯一**。软化族自己的后继缺陷已经是 §2.9 的 `1/(s log² s)`；
   阶梯相对这条主阶的距离是 §2.10 的 `u_0/L_s ∼ 1/(s log(s/a))`。这条候选在后继方程上自洽到
   比它离阶梯的距离更细的尺度，而且 `s+1/2` 与 `s+it`（`|t| ≤ 5`）的缺陷与整数阶同量级（§2.6）。
   它给任何候选构造加了一条新的硬判据：
   > **C6**（`1 < b < η`；由第 3 条推广到 `1 < b < b_∞`）：`s → ∞` 时 `b[s]z` 必须热带化到 `min(1+z, b)`，
   > 且 `b[s](b−1) = b − log 2 · ħ(s) + o(ħ)`。
3. **η 以上**：只要 `b ∈ C_s`（§7）对某个 `s` 成立，从那一级起整条阶梯就是正则的，
   C6 照样适用（§6 在 `b = 1.5, 1.6` 上验证）。所以 C6 的适用范围是 `1 < b < b_∞`，
   不只是 `1 < b < η`。**`b ≥ 2`（含底数 e）**每一级塔都发散（§7 引理 2），
   没有可供正则迭代的吸引实不动点；有界的极限在那里根本不存在：
   `b[s]3 ≥ 2[s]3 = 2[s−1]4 → ∞`。

## 7. 临界底数 `b_c(s)`

记第 `s` 级塔为 `u_0 = 1, u_{k+1} = S_{s−1}(u_k)`（即 `u_k = S_s(k)`），
`C_s` 为它收敛的底数集合，`b_c(s) = sup C_s`。仓库已有：
`b_c4 = η = 1.44467`、`b_c5 = 1.63532`、`b_c6 = 1.73736`、`b_c7 = 1.79912`
（[hyperoperation-program-zh.md](hyperoperation-program-zh.md) §4.11–4.17）。

下面的「阶梯」指任何一族在 `[1, ∞)` 上递增的实函数 `S_3(x) = b^x, S_4, S_5, …`，
满足 `S_s(0) = 1`、`S_s(z+1) = S_{s−1}(S_s(z))`。**不依赖分数高度怎么延拓**。

**引理 1 [证]（一旦有界，永远有界）.** `C_s ⊂ C_{s+1}`。

*证.* `b ∈ C_s`：`S_s(k) = u_k ↑ p`（`u_1 = b > 1 = u_0` 且 `S_{s−1}` 递增 ⟹ `u` 递增）。
`S_s` 递增 ⟹ 对 `z ≥ 0`，`S_s(z) ≤ S_s(⌈z⌉) < p`。第 `s+1` 级塔 `v_{k+1} = S_s(v_k)`
从 `v_0 = 1` 出发递增（`v_1 = b > 1`）且 `< p`，故收敛。∎

**引理 2 [证]（底数 2 是硬墙）.** `b ≥ 2` ⟹ 对一切整数 `n ≥ 0`、`s ≥ 3`，
`S_s(n) ≥ 2[s]n`（右边是整数超运算）。特别地 `C_s ∩ [2, ∞) = ∅`。

*证.* 对 `s` 归纳。`s = 3`：`b^n ≥ 2^n`。设对 `s−1` 成立。令 `w_k = 2[s]k`（整数，
`w_{k+1} = 2[s−1]w_k`），对 `k` 归纳证 `S_s(k) ≥ w_k`：`k = 0` 两边为 1；
`S_s(k+1) = S_{s−1}(S_s(k)) ≥ S_{s−1}(w_k) ≥ 2[s−1]w_k = w_{k+1}`
（第一个 `≥` 用 `S_{s−1}` 递增，第二个用 `s−1` 的归纳假设——`w_k` 是整数）。
`2[s]k` 对 `k` 无界（`1, 2, 4, 2[s−1]4, …` 严格递增），故第 `s+1` 级塔发散。∎

`b = 2` 时塔的前几项就是整数超运算（`1, 2, 4, 2[s]4, …`）——
`tests/test_rank_above_eta.py` 对 `s = 4…8` 逐项核过。

**推论 [证].** `b_c(s)` 单调不减、`≤ 2`，收敛到 `b_∞ ∈ [1.83976, 2]`。
（若 `C_s` 是区间 `(1, b_c(s))`——数值上如此——则 `b < b_c(s)` 与收敛等价。）

**`b_∞` 不是普适的 [数]——种子阶梯的二分.** 为了在 7 级以上检验 `b_∞`，取最粗的阶梯：
每级 `s ≥ 4` 在 `(−1, 0]` 上取同一个递增种子 `σ`（`σ(−1)=0, σ(0)=1`），其余由递推定。
它满足两条引理的全部假设，`b_c(s)` 可以算到 22 级
（[`demo_critical_bases_seeded.py`](demo_critical_bases_seeded.py)，

**命题 D [证]（包络陷阱）.** 设 `f` 在 `[0, L]` 上不减，`f(1) = b ∈ (1, 2)`，
`L = 1/(2−b)`，并且

```
f(x) ≤ 1 + (b−1) x     对一切 x ∈ [1, L].
```

则轨道 `1, f(1), f(f(1)), …` 收敛到 `[b, L]` 里的不动点。因此
`b ≤ b_c`（下一级塔的临界底数）。斜率不增（二阶差分 `≤ 0`）加上 `f(0) = 1`
推出这条包络，因为 `(f(1)−f(0))/1 ≥ (f(x)−f(1))/(x−1)`。

*证.* `x ≥ 1` 时 `f(x) ≤ 1+(b−1)x`。`x ≥ L` 时右边 `≤ x`，故 `f(L) ≤ L`。
`f` 不减且 `f(1) = b`，所以 `x ∈ [1, L]` 时 `b ≤ f(x) ≤ L`。轨道从 `u_1 = b` 起
不减、不超过 `L`，收敛到不动点。`b ∈ (1, 2)` 时 `L ≥ b`，因为
`(b−1)^2 ≥ 0`。∎

这是充分条件，不是必要的。线性种子在 `(0,1]` 上凸，仍然 `b_∞ = 2`；
四级运算在 `b = 1.63`（还没到 `b_c5`）已经有 `0.002` 的包络超出，塔仍收敛。
充分条件离临界值很近：包络在 `b ≤ 1.62` 成立（`L = 2.63`），
`b_c5 = 1.6353`，差 `0.015`。

**速率律模型的 `b_∞` 是 2 [证].** 主项 `q_s = a/s`，`a = (2−b)/(b−1)`，
`L_s = log(s/a)/(b−1)`，`ε_s = q_s^a / L_s`，`M = L_{s−1}`，`λ = e^{−L_s}`。令

```
Φ(z) = b + ε_s − (1/M) log(1 + A λ^z),     A = (e^{M ε_s} − 1)/λ.
```

则 `Φ(1) = b`。`λ^z` 随 `z` 下降，所以 `Φ' > 0` 且 `Φ'' < 0`。斜率

```
Φ'(1) = (L_s / M) (1 − e^{−M ε_s}) ∼ (a/s)^a → 0.
```

一旦 `Φ'(1) ≤ b−1`，凹性给出 `x ≥ 1` 时
`Φ(x) ≤ b + Φ'(1)(x−1) ≤ 1 + (b−1)x`。这正是命题 D 在 `[1, 1/(2−b)]` 上要的包络，
塔收敛。每个固定的 `b ∈ (1, 2)` 都有足够大的 `s` 使斜率落到 `b−1` 下面
（`b = 1.99`、`s = 20`：斜率 `0.6056 < 0.99`，`[1, 100]` 上包络超出为 0；
`b` 越接近 2，`(a/s)^a = s^{−a}` 掉得越慢，但 `a > 0` 时仍然趋于 0）。
所以这条模型的 `b_∞ = 2`。它不是精确的后继阶梯：相邻两级的缺陷是 §2.9 那个 `1/(s log² s)`。

凹种子的斜率不落到 `b−1` 下面，`b_∞` 可以停在 2 下面。解析阶梯在 `η` 以下的 `(ε, λ)` 就是这套参数，包络在那里成立，但那边的塔本来就收敛。要在 `b_c8` 以上得到同一个 2，需要某一级真实的 `S_s` 满足 `Φ'(1) ≤ b−1`。七级运算在 `b = 1.845` 已经冲出包络。解析 `b_∞` 仍是区间 `[1.83976, 2]`。
