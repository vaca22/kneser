## 1. 生成元 V:流的速度场(问题 1.1 / 1.2 / 1.3)

定义 `V(x) = sexp'(slog(x))`,即 `d/dt E_t(x)|_{t=0}`。三条恒等式在
50 位精度下验证:

```
V(e^x) = e^x V(x)                 max 残差 7.5e-60   (x in [-2,2])
V(f(x)) = f'(x) V(x), f=half_exp  max 残差 2.0e-52
slog'(x) = 1/V(x)  即  slog(y)-slog(x) = ∫_x^y dt/V(t)
```

第三条是关键换位:**Abel 坐标就是把流走成匀速的时钟**,`slog` 是
`1/V` 的原函数。由此 `half_exp` 完全等价于"自治常微分方程
`x' = V(x)` 的 1/2 时刻流映射":解 `∫_1^y dt/V = 1/2` 得
`y = 1.6463542337511945809...`,与 `sexp(1/2)` 相差 2.7e-68(求积误差)。
这回答了问题 1.2。

### 1.1 新常数:流的最慢点

`V(e^x) = e^x V(x)` 在 `x=0` 处给出 `V(1) = V(0) = sexp'(0)`,
于是 Rolle 保证 (0,1) 内有临界点;数值上它是全局最小值,
也是 `sexp''` 的零点(因为 `V'(x) = sexp''(slog x)/V(x)`):

```
a* = slog(x*) = -0.52176479262332215534002809319448765236548708857447...
x* = sexp(a*) =  0.47774309476666623517566409504934474038996334686727...
V_min = V(x*) =  0.95652179752806394866637489488337260693185792059977...
```

指数流在 `x* ≈ 0.4777` 处走得最慢(慢于单位速度约 4.3%),向两侧
单调加速。完整 80 位值见 `demo_constants_pslq.py --coeffs` 输出。

### 1.2 渐近与凸性

- 左端:`V(x) = V(e^x)/e^x → V(0)·e^{-x}`(由恒等式直接得出;
  `x=-20` 时 `V(x)e^x` 与 `V(0)` 已合到 9 位)。
- 右端:`V(x) = x·V(log x)` 展开为 `x · log x · loglog x ···`
  直到核心区间,数值检查为精确恒等(check = 1.0)。
- 第一轮二阶差分在 `[-4,8]` 为正;扩域实验改用 `S',S'',S'''` 的解析
  链式法则和 `V''(x)=(V'(log x)+V''(log x))/x`,在非均匀 840 点
  `[-100,10^100]` 上仍无非正值。扫描本身不是证明。
- 第二轮命题 V1 把凸性归约为 `φ=log S'` 的对数凸性。
  `docs/certify_phi_log_convex.py` 对已发布级数证明
  `(log S')'' > 0` 于 `(-2, +∞)`,因而 `V'' > 0` 于 `ℝ`,并且 `x* < 1/2`。

### 1.3 度量畸变(问题 1.3 的答案)

由 `E_t(x) = sexp(slog(x)+t)` 求导:

```
∂E_t/∂x = V(E_t(x)) / V(x)
```

即**流的局部拉伸因子是速度比**。数值表(x=1):t=1 时拉伸 = e(精确),
t=2 时 41.1935...,t=-1/2 时 0.87633613...= f'(1)·的对应值,均与
`V(E_t)/V(x)` 逐位一致。"Abel 坐标中平凡的平移,拉回后畸变如何"
就此有了闭式答案。

## 2. 运算路径 +_t(问题 2.1 / 2.2,猜想 B)

约定 `x, y > 0`、`t ∈ [0,1]`(此域内 `E_{-t}`、外层 `E_t` 全有定义)。

### 2.1 端点斜率公式

```
d/dt (x +_t y) |_{t=0} = V(x+y) - V(x) - V(y)
d/dt (x +_t y) |_{t=1} = xy · [ V(log xy) - V(log x) - V(log y) ]
```

(推导:对 `E_t(E_{-t}x + E_{-t}y)` 在端点求导,用 `d/dt E_t = V(E_t)`
与 `∂E_t/∂x = V(E_t)/V(x)`。)六对 `(x,y)` 上与数值导数一致到 8 位。
于是**非单调性变成 V 的次可加/超可加符号判据**——猜想 B 从"画曲线"
升级为"查符号"。

### 2.2 猜想 B:支持并精化

7×7 正数网格(0.25 ... 5)上 28 对中 **16 对非单调**。代表性数据:

```
2 +_t 3:  5 → 6.2929522915 (t*=0.7488) → 6      超出乘积 0.293
2 +_t 2:  4 → 4.5232 (t≈0.62) → 4               两端相等,内部强迫极值
```

形态由端点斜率符号对 `(sign s0, sign s1)` 分类:`(+,-)` 上凸越顶
(2+3 型)、`(-,+)` 下凹穿底(0.5+0.5 型)、同号则可单调。
单调的 12 对集中在"两端点差距悬殊"的区域((0.25,5)、(5,5) 等)。
猜想 B 的精确化候选:**非单调 ⟺ `s0` 或 `s1` 与
`W_1-W_0=xy-(x+y)` 异号**(`W_1=W_0` 另行处理)。旧稿“`s1` 同号”
与显示的导数公式及 `(2,3)` 都矛盾,是符号笔误。16 点扩展网格的 136 个
无序对、97 个 t 层上全部吻合。强形式在 `q ∈ [1e-4, 24]`(p 任意)上是定理:见
[lemmas-round2-zh.md](lemmas-round2-zh.md) 的端点斜率分类,证书
`docs/certify_strong_b.py`。

### 2.3 D_t 的符号结构(问题 2.1)

`D_{1/2}(x,y) = x +_{1/2} y - xy` 在网格上的符号:

```
        0.25  0.5   1   1.5   2    3    5
 0.25    -    +    +    +    +    +    +
 0.5     +    +    +    +    +    +    +
 1       +    +    +    +    +    +    +
 1.5     +    +    +    +    +    +    +
 2       +    +    +    +    +    -    -      (2,5) 为 -
 3       +    +    +    +    -    -    -
 5       +    +    +    -    -    -    -
```

半级运算在一个含对角中段的区域**高于乘法**,在原点角与大数角
**低于乘法**。这张符号图现在是定理:每个 `t ∈ (0, 1)` 上,
`D_t = 0` 恰好是两条严格递减的对合。小支连接 `(0, S(t-1))` 和
`(S(t-1), 0)`,大支连接 `(1, ∞)` 和 `(∞, 1)`,中间
`x ∈ [S(t-1), 1]` 恒有 `D_t > 0`。小支在原点端是线性渐近,大支在
`x → ∞` 时 `y - 1 ∼ S(-t) V(log x) / V(E_{-t} x)`。证明见
[lemmas-round2-zh.md](lemmas-round2-zh.md)。§6.1 的切片只是这一定理的图示。
相对加法的符号则沿"`x+y` vs 距离曲线"翻转(见 demo 输出第二表)。

### 2.4 单位元与逆元路径(问题 2.2 的答案)

`0_t = E_t(0) = sexp(t-1)` 正是 0 的流轨道:数值速度与 `V(0_t)`
逐位一致。携带的几何信息:

- 中点 `0_{1/2} = sexp(-1/2) = 0.49856328794111443...`(略小于 1/2);
- 路径最慢点在 `t = 1 + a* = 0.47823520737667...`,速度 `V_min`
  ——单位元路径直接看见了 §1.1 的新常数;
- 2 的逆元路径 `-_t 2` 从 -2 连续走到 1/2,在
  `t0 = 0.6553419477268455...` 处穿过 0。

## 3. 复时间(问题 3.1–3.4,猜想 C)

### 3.1 构造与校准

复 `sexp` 用与构建器相同的两套件实现(见 `demo_complex_time.py`):
带内(|Im z| < 1/2)纯 Taylor 级数 + 函数方程;带上
(Im z ≥ 1/2)`superf(z + theta(z))`(不动点 `L` 处 Koenigs 超函数
+ 由现成级数一次拟合的 192 个衰减 Fourier 模)。两条**独立求值路径**
在重叠带一致:

```
Im z = 0.6:  max 差 2.9e-52      Im z = 1.2:  5.0e-32
Im z = 0.9:  max 差 9.1e-48      Im z = 1.4:  4.4e-23   (级数半径边缘)
函数方程残差:Im z = 2/5/10/20 处 3e-53 / 8.5e-57 / 1.3e-62 / 2.1e-64
```

### 3.2 猜想 C:数值确认到 15 位

精确化:`e^L = L` 蕴含 `log L = L`(`ln|L| = Re L`,`arg L = Im L`),
故 Koenigs 坐标下一单位虚时间乘以 `e^{iL}`,预言

```
角速度 → Re L = 0.3181315052047641...  rad / 单位 t
收缩率 → Im L = 1.3372357014306894...  e-folds / 单位 t
卷绕周期 2π/Re L = 19.7502768647...
```

实测(x = 0, 1, 2 三条轨道,t ∈ [25,40] 尾段拟合):

```
x=0:  d arg/dt = 0.31813150520476420   -d log r/dt = 1.3372357014306893
x=1:  d arg/dt = 0.31813150520476433   -d log r/dt = 1.3372357014306895
x=2:  d arg/dt = 0.31813150520476423   -d log r/dt = 1.3372357014306896
```

**与 (Re L, Im L) 吻合 15–16 位,且与起点无关。** 局部速率从真正
非渐近的早期值收敛过来(x=0 在 t=1 处角速度仅 0.114):轨道是
"进入"渐近域,不是公式同义反复;两条独立求值路径的一致性(上表)
排除了仪器偏置。猜想 C 对**这一个解**已在第二轮用 Koenigs 展开 +
theta 模衰减写成命题 C;本节和 §6.1 的数值贡献只是校准“多快进入”和
二阶余项,不是该命题的证明。

### 3.3 轨道形态(问题 3.1)与奇点(问题 3.2)

- 三条轨道的辐角自 t ≈ 0.1–0.6 起严格单调递增、半径单调下降:
  **无自交的简单内旋螺线**;40 单位虚时间内绕 L 约 1.95–2.13 圈
  (预言 2.025 圈,差异来自初始相位段)。
- `E_tau(x)` 在 tau 平面的奇异集只有实射线 `tau ≤ -2 - slog(x)`
  (Kneser 解全纯域 `C \ (-∞,-2]` 的平移);沿射线逼近时对数发散
  (-2.24 → -4.52 → -6.82,每次 ×10 靠近),离开射线 0.05i 即光滑。

### 3.4 复时间不变量(问题 3.4,命题+数值校准)

第二轮命题 C 给出不变量:

```
I(x) = lim_{t→∞} d/dt log( E_{it}(x) - L ) = iL        对所有实 x
```

它把不动点本身变成轨道的可测量。区分力的来源:此极限存在要求解在
上半平面全纯并收敛到 L——这正是 Trappmann–Kouznetsov 唯一性所拣选的
性质;非 Kneser 的 `C^∞` 分数迭代解根本不提供全纯虚时间流。
证明与适用条件见 [lemmas-round2-zh.md](lemmas-round2-zh.md);有限窗口
斜率拟合只作独立数值校准。

## 4. 无限复合方程(问题 4.2 / 4.4)

### 4.1 Carleman 截断开方(问题 4.2,实验回答)

`M_exp` 的 n 阶截断取主支矩阵平方根,第 1 行作为 `exp^[1/2]` 的
Taylor 行,对照本仓库 Kneser 值:

```
  n   算术    |f(0)-ref|   |f(0.5)-ref|   |f(1)-ref|   cond(V)
  8   f64      8.8e-05       2.3e-05       8.1e-05     7.3e+01
 16   f64      8.5e-06       5.9e-06       2.1e-06     9.5e+03
 24   f64      1.6e-06       1.8e-06       4.9e-07     2.7e+04
 28   f64      4.9e-07       9.2e-07       1.0e-06     7.2e+04
 32   f64      5.6e-06       3.3e-06       1.3e-05     2.3e+05   ← 回弹
  8/12/16 mp40 与 f64 逐位相同 → n≤16 误差纯属截断
```

三个结论:

1. **主支选择自动落在 Kneser 解上**(Taylor 系数 a0/a1/a2 同步逼近
   Kneser 值)——"分支选择反映唯一性条件"获得第一份实验证据;
2. 收敛只有**代数阶**(粗略 ~n^-3 至 n^-4),与 theta 迭代的
   指数收敛(每轮 ~1.4 位)形成数量级对比;
3. float64 特征基条件数在 n≈28 后反噬,**截断 Carleman 路线有
   精度天花板**;高精度算术可以推迟但成本陡峭。

识别定理:若主支截断局部一致收敛到实解析且导数为正的 `f`,则由
Trappmann–Kouznetsov (2010) 的唯一性,`f` 就是 Kneser 半迭代。
对 `n` 一致的速率没有证明;观测到的是 `n ≤ 24` 上大约 `n^{-3}` 到
`n^{-4}`,float64 特征基在 `n ≈ 28–32` 条件数炸掉。

### 4.2 theta 迭代收缩率(问题 4.4,测量 + 模型排除)

变动单参数重跑构建器(digits=24,carleman 种子),清洁段拟合:

```
δ (采样高度)   0.05    0.10    0.20    0.30
位/轮          1.606   1.481   1.305   1.196   (±0.01-0.02)
digits=36, δ=0.1:   1.477 位/轮(与目标位数无关)
digits=80, δ=0.1:   1.413 位/轮(loop0→20 平均,baked 种子)
```

排除:常数 `e^-π`(=1.364,但实测随 δ 移动);纯采样高度模型
`e^-2πδ`(=0.273 位,差一个量级);带宽占比模型(0.7–1.5 位但
δ 依赖方向错)。四点拟合 `κ(δ) ≈ 0.017 + δ/(2π)` 是实的。
`1/(2π)` 对上的是单界面转角 `d(arcsin δ)/(2π dδ)|_0`,不是 Poisson 核:
`r=1/2`、`φ=0` 的核等于 `3`,给出 `3/(2π) ≈ 0.477`。调和测度斜率
`10/(3π)` 也不对。理想 theta 线性化的谱半径大约过收缩一百倍
(`δ=0.05/0.10/0.20/0.30` 时约 `3e-5/3e-4/2.7e-3/9e-3`,对照
`κ ≈ 0.025/0.033/0.050/0.064`)。地板 `0.017` 是被省略的 theta 模。

副产品:depth×2 而 dps 不变的组在 1e-13 停滞——`isuperf` 的
`(w-L)` 相消每单位 depth 损失 0.138 位,正是 `plan()` 标定律的
直接演示。

### 5.1 常数族(80 位,摘录前 50 位)

## 6.1 工作包 K–R:四个开放方向的可复现实验

以下均为本次实际运行结果。V、D 与复时间的数据是**声明有限域/时间窗内的
数值证据**;`Fraction` 复合等式是在所报有限截断环中的精确等式。它们不推出
全实轴凸性、端点判据充要性、统一渐近常数或一般 `f∘f=g` 理论。

### V:解析导数扩域扫描

`demo_v_convexity_extended.py` 用 `S` 的三阶解析导数计算 `V''`,尾部用
微分后的 `V(e^x)=e^xV(x)` 递推。非均匀 840 点覆盖
`x∈[-100,10^100]`:未见 `V''≤0`;采样最小值
`1.14685777945177869e-99` 出现在右端 `x=10^100`。微分递推最大相对残差
`5.499e-68`;`V'` 仅在 `[0.25,0.5]` 出现一次符号变化,细化根
`x=0.477743094766666235175664095049`,该点 `V''=1.0807638429477913`。
最小值落在声明域端点,尤其不能读成全局下界。

### D_t:端点判据与半级零切片

16 点 `x,y∈[0.1,12]` 的 136 个无序对、`t=j/96` 上,端点候选与采样斜率
分类吻合 `136/136`,两者都判出 67 对非单调。端点分类本身在
`q ∈ [1e-4, 24]` 上已是定理;这张网格只是图示。`D_1≡0` 只作端点校准
(浮点最大残差 `2.132e-14`)。`D_t = 0` 的两条曲线也已是定理
([lemmas-round2-zh.md](lemmas-round2-zh.md))。下面的 `D_(1/2)=0` 切片
分别落在小支、间隙和大支上:


### 复时间:主项拟合后的二阶余项

quick 配置(`dps=90, depth=190, modes=80, nf=176`)先在 `t∈[13,17]`
同时拟合主项 `c e^{itL}` 和用于稳定 c 的 nuisance 二次项,再在不相交的
`t∈[5,10]` 上只扣除主项。路径校准:重叠求值最大差 `2.099e-27`,函数方程
最大残差 `2.064e-28`。余项对数斜率:

```

x=1: 2.67447351750280638   距 2 Im L 为 2.11464e-6

```

按 `Im L` 去指数后的包络跨度约 `800.6/801.2`,按 `2 Im L` 去指数后仅
`1.00084/1.00018`;有限窗口明显选择二倍模型。这支持命题 C 的二阶率,
但不是统一误差界的证明。

### f∘f=g:两个最小校准族

`g(x)=(9/4)x` 的主实支精确为 `f(x)=(3/2)x`,模 `x^25` 复合检查通过。
`g(x)=e^x-1` 复用 `demo_infinite_system.py` 的 exact `Fraction` 复合递推,
在 `f(0)=0,f'(0)=1` 分支上精确验证
`f(f(x))=e^x-1 (mod x^25)`。前六项为
`1, 1/4, 1/48, 0, 1/3840, -7/92160`;这只说明有限阶形式可解,不说明
级数收敛,更不说明一般 `g` 可解。

   这条零点的条数和轨道导数还没有收成定理。
3. `D_t` 在 `(0, 1)` 上的零点集是定理:小支 `x ∈ (0, S(t-1))` 和大支
   `x > 1` 各是一条严格递减的对合,间隙 `x ∈ [S(t-1), 1]` 上 `D_t > 0`。
   小支原点端的斜率、大支 `x → ∞` 与 `x → 1+` 的渐近,以及 `t → 0+` 时
   大支收到 `(x-1)(y-1) = 1`,都写在
   [lemmas-round2-zh.md](lemmas-round2-zh.md)。`demo_dt_zero_curve.py`
   只保留切片图示。
4. Carleman 主支若局部一致收敛到实解析且导数为正的 `f`,则 `f` 是

6. 100 位同协议 PSLQ 全部为空(§5.3)。`--digits 200` 没有跑:
   100 位用了 3512 秒,200 位是一天量级。
