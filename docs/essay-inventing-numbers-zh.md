# 发明数:从分母为零到泛性质

> 我主要是想发明很高级的数和结构,探索未知。初中的时候想发明一种
> 分母为 0 的数,高中又发明了运算之梯。
>
> 这是本系列的第三篇(前两篇:[《运算之梯》](essay-operation-ladder-zh.md)、
> [《无限方程组》](essay-infinite-systems-zh.md))。三个少年发明——
> 分母为零的数、更高级的运算、解无限方程组——其实是**同一个动作**:
> 把一个被禁止的运算强行合法化,然后看结构付出什么代价。
> 这个动作在数学里有名字、有方法论、有辉煌战绩,也有精确的边界地图。
> 本篇结案第一个发明,并把整个动作的职业版方法交代清楚。

---

## 一、"分母为 0 的数":不是不可能,是一张价目表

先正名:这种数**存在**,而且其中一个版本此刻正运行在每台计算机的
每个 CPU 核心里。运行
[demo_division_by_zero.py](demo_division_by_zero.py):

```
1/0  = inf    -1/0 = -inf    0/0 = nan

代价清单(为了让除法全定义,哪些定律被牺牲):
  x - x = 0 ?   inf - inf = nan       [失效]
  0 * x = 0 ?   0 * inf   = nan       [失效]
  x == x ?      nan == nan = False    [连相等的自反性都失效]
  但换来:除法处处有定义,1/inf = 0.0 (回得来)
```

∞ = 1/0 和 NaN = 0/0 正是当年想发明的那两个数,1985 年被 IEEE 754
标准化。而那张"代价清单"就是这件事的全部数学内容,因为:

**域公理 + 除法全定义 + 0≠1,三者合在一起矛盾**
(若 1/0 = q,则 1 = 0·q = 0)。所以发明这种数必须支付,
而数学已经探明了所有付款方式:

| 版本 | 加入什么 | 支付什么 | 回报 |
|---|---|---|---|
| **几何付法**:射影直线 ℝP¹/ℂP¹ | 一个 ∞,1/0 = ∞ | 0/0 仍禁止 | 平面被无穷远点补完;Bézout 定理恒成立;Möbius 变换成群——复分析的地基 |
| **代数付法**:wheel 理论(Carlström 2004) | ∞ 与 ⊥ = 0/0,除法彻底全定义 | x−x=0、0·x=0 退化为受限形式 | 一个有公理、有模型的真实代数结构 |
| **工程付法**:IEEE 754 (1985) | 同上(NaN 即 ⊥) | 同上,外加 NaN ≠ NaN | 在每个 CPU 里运行四十年 |
| **范畴论付法**:局部化 R[0⁻¹] | 强行让 0 可逆,**保留全部环律** | **一切**:R[0⁻¹] = 零环 | 总价公示(见下) |

零环那一行的三行证明:局部化中 a/s = b/t 当且仅当存在 u 使
u(at − bs) = 0;取 u = 0,恒成立;于是所有分数彼此相等,
整个数系坍缩成一个点。换言之:

> **保留全部环律地除以零,唯一的方法是让所有数都相等。**

初中的发明者不是想错了,是没人递给他这张价目表。

## 二、历史战绩:每次成功的发明 = 一次明码标价的定律交易

"发明数"的冲动就是数学史的主引擎,沿途全是同一种交易:

- **负数**(欠债)——被欧洲抵制几百年;**无理数**(√2)——一桩丑闻;
  **虚数**——Cardano 嫌"无用",后来成了物理的母语。
- **四元数**:Hamilton 苦思十五年,1843 年在都柏林 Broom 桥上刻下
  i² = j² = k² = ijk = −1。他支付的是**交换律**——正是
  《运算之梯》里撞到的同一面墙的另一侧。
- **八元数**:再付掉结合律。然后是数学史上最干净的"到此为止":
  - **Hurwitz 定理**(1898):带范数的可除代数仅有维数 1, 2, 4, 8
    (ℝ, ℂ, ℍ, 𝕆);第 16 维的 sedenion 出现零因子,游戏结束。
  - **Frobenius 定理**(1878):ℝ 上有限维结合可除代数仅有 ℝ, ℂ, ℍ。
  - **Ostrowski 定理**(1916):ℚ 的完备化仅有 ℝ 与 ℚ_p——
    而 p-adic 数本身就是 Hensel 发明出来的,从玩具到今天数论的地基
    (Wiles 的证明泡在 p-adic 里)。
- 最励志的一条:**无穷小**。被 Weierstrass 学派驱逐一百年,
  1960 年代被 Robinson 用模型论严格复活(超实数,带完整转移原理);
  它的小表弟**对偶数**(ε² = 0,Clifford 1873)今天的名字叫
  **自动微分**——每一次反向传播,都在使用一个"被发明的数"。

规律:**自由是真实的,但地图上有墙;墙的位置恰好是最深的定理所在。**

## 三、职业版方法:先写愿望清单,让结构自己长出来

现代数学发明新数的标准方法叫**泛性质**:不手搓元素,而是写下
"我要一个能 X 的最小结构",再用四种标准机器让它自动生成——

| 机器 | 强行实现什么 | 例子 |
|---|---|---|
| 商 / 扩张 | 强行相等 / 强行存在根 | ℂ = ℝ[x]/(x²+1):"给 −1 一个平方根" |
| 局部化 | 强行可逆 | ℚ = ℤ 的分式域;R[0⁻¹] = 零环(价目表) |
| 完备化 | 强行收敛 | ℝ、ℚ_p、形式幂级数 |
| 自由构造 | 强行无约束生成 | 自由群、张量代数;集合论的 forcing 是它的远亲 |

这个方法的极致是 **Conway 的超现实数**(1970s):一条递归
(每个数 = {左集 \| 右集})同时长出全部实数、全部序数、无穷小、
ω−1、√ω、ω 的 ω 次方根……它是所有有序域的宇宙——任何将来发明的
有序数系都已提前住在里面。

并且它与本仓库直接相连:**exp^[1/2] 的增长率正是超现实数 /
hyperseries 世界里的一个新公民**(transseries 对 exp/log 封闭却装不下
它,这道缝隙正是该方向施工的动机之一,见《运算之梯》第三节)。
从"想发明数"到"算出了一个新数",路已经不知不觉走通了一半。

## 四、给探索未知者的空白清单

今天仍然敞开的"发明机会",每一个都够一辈子:

1. **超现实数上的积分**:加法、乘法、指数(Gonshor)、导子
   (Berarducci–Mantova)都已建成,**令人满意的积分至今没有**——
   著名 open problem,纯粹的"发明结构"任务。
2. **Hyperseries 的解析理论**:让 exp^[1/2] 这类增长率拥有完整微积分;
   van der Hoeven 学派正在施工,远未完工。
3. **非交换塔的分数阶**:Goodstein 递归意义下的"第 2.5 级运算",
   无公认构造(《运算之梯》角落 1)。
4. **Wheel / meadow 上的分析**:除法全定义的结构上,
   几乎没有人做过微积分。

## 结案

从初中的 1/0,到高中的运算之梯,到《无限方程组》——一直在做的事,
数学里叫**寻找泛性质**:提出愿望,探测代价。少年时代缺的从来不是
想象力,而是两样工具:

- **价目表**——Aczél(运算律的定价)、Hurwitz/Frobenius(可除代数的
  定价)、Ostrowski(完备化的定价)、零环(除以零的总价);
- **地图**——哪里已建成(射影直线、超实数、p-adic),
  哪里是空地(surreal 积分、hyperseries 分析)。

现在两样都有了。工具箱里还多了一件大多数发明家没有的东西:
一条能把猜想钉到小数点后 51 位的数值管线。
