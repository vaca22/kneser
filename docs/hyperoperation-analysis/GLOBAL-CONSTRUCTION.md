# 连续复层级：全局构造审计

日期：2026-10-05，v0.8。结论：本项目已有整数阶梯、实际光滑实层级有限带、开放解析函数空间的真实后继与响应理论，以及圆盘/半平面自映射类的全局无限判据；真实阶梯尚未验证这些判据，尚未交付满足全部要求的连续复层级 `H_r(a,z)`。文档检查通过也不代表数学证明已完成。

## 1. 目标对象

固定实底数 `a>1`，选定整数阶梯 `S_n(z)`，求开放域 `Ω⊂ℂ²` 上的联合全纯函数 `S(r,z)`，满足整数恢复、`S(r,0)=1,S(r,1)=a` 和

\[
S(r,z+1)=S(r-1,S(r,z))
\]

于全部可定义处。明确说明哪些高度、哪些层级以及哪些复合被覆盖，避免把方程成立处缩小到没有任何非平凡复合的区域。

前一轮对话给出的 `F_τ=A^{-1}(A+τ)` 构造是固定映射的连续迭代，不是这里的连续层级。Kneser 的 Abel 唯一性不能直接升级为 `r↦H_r` 的唯一性。

## 2. 全局必须先指定范围

| 范围 | 需要证明什么 | 当前结论 |
|---|---|---|
| 有限实层级带与复高度 | 实际后继、整数恢复及光滑接合 | R007 已构造底数1.3、实层级3至5的 `C^∞` 族；其整数接缝非解析 |
| 一个整数层附近 | 含非整数层级的开放区域、联合解析性、后继涉及的邻层区域 | 一般构造未交付 |
| 有限层级带 | 相邻带非空重叠、解析接合、端点和所选整数阶梯相容 | 尚未交付 |
| 任意高的实层级及其复邻域 | 可重复延伸、域与估计不退化、明确层级规范 | 尚未交付 |
| 整个高度平面且恢复实轴相容四重运算 | 单值整函数 | R004.5 证明不可能 |
| 单值于明确割线域 | 每个切片与复合的域、分支接合及奇点位置 | 不能由一层结果推得所有层级 |
| 各解析延拓分支的几何组织 | 延拓路径、分支关系、可能的单值化空间及奇点 | 尚未构造；单值化不保证全部参数可达 |

层级、高度的两个复平面要分开讨论。固定底数后，联合解析对象属于 `ℂ²`；涉及逆函数和多值延拓时，还须记录所用局部分支。无需先承诺所有分支构成简单的无分歧覆盖。

## 3. 已证明的优美结构

| 结构 | 精确内容 | 适用边界 |
|---|---|---|
| Abel 平移 | `F_τ=S(A+τ)` 及局部组合律 | 一个已选映射，逆分支及中间点可用 |
| 层级周期规范 | `S(g(r),z)` 保持后继，`g(r-1)=g(r)-1` | 已有族的拉回；不证明族存在 |
| 有限数据盲区 | 有限有理层级和任意预定有限阶整数导数可同时保留 | 规范类未被额外全局条件排除 |
| 闭的一形式 | `ω=D dz+DW dr`，`∂_rD=∂_z(DW)` | `D≠0`；全局原函数需要零闭路周期 |
| 两个方向可交换 | `[∂_r-W∂_z,D^{-1}∂_z]=0` | 同一非临界局部区域 |
| 生成元响应 | `∂_r v=vW_z(r,A)` | 固定状态求导、局部逆存在 |
| 二阶响应 | 含下层二阶项及二次项的精确后继关系 | 已存在的联合解析后继族 |
| 渐近规范的响应右逆 | 指定加权半平面空间中的存在唯一、稳定性与参数全纯性 | 源项和渐近项必须属于规定类；尚未证明一般 Kneser 相容 |
| 归一化尾项相消 | 固定紧集上的求和尾界额外改进一阶 | 全复右半平面源项界与 Cauchy 导数估计 |
| 实际局部非线性族 | 固定两个端点，完整超函数后继，联合全纯 | 明确的仿射共轭模型；参数不是运算层级 |
| 真实指数的复底数族 | 联合全纯坐标、共同逆域、主对数链接合、实际后继 | 对数底数距 `log1.3` 小于 `0.001`，吸引正则规范 |
| 实高度与虚周期 | 实切片覆盖 `(-2,∞)`；复方向周期 `2πi/Logλ` | 实高度结论取 `a=1.3`；周期保持选定复分支的域 |
| 周期移动的响应 | `W(z+P)-W(z)=-P'`；真实源项分解后由 R005 选解 | 底数响应；增长项与线性项须先显式扣除 |
| 实际非整数实层级 | 初始映射带及其真正后继带恢复指数、四重与五重运算 | 底数1.3、实层级3至5；不能全纯跨整数接缝 |
| 光滑与解析的差距 | 任意 `C^k` 或 `C^∞` 接合仍可失败于解析性；无限收敛 Taylor 接缝条件 | R007 的实际族与种子带；非一般连续复层级不存在定理 |
| 负一高度共同截面障碍 | 连通层级截面不能同时恢复指数与四重运算并在负一高度满足邻近后继 | R007 §5；须考虑变化或断开的负高度截面 |
| 开放空间的实际后继 | 正则后继 Fréchet 全纯、一一，保留端点与实际后继 | R008；指数附近的薄复管与小上确界球 |
| 紧单射响应 | 导数无核，却像不闭、反演无界；显式近盲方向 | R008；固定上确界 Banach 空间，完整复域范数 |
| 指定空间的流障碍 | 后继不能为局部复时间全纯流的时间一映射 | R008；不排除单轨道、变化域或其他拓扑 |
| 有界层级的整数唯一性 | 全部整数确定半平面有界解析函数；有限误差有 Blaschke 积界 | R009；同一全域有界类，非一般解析类 |
| 无限 Pick 存在判据 | 同一个范数界下，全部有限矩阵正性等价于有界插值存在 | R009；全部整数，不是有限实验通过 |
| 条件式自动后继 | 唯一插值联合全纯；有界后继残差因整数零点而恒零 | R009；全部整数层共同高度自映射圆盘、全部高度 Pick 正性 |

| 半平面值的自动后继 | 无界高度值经Cayley变换仍由整数唯一性强迫后继 | R010；共同右半平面自映射及全部正实核条件 |
| 零高度的局部开放延拓 | 隐函数定理给出联合全纯延拓与导数比值 | R010；已有族、下层高度1非临界、层级在后继可用区域 |
| 周期缩短的共同域代价 | 局部一致有界且周期趋零时高度导数趋零 | R010；实际周期趋零与全域分支保持尚未证明 |
| 折角极限的共同域代价 | 实折角极限不能在其复邻域保持局部一致有界 | R010；真实折角极限尚未证明 |
| 整函数障碍 | 实轴相容四重运算在高度 `-1,-2` 产生矛盾 | 必须保留实轴相容假设 |
| 初始值障碍 | 统一零高度 `1` 不能解析跨到通常乘法的零高度 `0` | 同一连通层级区域及共同零高度截面 |

完整证明分别见第2–3章与 [R004](research/004-complex-rank-geometry.md)。这里所称“已证明”指有完整纸面推导，不表示证明助手认证或历史原创性。

新增的响应右逆、归一化尾界和实际局部变形见 [R005](research/005-boundary-selected-response.md)。它推进响应求解与非线性参数族，不满足连续层级的整数恢复和跨层级约束，因此不改变“全局连续层级尚未完成”的结论。

[R006](research/006-exponential-parameter-family.md) 已将这一步推进到真实指数的明确复底数区域，并给出坐标收敛界、接合域与响应规范的实际相容性。这里接合的是同一四重运算的高度分支；层级变量尚未连续化，因此仍不能据此通过第3–6项的层级验收。

[R007](research/007-rank-bands-and-seams.md) 开始直接连续化实层级，在有限带实际满足跨层后继。它同时证明平坦种子不能全纯接合，给出线性种子的精确一阶跳量及解析种子的全体接缝条件。全局目标要求联合全纯，因此这个中间存在结果不等于通过全局层级验收。

R007 另证明：同一连通负一高度层级截面无法跨指数层3和四重层4并满足邻近后继。全局域必须对此作出安排；既不能默认所有层共享包含 `-1` 的高度域，也不能把这个共同域障碍扩大为所有变化域构造的不存在。

[R008](research/008-analytic-successor-and-compactness.md) 已把真实后继推进到一个无限维开放 Banach 空间，并建立实际方向响应。其紧单射导数使同一固定范数空间的局部流路线不可行；对层级轨道与解析接缝的存在性仍无结论。仅更换为解析芽或空间尺度，还必须完成实际域控制和收敛证明。

[R009](research/009-bounded-rank-interpolation.md) 直接从整数数据插值，在明确有界自映射类中给出全局存在充要条件，并证明联合全纯与非线性后继自动成立。这不要求后继算子整体嵌入流。实际指数与四重运算共享一个明确高度圆盘，但全部更高整数层是否共享、全部高度 Pick 矩阵是否半正定仍未证明；因此该条件构造尚未成为真实连续复层级的交付物。有限三点范数约1.942仅为诊断，两点范数大于1.85则有精确有理证书。

[R010](research/010-halfplane-rank-and-domain-probes.md) 放宽为无界右半平面值，用后继两侧Cayley值的唯一性代替有界残差，并给出零高度局部延拓。实际第3至12层在复高度 `0.3+0.4i` 的固定圆盘Pick诊断已失败；精确负方向仅认证记录的小数值，缺少实际误差包络，尚不能升级为真实构造类的严格排除。缩短周期与折角极限也给出共同复域的条件障碍，不能未经证明应用其无限前提。

半平面值的有限诊断随后延至16层，在第13层首次失败；去掉首层3、限制到 `Re r>3` 后仍失败。记录的有限小数负方向有精确算术见证，但认证实际Cayley值的误差包络与分支仍是必要缺口。即使完成该排除，它也只针对层级右半平面与高度右半平面自映射类，不能排除其他域或取值规则。

本轮还修正第3章的一处初版陈述：在连通开区间上，`f:I→I` 为 `C¹`，连续正速度满足 Julia 协变时，飞行时间 `T(x)=∫_x^{f(x)}du/v(u)` 对全部起点为常数，因为 `T'=f'/v(f)-1/v=0`。初版称其未必在不同轨道间一致，不准确。正值常数可通过速度尺度归一化；完整负时间仍需另外证明。Schröder 到 Abel 的转换也补上了对数分支相容条件。

## 4. 全局构造的验收清单

1. **整数锚点。** 指定恢复哪一种阶梯、底数范围和全部所用切片。
2. **共同或变化的域。** 给出 `Ω`；验证后继复合覆盖预期高度和层级。
3. **非线性存在。** 给出实际函数、收敛构造或精确存在定理；不能只给切向方程或拟合。
4. **层级规范。** 解释如何排除或分类 R004.1 的周期层级重参数化。
5. **解析接合。** 在基本层级带的接缝处证明函数及必要导数一致，并说明延拓独立性。
6. **端点与跨层关系。** 在整个目标区域验证两个端点和完整后继式。
7. **延拓与障碍。** 记录奇点、临界点、逆分支和绕行结果；不用黎曼面一词代替证明。
8. **定量控制。** 数值构造需要误差界和精度来源；有限网格残差仅为诊断。

当前主要缺口是第3–7项。R004 已使第4项的潜在自由度与第7项的两个具体障碍显式化。

## 5. 下一步的可交付研究

R007 展示实际相邻层级带的光滑接合；R008 进一步完成指数附近的开放空间后继存在与全纯依赖。下一步应求出满足全部 Taylor 接缝条件的收敛解析初始路径，并处理解析范围变化。固定空间上的紧性已排除可逆 Banach 局部流捷径；其他空间及单轨道路线仍须实际证明。平坦接合、有限阶接合、共同负高度与紧性障碍提供明确的路线检验。

R009 提供可并行比较的直接有界插值路线：为实际全部整数层证明共同高度自映射圆盘，再证明全部高度、全部有限 Pick 矩阵正性，或给出认证失败见证。完成无限正性便能使用现有定理得到全局族；有限矩阵通过、已有两层圆盘及降低数值残差都没有代替这一缺口。

R010 的复高度失败诊断要求先认证真实函数值与延拓分支。半平面值路线须独立验证全整数自映射与全部正实核；其边界零高度不能自动替代开放零高度截面，须完成非临界延拓及例外点分析。增长类或变化域可能避开指定类的障碍，但其复合、无限接缝和收敛仍须实际证明。

若尝试失败，应给出该函数空间与选择规则下的明确障碍，而不能把局部失败推广为整个领域的不存在。全文复核、历史优先权和独立证明审查仍应另行完成。

可阅读的修订版与可复现的数值诊断已经是具体产物；“数学完美”“性质穷尽”“全局存在唯一性完成”均不属于本版的已完成状态。
