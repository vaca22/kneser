## 每次推进的最小记录

1. 精确问题、假设、定义域和判定标准。
2. 推导与引理依赖，是否存在周期核或分支自由度。
3. 参数、脚本、输入、误差和反例。
4. 状态变化及其理由，明确是否需要修订书稿。

“数值符合”升级为“证明”必须增加完整解析论证或覆盖目标区域的计算机证书。研究札记有完整证明，仍须另行评估原创性。
