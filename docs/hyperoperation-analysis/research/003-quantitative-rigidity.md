# R003　有限带宽刚性与生成元辨识的小分母

日期：2026-10-04。状态：`[证]`；历史原创性未核定。有限 Fourier 对角化属于经典方法，本轮将它用于超函数周期规范的辨识问题。

## 1. 从精确刚性到误差问题

R001 证明，一个无理时间上的全部函数相等可排除周期时间变换。实际观测只能给出误差。本札记研究 Abel 时间轴上的残差

\[
\Delta_\alpha p(u)=p(u+\alpha)-p(u),\qquad
P(u)=u+p(u).
\]

这是周期规范对无理平移的交换误差。它与状态空间函数误差之间还需要 `S` 的导数及逆导数界；不能无条件把两者的范数相同看待。

## 2. 有限带宽稳定性定理 `[证]`

设 `p(u)=∑_{|k|≤N}c_k e^(2πiku)` 为三角多项式，`α` 无理，`p̄=c₀`。取周期 `L²` 范数

\[
\|h\|_2^2=\int_0^1|h(u)|^2\,du.
\]

令

\[
d_k=|e^{2\pi ik\alpha}-1|=2|\sin(\pi k\alpha)|,
\quad d_N^*=\min_{1\le k\le N}d_k>0,
\]

\[
C_N=\left(2\sum_{k=1}^Nd_k^{-2}\right)^{1/2},
\quad M_N=\max_{1\le k\le N}\frac{2\pi k}{d_k}.
\]

**定理 R003.1。** 若 `‖Δ_αp‖₂≤δ`，则

\[
\|p-\bar p\|_2\le\frac\delta{d_N^*},\quad
\|p-\bar p\|_\infty\le C_N\delta,\quad
\|p'\|_2\le M_N\delta.
\]

若另有 `p(0)=0`，则 `‖p‖∞≤2C_Nδ`。第一个和第三个算子常数都是最优的，即使限制为实三角多项式仍可由单频正弦达到。

**证明。** 记 `b_k=(e^(2πikα)-1)c_k`。指数函数在 `[0,1]` 上正交，直接积分有限和得

\[
\|\Delta_\alpha p\|_2^2=\sum_{k\ne0}|b_k|^2,
\quad\|p-\bar p\|_2^2=\sum_{k\ne0}\frac{|b_k|^2}{d_k^2}.
\]

下界 `d_k≥d_N^*` 给出第一式。逐点使用 Cauchy–Schwarz：

\[
\left|\sum_{k\ne0}\frac{b_k}{e^{2\pi ik\alpha}-1}e^{2\pi iku}\right|
\le\left(\sum|b_k|^2\right)^{1/2}
\left(\sum d_k^{-2}\right)^{1/2},
\]

得第二式。对导数同样正交积分，得

\[
\|p'\|_2^2=\sum_{k\ne0}\frac{(2\pi k)^2|b_k|^2}{d_k^2}
\le M_N^2\delta^2.
\]

`p(0)=0` 时，`p̄=-(p(0)-p̄)`，所以 `|p̄|≤C_Nδ`，给出归一化结论。选择使相应比值取极值的单频正弦，第一式或第三式等号成立。∎

**适用范围。** 带宽 `N` 是外加的先验条件。未给带宽或高频衰减时，不能把 `C_N,M_N` 当作固定常数。

## 3. 高频近共振反例 `[证]`

固定 `0<ε<1`，取

\[
p_q(u)=\frac\varepsilon{2\pi q}\sin(2\pi qu).
\]

则 `P_q'=1+εcos(2πqu)` 始终在 `[1-ε,1+ε]` 之间。交换残差精确为

\[
\|\Delta_\alpha p_q\|_\infty
=\frac\varepsilon{\pi q}|\sin(\pi q\alpha)|,
\]

而 `p_q'(0)=ε` 和 `‖p_q'‖₂=ε/√2` 不随 `q` 减小。

对任意无理 `α`，存在无穷多整数 `q` 使 `dist(qα,ℤ)<1/q`。这里给出所需的短证明：对任意 `Q`，将 `0,α,…,Qα` 的小数部分放入 `Q` 个等长区间，抽屉原理给出 `1≤q≤Q` 且距离小于 `1/Q≤1/q`。若产生的 `q` 只有有限多个，它们到整数的正距离有正最小值，与 `Q→∞` 矛盾。

沿这样的无穷子序列，

\[
\|\Delta_\alpha p_q\|_\infty<\frac\varepsilon{q^2}\to0,
\qquad\frac{v_{P_q}(c)}{v(c)}=1+\varepsilon.
\]

因此即使已知周期时间变换的导数一致有界且离零有统一下界，无理时刻的近似交换仍不能给出归一化点生成元的统一稳定性。需要额外的频率或更高正则性控制。

这里没有否定函数值层面的所有稳定性：本反例自身 `‖p_q‖∞→0`。结论针对生成元/导数辨识，并清楚区分了两种拓扑。

## 4. 对状态空间的含义

在一个共同紧区域内，若 `|S'|≤L`，交换残差给出

\[
|F^P_\alpha(x)-F_\alpha(x)|
\le L\,\|\Delta_\alpha p\|_\infty,
\]

其中 `u=P^{-1}(A(x))`，两个 `S` 的输入为 `P(u+α)` 和 `P(u)+α`。高频反例因此能使一个无理时刻的整个紧区域上的函数差趋零，同时保留起点生成元的固定差。

带宽条件下，定理对 `p'` 的控制可以再通过 R001 的精确生成元公式传回状态空间，但需要记录坐标变化带来的测度权重和范数常数。本札记没有将 Abel 坐标的 `L²` 界未经换元直接称为状态空间 `L²` 界。
