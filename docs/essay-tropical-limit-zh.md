# 超运算阶梯的热带极限

2026-10-02。本文是结论稿。数值表、逐级脚本和撤回过的拟合在
[rank-tropical-limit-zh.md](rank-tropical-limit-zh.md)。

记号：`S_s(z) = b[s]z`，`S_s(0) = 1`，`S_s(z+1) = S_{s−1}(S_s(z))`。
`p_s` 是 `S_{s−1}` 的吸引不动点，`λ_s = S_{s−1}'(p_s)`，`L_s = |log λ_s|`，
`β = b − 1`，`a = (2−b)/(b−1)`，`ε_s = p_s − b`。
`η = e^{1/e} ≈ 1.444667861`。
三段标记：**[证]** 有完整证明；**[推]** 有推导，渐近匹配尚未封成定理；
**[数]** 只有数值。

---

## 1. 结论

在 `1 < b < η` 上，正则阶梯在每个固定的紧区间上满足

```
S_s(z) → F_b(z) = min(1 + z, b),
‖S_s − F_b‖ = (log 2) / L_s · (1 + o(1)).
```

`L_s ∼ log(s/a) / (b − 1)`，所以收敛是对数慢的，主项是 `(b−1) log 2 / log(s/a)`。
转折点在 `z = β`，不在 `0`。有限阶是这条折线的 log-sum-exp 光滑化，温度 `1/L_s`。

主项是软化折线的 **[证]**。阶梯贴着闭式对数、从而贴着这条主项，是 **[推+数]**：
Koenigs 圆盘内第 16 级已经到 `10^{−7}`，网格上的剩余是高一阶的 `1/(s log s)`。

临界底数另有一条独立的结论：对任何递增阶梯，`b_c(s)` 单调、不超过 2。
`b_∞ = 2` 对速率律模型成立 **[证]**，对解析阶梯仍是区间 `[1.83976, 2]`。

## 2. 折线是不动点，但不是唯一的 [证]

**命题 A.** `F_b(z) = min(1+z, b)` 满足 `F(z+1) = F(F(z))`、`F(0) = 1`、`F(1) = b`。

*证.* `F(F(z)) = min(1 + min(1+z, b), b) = min(2+z, b) = F(z+1)`。∎

凹在这里指 `f'' ≤ 0`，图像在弦的上方。

**命题 B.** 设 `G` 在 `[−1, ∞)` 上凹、不减，`G(−1) = 0`、`G(0) = 1`、`sup G = b`。
则 `G ≤ F_b` 于 `[0, ∞)`，`G ≥ F_b` 于 `[−1, 0]`，并且 `G = F_b` 当且仅当 `G(β) = b`。

*证.* 弦 `[−1, 0]` 的斜率是 1。凹函数在这段弦之外位于其延长线下方，所以 `z ≥ 0` 时
`G(z) ≤ 1+z`；之内位于上方，所以 `z ∈ [−1, 0]` 时 `G(z) ≥ 1+z`。再加 `G ≤ b`。
若 `G(β) = b`，弦 `[−1, 0]` 与弦 `[0, β]` 的斜率都是 1，相邻两弦斜率相等，
`G` 在 `[−1, β]` 上是直线 `1+z`；`z ≥ β` 时由不减，`b = G(β) ≤ G(z) ≤ b`。∎

**命题 C.** 在 `[0, 1]` 上任取凹、不减、夹在弦 `1+(b−1)z` 和 `min(1+z, b)` 之间、
且 `h(0) = 1`、`h(1) = b` 的 `h`。把它在 `z ≤ 0` 接成 `1+z`、在 `z ≥ 1` 接成常数 `b`，
得到的 `G_h` 仍然满足后继方程和同一组规范化。`F_b` 是这一族的上包络。

所以不动点方程、规范化、凹性一起**选不出**极限。阶梯选中上包络，等价于转折点缺口
`g_s = b − S_s(β)` 趋于 0。

## 3. 软化折线收到折线 [证]

```
Σ_L(z) = b − (1/L) log(1 + e^{L(β − z)})
       = −(1/L) log( e^{−L(1+z)} + e^{−L b} ).
```

这是 `min(1+z, b)` 的 log-sum-exp，温度 `1/L`。两个指数之和至少是较大的那个，所以
`Σ_L ≤ F_b`。

记 `u = L(β − z)`，`ψ(u) = log(1+e^u) − u e^u/(1+e^u)`。则

```
∂Σ_L / ∂L = L^{−2} ψ(u),     ψ'(u) = −u e^u / (1+e^u)^2.
```

`ψ` 在 `0` 取唯一最大值 `log 2`，并且 `ψ > 0`。因此 `L` 增大时 `Σ` 逐点上升。
转折点上的缺口恰是 `log 2 / L → 0`。单调、有上界、缺口消失，`Σ_L → F_b`。

更精确：在整条实轴上

```
‖Σ_L − F_b‖_∞ = log 2 / L,
```

只在 `z = β` 取到。`z ≤ β` 时 `F − Σ = L^{−1} log(1 + e^{L(z−β)})`，
`z ≥ β` 时 `F − Σ = L^{−1} log(1 + e^{L(β−z)})`，两边都不超过 `log 2 / L`。

斜率与底数无关：

```
Σ'(z) = σ(L(z − β)),     σ(u) = 1/(1+e^u) = (1/2)(1 − tanh(u/2)).
```

于是 `Σ'(β) = 1/2`，`Σ''(β) = −L/4`，`Σ'(β+t) + Σ'(β−t) = 1`，
并且 `Σ^{(n)}(β) = L^{n−1} σ^{(n−1)}(0)`。前四项是 `1/2`、`−1/4`、`0`、`1/8`，
所以 `Σ''''(β) = L^3 / 8`。

## 4. 后继缺陷的主项是 `log 2` [证]

`F_b` 精确满足后继方程。同一温度的两份软化折线几乎继承这一点，差是指数小的：
`L = 8` 时最大 `4.2×10^{−5}`，`L = 16` 时最大 `7.0×10^{−9}`，都比 `e^{−L}` 小。

温度从 `N` 降到 `L = N + dL` 时，缺陷对 `N` 的导数是 `−N^{−2} ψ(N(β − Σ_L(z)))`。
`ψ` 在内层落到转折点时取最大，那里 `z = b − 2 + O(e^{−L}/L)`。一阶项是

```
Δ = log 2 · dL / L^2 + O(dL^2 / L^3).
```

相对误差 `dL/L → 0`。配上速率律 `L_s ∼ log(s/a)/(b−1)`、
`L_s − L_{s−1} ∼ 1/((b−1) s)`，峰高

```
Δ ∼ (b−1) log 2 / (s [log(s/a)]^2).
```

底数 1.3，在 `z = b−2` 上实测与这一阶项的比：`s = 24, 48, 100, 500` 为
`1.049, 1.014, 1.004, 1.0004`。`s^2 Δ` 不收敛，因为主项比 `1/s^2` 大一个 `s/log^2 s`。

半整数阶和 `s+it`（`|t| ≤ 5`）的缺陷与整数阶同量级。整数性不进入误差。
这是软化族自己的缺陷，不是阶梯对软化折线的距离。

## 5. 闭式对数，以及转折点为什么不在半斜率点上

上一级若是 `T(p+t) − p = (λ/L)(1 − e^{−L t})`，Koenigs 逆的二次项有闭式

```
u_2 = (L/2) / (1 − λ).
```

`λ → 0` 时 `u_2 → L/2` **[证]**。高阶同样是 `L^{k−1}/k` 加上 `O(λ)`。
因此

```
U(σ) = −(1/L) log(1 − L σ)
```

是 `λ → 0` 时的 Schröder 逆。代回超函数，用 `Φ(1) = b` 定常数，得到闭式对数。
记 `M = L_{s−1}`，`λ = λ_s`：

```
Φ(z) = p_s − (1/M) log(1 − M C_s λ^z).
```

它的导数是被温度比拉开的逻辑斯蒂：

```
Φ'(z) = (L_s / M) · σ(L_s (z − z_{1/2})).
```

`z_{1/2}` 是斜率等于 `L_s/(2M)` 的点。令 `A = −M C_s`。半斜率点满足 `A λ^{z_{1/2}} = 1`。
`Φ(1) = b` 给出 `A λ = e^{M ε} − 1`，于是转折点相对半斜率点的偏移是

```
u_0 = L_s (β − z_{1/2}) = −log(e^{M ε} − 1) + (b − 2) L_s.     [证]
```

右边两项各自是几的量级，差是零点几。底数 1.3、第 24 级：`5.552` 与 `−5.407` 留下
`u_0 = 0.145`。这一级的斜率、二阶、三阶、四阶导数，阶梯和 `(L/M) σ^{(n−1)}(u_0)`
逐位相同：**[数]**。

在约化映射的一步上，这个偏移就是温度的前差 **[证]**。令 `x = L_{s−1} ε_s`，

```
u_0(s) = (L_{s+1} − L_s) − ε_{s+1} L_s + log(L_s / L_{s−1}) − log((e^x − 1)/x).
```

`1 < b < η` 时 `a > 1`，后三项比 `1/s` 小，所以 `u_0 ∼ L_{s+1} − L_s`。
由 `L_s ∼ log(s/a)/(b−1)` 的差分，

```
s u_0(s) = 1/(b−1) + 1/log(s/a) + o(1/log s).     [推]
```

底数 1.2、1.3、1.4 的约化轨道在 `s = 10^6` 上与这个两项式差约 `0.01`，是 `1/log^2 s` 那一档。

## 6. 离软化折线多远 [证：对 Φ；推+数：对阶梯]

令 `v = L_s(z − β)`。由 `A λ^z = e^{−(v+u_0)}`，

```
Φ(z) − Σ(z) = E(v)
E(v) = ε + (1/L) log(1+e^{−v}) − (1/M) log(1+e^{−(v+u_0)}).
```

`E'(v) = −σ(v)/L + σ(v+u_0)/M`。比值 `σ(v+u_0)/σ(v)` 从 1 严格降到 `e^{−u_0}`。
阶梯上 `L > M` 且 `e^{−u_0} < M/L`，所以恰好一个零点，那是最大值
（`v → −∞` 时 `E → −∞`，因为 `1/M > 1/L`；`v → +∞` 时 `E → ε`）。

令 `κ = (L − M)/(u_0 L)`。`κ → 0` 时

```
max E = ε + (u_0 / L) (1 − κ − κ log(1/κ)) + o(u_0 / L).
```

`κ ∼ (b−1)/log(s/a) → 0`，并且 `κ log(1/κ) → 0`。`b < 3/2` 时 `a > 1`，
`ε = o(u_0/L)`；正则区 `b < η` 整个落在这里。于是

```
max |Φ − Σ| ∼ u_0 / L_s ∼ 1 / (s log(s/a)).
```

这个因子掉得很慢。第 24 级括号里还是 `0.62`，所以 `s^{1.3}` 乘上第 16–48 级的误差几乎是平的。
那是窗口，不是指数。峰的位置 `z_* = β + v_*/L` 滑向转折点；底数 1.3、第 24 级，`z_* = 0.036`。

三个底数上，`E(v_*)` 和网格上的 `max(Φ−Σ)` 前四位相同。底数 1.3：

| s | `max(Φ−Σ)` | `E(v_*)` | 上式的主项 | `log 2 / L` |
|---|---|---|---|---|
| 8 | 0.06361 | 0.06368 | 0.06327 | 0.171 |
| 16 | 0.02122 | 0.02123 | 0.02108 | 0.108 |
| 24 | 0.01222 | 0.01223 | 0.01217 | 0.0897 |

`Φ` 在 `−∞` 的斜率是 `L/M`，不是 1，所以范数要在固定的紧区间上取。
在那样的区间上，`max|Φ−Σ| = o(1/L)`，因此

```
‖Φ − F_b‖ = (log 2) / L · (1 + o(1)).     [证]
```

转折点上少掉的那一截是 `E(0)`，不是峰高。底数 1.3、第 24 级：
`g_s = 0.0816`，`log 2 / L − g_s = 0.0081 = E(0)`。

阶梯这边 **[数]**：模型映射的 `u_2` 收到 `L/2` 之后，真实系数更贴，
第 24 级 `u_k · k / M^{k−1} = 1.00001`（`k = 2…5`）。圆盘内 `|S − Φ|` 在第 16 级是 `10^{−7}`。
固定区间的左端还有一条同阶的尾巴，底数 1.3 上 `[−1, 2]` 的 `|S−Φ|` 从第 8 级的 `0.030`
降到第 20 级的 `0.005`，仍然比 `log 2 / L` 小。网格上阶梯离折线的距离就是
`log 2 / L_s` 加上本节这一项。

速率律给出 `ε_s → 0`，所以 `p_s → b` **[推]**。闭式对数在转折点的缺口
`−ε + M^{−1} log(1+e^{−u_0})` 趋于 `log 2 / M` **[推]**。
整段 `S_s → F_b` 在紧区间上还差一条均匀的 `|S−Φ| → 0`；上一段的数支持它，证明没有封上。

## 7. 临界底数

`b_c(s)` 是第 `s` 级塔收敛的底数的上确界：轨道 `1, S_{s−1}(1), S_{s−1}(S_{s−1}(1)), …` 收敛。

**引理 1 [证].** 若每一级在 `[1, ∞)` 上递增，则 `C_s ⊂ C_{s+1}`。某一级的塔一旦有界，
以后各级都有界。

**引理 2 [证].** `b ≥ 2` 时每一级塔都发散。整数超运算从下面压住：`b[s]n ≥ 2[s]n`，
而 `2[s]n` 随 `n` 发散。

因此 `b_c(s)` 单调不减、不超过 2，收敛到某个 `b_∞ ≤ 2`。这与阶梯在分数高度上怎么延拓无关。

**`b_∞` 不普适 [数].** 每级在 `(−1, 0]` 上取同一个种子 `(1+z)^q`。
`q < 1` 时停在 2 下面：

| q | 0.5 | 0.8 | 0.9 | 0.95 |
|---|---|---|---|---|
| `b_∞(q)` | 1.7305123616 | 1.8215094562 | 1.8835547088 | 1.9365157852 |

`q ≥ 1` 时趋于 2。机制：`q < 1` 使 `(0, 1]` 上的值被反复迭代推向 1，极限在转折点上方跳起来，
不再被 `b` 压住。

「不越过 `1+z`」不是判据 **[数]**。`b = 1.65 > b_c5` 时 Kneser 四级运算在网格上仍不超过 `1+z`
（`sexp(1/2) = 1.340 < 1.5`），五级塔却发散。

**命题 D [证].** 设 `f` 在 `[0, L]` 上不减，`f(1) = b ∈ (1, 2)`，`L = 1/(2−b)`，并且
`f(x) ≤ 1+(b−1)x` 对一切 `x ∈ [1, L]`。则轨道 `1, f(1), f(f(1)), …` 收敛到 `[b, L]` 里的不动点，
从而 `b` 不超过下一级的临界底数。

*证.* `x ≥ L` 时包络不超过 `x`，所以 `f(L) ≤ L`。`f` 不减且 `f(1) = b`，
轨道从 `b` 起不减、不超过 `L`。`b ∈ (1, 2)` 时 `L ≥ b`。∎

这是充分条件。四级运算上包络保持到 `b = 1.62`，真值 `b_c5 = 1.63532449671528`，松 `0.015`。
`b = 1.63` 时包络已经超出 `0.002`，塔仍收敛。

**速率律模型的 `b_∞` 是 2 [证].** 取主项 `q_s = a/s`，`L_s = log(s/a)/(b−1)`，
`ε_s = q_s^a / L_s`，用这些参数定义 `Φ`。则 `Φ(1) = b`，`Φ'' < 0`，并且

```
Φ'(1) = (L_s / M) (1 − e^{−M ε_s}) ∼ (a/s)^a → 0.
```

一旦 `Φ'(1) ≤ b−1`，凹性给出 `x ≥ 1` 时 `Φ(x) ≤ 1+(b−1)x`。命题 D 适用，塔收敛。
每个固定的 `b ∈ (1, 2)` 都有足够大的 `s`。`b = 1.99`、`s = 20`：斜率 `0.6056 < 0.99`，
`[1, 100]` 上包络超出为 0。`b` 越接近 2，`(a/s)^a = s^{−a}` 掉得越慢，但 `a > 0` 时仍然趋于 0。
相邻两级并不精确满足后继方程，缺陷就是第 4 节的 `1/(s log^2 s)`。

凹种子的斜率不落到 `b−1` 下面，所以可以停在 2 下面。解析阶梯要得到同一个 2，
需要某一级真实的 `S_s` 满足 `Φ'(1) ≤ b−1`。已知的临界值：

| 级 | `b_c` | 逐差 |
|---|---|---|
| 4 | `η = 1.444667861` | |
| 5 | 1.63532449671528 | 0.190657 |
| 6 | 1.73735592515 | 0.102031 |
| 7 | 1.79912060 | 0.061765 |
| 8 | 1.83976 | 0.04064 |

七级运算在 `b = 1.845` 已经冲出包络。解析 `b_∞` 仍是 `[1.83976, 2]`。
外推不能收口：`q = 0.9` 的种子真实停在 1.8836，对它做 Aitken 却给出 1.896。

## 8. 阶数作为复变量

`F_b` 在转折点不可微，逼近是对数慢的，没有乘子。对后继算子在 `F_b` 处做 Koenigs 迭代没有出发点。

主阶上，阶数只通过 `ħ_s = 1/L_s` 进入，而

```
ħ(s) = (b−1) / (log s − log a − …)
```

在 `Re s > 1` 上解析。因此

```
b[s]z ≈ −ħ(s) · log( e^{−(1+z)/ħ(s)} + e^{−b/ħ(s)} )
```

是一个渐近意义上的复数阶，地位和 Stirling 级数对 Γ 一样。它不唯一。
软化族自己的后继缺陷已经是第 4 节的 `1/(s log^2 s)`；阶梯相对这条主阶的距离是第 6 节的
`1/(s log s)`。

由此得到一条判据。`1 < b < b_∞` 时，任何候选的复数阶在 `s → ∞` 必须热带化到 `min(1+z, b)`，
并且 `b[s](β) = b − log 2 · ħ(s) + o(ħ)`。`b ≥ 2` 时每一级塔发散，没有有界的实极限。

## 9. 和已有工作的关系

Nixon（arXiv:1503.07555、2106.03935）逐级构造了 `η` 以下的这条链，没有讨论 `n → ∞`。
他的有界解析链就是这里的正则链。`η` 以上四级用 Kneser 解，五级起重新变成正则迭代，
同一条折线继续出现（`b = 1.5` 到 40 级，`b = 1.6` 到 24 级）**[数]**。

Rubtsov–Romerio 的 omegation 只在整数高度上写下 `a[ω]n`。`F_b` 在整数点上与之相容
（`F_b(0) = 1`，`n ≥ 1` 时 `F_b(n) = b`）。连续高度上的转折点、温度和速率，在已查到的资料里没有出现。

`−ħ log(e^{−x/ħ} + e^{−y/ħ}) → min(x, y)` 是 Maslov 去量子化的标准形式。
新的是它从超运算阶梯里长出来，而且 `ħ` 由阶数给定。
