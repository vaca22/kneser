## 0. 结论

> ⚠ **下面第 3、4 条已被推翻**（2026-09-16）。第 1、2 条仍然成立，但第 2 条里的
> `exp(−6/Im b)` 衰减律已撤回，正确尺度是 `Λ(b)=exp(4π²/log λ_up)`。
> 完整修订见本文 §5 末尾的修订块与 [base-separation-zh.md](base-separation-zh.md)。

1. **Kneser 双不动点构造可以穿过 Shell–Thron 边界继续做下去**（上不动点变成吸引的，
   |λ_up| < 1）：路径上每一步以上一基底的系数为种子，4–10 轮收敛，残差 ≤ 7e-10，θ 保持 1-周期。
2. **区内它不是正则解**，但差别随基底逼近实轴 (1, η) 而以本质奇点的速度消失：
   θ_up 的第一个非常数 Fourier 模 |a₁ᵘᵖ|（它为 0 当且仅当解就是"正则超函数平移"）
   在区外和边界处 ≈ 0.05，进区后 2.7e-2 → 2.1e-3 → 6.5e-4 → 1.8e-4 → 1.3e-6 → 1.0e-9 → 噪声，
   拟合 **|a₁ᵘᵖ| ≈ exp(−(6 ± 0.5)/Im b)**，在 Re b = 1.3 与 1.42 两条竖线上常数一致。
3. **Im b → 0 的极限是正则解，且到全部可达位数**：12 位构建在 1.3+0.15i、1.3+0.05i 与
   正则引擎（24 位）之差 3e-14、7e-15；直接在实基底 1.3 上强制 α/β 不动点做迭代，收敛到实系数
   （|Im| ≤ 1.9e-10），与 `_regular` 差 4e-10（8 位构建精度）。共轭基底给共轭系数（1.8e-10），
   所以从下方逼近极限相同，实轴上的极限函数是实值的——(1, η) **不是**基底平面上的割线。
4. 所以"延拓得到另一个实解析解"在数值上不成立：延拓的边界值就是正则解。真正的发现是
   区内 Kneser 解 K(b) 与正则解 R(b) 相差一个 exp(−C/Im b) 量级的项——它在实轴上按任意阶消失，
   却在 1.3+0.3i 处确凿非零（1.6e-9，12 位构建证实）。§5 讨论这为什么在理论上不平凡。

## 1. 方法：吸引不动点一侧怎么算（`_cbuild.py`）

区外的构造（base-plane-zh.md §4）要求两个不动点都排斥，超函数用正向迭代
F(z) = E^{n}(L + λ^{z−n})，Abel 函数用带分支延拓的反向迭代。进入 Shell–Thron 区后上不动点
L_up 变成吸引的（|λ_up| < 1）。只要 arg λ_up > 0，正则超函数 F_up(z) = L + u(λ^z)
（u 为 Schröder 反级数）在 Im z → +∞ 时仍趋于 L_up，Kneser 的刻画条件不变，只是求值方向反过来：

* **superf**：F(z) = E^{−n}(L + u(λ^{z+n}))，n 取到 |λ^{z+n}| ≤ s_max（≤ 0.05，或级数收敛半径的
  1/8）。n 步 log_b 的分支沿单位圆**解析延拓**：每一步取离上一个圆周采样点同一步链值最近的分支，
  第一个点取离 L 最近的——与区外 isuperf 的做法对称。
* **isuperf**：正向迭代 w → E(w) 到 |w − L| ≤ s_max/4，再用 Newton 反解 u，Abel 值
  log(s)/log λ − m，无分支问题；采样线上按周期 P = 2πi/log λ 去卷绕。
* **常数模要取模 P**：Abel 值只定义到 P 的整数倍，F_up 又是 P-周期的，所以 θ 的常数项只定义
  mod P。第一次实验在 1.8+1.15i（P ≈ 3.97 + 0.16i，几乎实）得到 θ ≈ −72（偏了 18 个周期），
  旧代码的阻尼 |θ| ≤ 3 把它截断，残差停在 0.12。改为把 θ 的均值约化到 |·| 最小的代表元。
* **阻尼上限不能是固定的 3**：随着基底逼近实轴，L_dn 跑向 β ≈ 7.86，下侧 θ_dn 的真实幅度
  从 1.3 涨到 5.6。1.3+0.5i 两次从不同种子都停在残差 0.05559，就是 |θ_dn| = 3.15 被截到 3。
  改为 max(3, 1.5·采样最大值)；吸引一侧不阻尼（反向迭代不会爆）。
* 拒绝 |λ| 与 1 相差 < 0.02 的基底（边界上没有双曲超函数）；`allow_attracting=False`（默认）
  行为与 0.3.3 完全一致：base 3 回归——6 轮、残差 1.7e-10、前 30 项系数与烘焙表差 2.0e-10。
* `CBuildResult.params` 新增 `attracting_up/dn`、`L_up/L_dn`、`lambda_up/dn` 以及最后一轮的
  θ 模 `fa_up/fa_dn`（诊断用）。

## 2. 路径

Shell–Thron 边界（|λ_up| = 1）在 2+1i 附近穿过（2+1i 本身 |λ| = 0.988，在拒绝带内），
所以跨边界这一步从 |λ| = 1.04 跳到 0.96：

```
3 → 3+0.5i → 2.6+0.7i → 2.4+0.9i → 2.16+1i ‖ 1.9+1.1i → 1.8+1.15i → 1.5+1i → 1.4+0.9i
  → 1.3+0.8i → 1.3+0.5i → 1.3+0.3i → 1.3+0.15i → 1.3+0.05i → 1.3+0.01i        （主路径）
1.4+0.9i → 1.42+0.6i → 0.4i → 0.25i → 0.15i → 0.08i → 0.04i → 0.02i → 0.01i     （η 侧）
1.42+0.15i → 1.44+0.15i → 0.08i → 0.04i → 0.02i → 0.01i
```

脚本按上一基底系数做种子；失败则二分（避开中性带）。实际只二分过一次
（2.4+0.9i → 1.8+1.15i 太远，插入 2.16+1i），其余每步一次成功。

## 5. 一个没解决的理论问题

D(b) := K(b) − R(b)（固定 z）在上半 Shell–Thron 区内应当是 b 的解析函数（两者都是），
在 1.3+0.3i 处 ≠ 0，却在实轴上三个点（1.3、1.42、1.44）沿竖直方向以 exp(−6/Im b) 消失。
如果 D 连续延伸到整段 (1, η) 并在那里为 0，Schwarz 反射会给出 D ≡ 0，与 1.6e-9 矛盾。
所以要么 K(b) 并非 b 的解析函数（构造每一步都收敛、残差 1e-10，但没有人证明我们跟踪的是
同一个解析族），要么 D 无法连续延伸到实段——exp(−C/Im b) 正是本质奇异行为而非解析性的
标志，(1, η) 可能是 K(b) 作为基底函数的自然边界，只是其边界值恰是正则解。
数值上分不清这两种情形；能说的是：**在 (1, η) 上，Kneser 延拓的极限就是库里的正则解，
到 12 位；区内它是另一个函数，差 exp(−(6±0.5)/Im b)。**

>    `Λ(b) = exp(4π²/log λ_up)`——它是周期差第一 Fourier 模被**强迫**的大小，不是拟合。
> 2. 该看的量是 `E = D/Λ`。

>    `Re b = 1.05/1.10/1.15` 处 `|D| → 1.009e-8 / 3.2402e-10 / 7.08e-12`，
>    `|E| → 6.02e-3 / 1.4086e-2 / 2.280e-2`。
>    **(1, η) 不是自然边界，但 Kneser 延拓在那里的极限也不是正则解。**
>    "到 12 位吻合"是当时仪器精度的假象。
> 4. **归属（当晚取得 Paulsen 2019 全文后补）**：上一条的**定性**部分是文献已有定理——
>    Paulsen 2019 §5 **Proposition 4**，解析反证。本文开头那句"论文摘要没提与正则解的比较、
>    所以只摆数值"是当时读不到全文的将就；**原文 §5 恰恰整节在讲这件事**。
>    本仓库独立重新发现了它，并额外给出文献没有的定量层（Λ 尺度与 `E` 曲线）。
>    Paulsen 给的例子是 `b=√2`：与正则解吻合到 **49 位**，`n=120` 时虚部现身 `−1.189e-48`；
>    换算成 `|E| = 0.0716`，正好落在本仓库测出的 `E` 曲线上（[base-separation-zh.md §4.4](base-separation-zh.md)）。
> 5. 另有两条原文事实本仓库此前不知道，对本文的构造有直接影响：
>    b-平面上从 `b=e^{1/e}` 起有一道"轻微割线"（`κ_{b+}` 与 `κ_{b−}` 互为共轭，因此 `√2`
>    在 Kouznetsov–Trappmann 的四个正则超指数之外还有两个 tetration）；
>    以及区内 `κ_b` 有**无穷多条自发割线**（`κ_i` 在 `z≈−3.810+0.1457i` 等处为零），
>    向左上延伸——这限制了 `_cbuild` 区内构建的可用域。见 [base-separation-zh.md §5.1.1](base-separation-zh.md)。
