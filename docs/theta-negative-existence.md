# 无限负模方程：紧算子障碍与有限可行性准则

**后续更新：** [周期拟共形构造](theta-qc-global-existence.md)已绕过
有限阶统一逆界，独立构造球内完整解析解，并通过正则逆支桥接
证明全部负模为零及其与原理想固定点相同。本文保留此前路线的
障碍分析与有限证书；此前的无限存在性缺口现已补上。
Kneser 规范身份仍单独待证。

2026-09-12。本文证明现有空间中直接使用有界 Newton 预条件器
不可行，并给出另一条严格的存在性归约。尚未证明归约中的所有
有限阶可行性条件成立。

## 1. 空间与导数

取实系数 Wiener 空间 A_r，范数为 Σ|c_j|r^j，切空间为 h(0)=0。
令 I 为 t+iδ（-1/2≤t≤1/2），ρ=sqrt(1/4+δ²)<r，η=ρ/r<1。
在已认证球 B(p,R) 上，选定的 A 分支解析且 |A'|≤L_A。
定义完整负模残差

    H(f)=(a_(-1)(f),a_(-2)(f),...) ∈ ℓ²(C),
    DH(f)h=P_-[A'(f(t+iδ))h(t+iδ)].

复 ℓ² 在这里按实 Hilbert 空间理解。P_- 是单位长度实区间上
Fourier 变换的负频投影，其 L²→ℓ² 算子范数为 1。
分支在更大的整球邻域上解析，故上述逐点求导和 Banach 空间
Fréchet 求导一致；有限长度积分也允许交换求导。

令 P_<N 保留次数 0,...,N-1，Q_≥N=I-P_<N。对 ||h||_r≤1，

    sup_I |Q_≥N h| ≤ η^N,
    ||DH(f)Q_≥N||_(A_r→ℓ²) ≤ L_A η^N.                 (1)

第一步直接对加权系数求和；第二步用乘子界和 Fourier 投影范数。
因此 DH(f) 是有限秩算子 DH(f)P_<N 的算子范数极限，是紧算子。
这不是“数值矩阵可能病态”的猜测，而是完整无限维导数的性质。

## 2. 为什么通常的有界 Newton 预条件器不成立

取单位向量 e_N(z)=(z/r)^N。由 (1)，

    ||DH(f)e_N||_2 ≤ L_A η^N → 0，  ||e_N||_r=1.

如果 DH(f) 有从其像空间（赋予 ℓ² 范数）到 A_r 的有界左逆 B，
则 1≤||B||L_Aη^N，对所有 N 成立，矛盾。因此它没有这种有界
左逆，更不能直接应用需要有界同构导数的隐函数定理。

更具体地，对任何有界实线性 B:ℓ²→A_r，

    ||(I-B DH(f))e_N||_r ≥ 1-||B||L_Aη^N,
    ||I-B DH(f)||_(A_r→A_r) ≥ 1.                     (2)

所以用 f↦f-BH(f) 构造严格收缩，在这两个范数下不可能成功。
若 B 随 f 可微变化，在一个真实根 H(f)=0 处，含 DB 的额外项
仍为零，(2) 的障碍继续存在。

对包含 e_N 的有限输入块，如果某个 B_N 左逆确实存在，则同理

    ||B_N|| ≥ 1/(L_Aη^N).                            (3)

输出再投影到有限负模只会缩小范数，不能消除这个下界。
本结论不排除使用更强的残差范数、函数空间尺度、解析延拓变量，
或其他方程的验证法；它只排除当前范数下的有界预条件方案。
原理想 θ 算子的收缩证书并未失效，因为其方程是 f-T(f)=0，
含一个恒等项，且不是 B H(f) 的上述表示。

## 3. 不需要逆算子的存在性准则

仍取同一个归一化闭球 B={p+u: u(0)=0，u 实系数，||u||_r≤R}，
其中 p(0)=1，p 为实系数多项式。
在 B 上使用较弱的拓扑：每个严格小于 r 的闭圆盘上一致收敛。

**紧性。** 任意序列 f_j=p+u_j∈B 的各阶系数均有界。对系数
作对角子序列抽取，得到极限 u 的全部实系数。对每个有限 K，

    Σ[k=0..K] |u_k|r^k ≤ R.

令 K→∞ 得 ||u||_r≤R。对 s<r，尾部一致受 R(s/r)^(K+1)
控制，所以所抽子序列在 |z|≤s 一致收敛到 p+u。故 B 在此
较弱拓扑下序列紧；可用一列 s↑r 定义度量，因此也紧。
这里没有错误地声称 B 在原 A_r 范数下紧。

**矩连续性。** 取 ρ<s<r，前述收敛在 I 上一致。已认证的更大
分支邻域保证 A 在这些函数值上连续，且 L_A 给一致 Lipschitz
控制，故每个 a_(-n)(f_j)→a_(-n)(f)。

由此得到三个等价命题：

1. B 中存在 H(f)=0 的函数。
2. 对每个 N，B 中存在使前 N 个负模精确为零的函数。
3. 存在 N_j→∞、ε_j→0 和 f_j∈B，使
   max_(1≤n≤N_j)|a_(-n)(f_j)|≤ε_j。

1⇒2⇒3 直接成立。3⇒1 时，抽取上述紧性子序列；固定任意 n，
当 j 足够大时 n≤N_j，由矩连续性和 ε_j→0 得 a_(-n)(f)=0。
不需要一致有界的 Jacobian 逆，也不需要将原范数中的 Cauchy 性
当作先决条件。

结合[负模拼接判据](theta-negative-modes.md)，一旦验证命题 2
或 3，就能完成精确拼接和已证明的条件延拓。在当前认证球内，
所得解也必定等于原理想算子的唯一固定点。

## 4. 完全有限维的近似可行性版本

对 d≥1，只允许

    f_d=p+Σ[k=1..d] u_k z^k，u_k∈R，Σ|u_k|r^k≤R。

令 ε_d=L_A Rη^(d+1)。则“B 中存在 H(f)=0”与下列条件等价：

    对每个 d，都能选取上述 f_d，使
    max_(1≤n≤d)|a_(-n)(f_d)|≤ε_d。                  (4)

必要性：若 f=p+u 是真根，取 f_d=p+P_≤d u。其加权距离仍≤R。
对整条连接线，分支导数界有效，故由采样尾界

    ||H(f_d)-H(f)||_2 ≤ L_A Rη^(d+1)=ε_d，

逐分量也成立。充分性直接用第 3 节命题 3，因为 η<1。
这里积分仍须严格计算；“有限维”指未知系数只有有限多个，
并不意味着可用未验证的有限深度或离散求积替代精确 a_(-n)。

**尚缺的量词是“对每个 d”。** 验证任何有限多个 d，或者在许多
截断阶数上观察到小残差，都不能独自建立 (4)。尤其不能从已经
认证的固定点距离 E 倒推一个负模全零的函数存在。

## 5. 有限阶数值探索的用途

`probe_theta_negative_feasibility.py` 使用 2N 个实系数扰动来求解
前 N 个复负模方程，保持常数项为 1。采用 170 位运算、600 层
正则逆迭代和连续 Gauss 积分，并以更多积分节点和更深迭代复查。
所有计算在 galic 执行。

该程序用于检查有限系统是否出现明显不相容或解离开认证球，
**没有使用向外取整区间算术**，所以不颁发有限精确可行性证书，
更不证明对所有 N 的统一可行性。其结果另存为 probe.json，
不混入前一轮的严格区间证书。

整段 Gauss 积分的初版没有通过换节点复查：例如 N=8 的复查
残差约 2.34e-18。因此初版的解离球现象是求积不可靠的表现，
不能据此否定有限系统的可行性。改成 16 个小区间、每段 48 个
Gauss 节点后，以 24 段及 640 层复查，N=2、4、8 的复查残差
分别约为 2.34e-84、6.40e-84、7.71e-83，扰动范数均约 2e-52。
这些数值仍只属于探索；下面另用区间方法证明有限存在性。

## 6. 已完成的有限精确存在性证书

取 f_u(z)=p(z)+Σ[j=1..2N]u_j(z/r)^j，u_j 为实数。
因此 ||f_u-p||_r=||u||_1。令 F_N(u) 依次列出前 N 个负模的
实部与虚部，得到 R^(2N)→R^(2N) 的解析函数。

中心 Jacobian J_N=DF_N(0) 的区间包络通过 64 段、96 阶 Taylor
积分计算，包含正则逆导数的有限深度误差；不是未经验证的 Gauss
探索结果。用区间逆构造精确 dyadic 实矩阵 B_N，再验证

    q_B=||I-B_N J_N||_1<1，
    ||J_N^(-1)||_1 ≤ K_N=||B_N||_1/(1-q_B).

检查器对所记录的 Jacobian 区间和 B_N 进行独立的精确有理区间
乘法，复核这个逆界。

整个复球的原半径为 R_0=10^-6。采样包络在函数值方向至少含有
半径 a=R_0 δ/r 的圆盘，因为每个采样输入圆盘的模上界≥δ。
原分支证书在该圆盘上给 |A'|≤L_A。对 ||u||_1≤R_f=10^-30，
Cauchy 导数估计及线段积分给出

    ||DF_N(u)-DF_N(0)||_1
      ≤ v_N=2N·2L_A R_f/(a-R_f).

每个输出实分量用复模控制，输入基函数在采样段的模不超过 1；
上式已计入全部 2N 个实输出分量。因 R_f<a，分支始终有效。

令 d_N 为已认证中心负模矩形给出的 ||F_N(0)||_1 上界。
映射 u↦u-J_N^(-1)F_N(u) 的收缩常数至多 q_N=K_N v_N。
已验证 q_N<1 且 K_N d_N/(1-q_N)<R_f，故 Banach 定理给出
该有限系统在此球内的唯一实根，并有下列距离界：

| 复负模数 N | 实变量数 | ||J_N^(-1)||_1 上界 | ||f_N-p||_r 上界 |
|---|---:|---:|---:|
| 2 | 4 | 26.288 | 4.659e-49 |
| 4 | 8 | 694.699 | 2.457e-47 |
| 8 | 16 | 773034 | 5.456e-44 |

这些是**有限精确方程的存在性结论**，不是把浮点小残差视为零。
三个有限根都位于原半径 10^-18 的认证球内，但它们可能彼此不同；
没有证明它们各自满足所有负模方程，也没有把它们当作原 θ 算子
的固定点。

[有限根证书](certificates/finite-negative-roots-e50/certificate.json)包含
源码快照和复核日志。9 项正常/篡改检查通过，涵盖错误的逆界、
中心残差、Jacobian 变化量、距离、标量分支域，以及虚假的无限
存在性和 Kneser 标记。检查器仍依赖冻结源码、FLINT 和 mpmath
生成的原始 Jacobian 包络，不是逐算术步骤的证明助手证书。

当前已把第 3 节的有限可行性条件严格验证到 N=8；尚未取得对
任意 N 的统一证明，所以精确无限拼接及 Kneser 身份仍未完成。
