# 超运算阶梯纲领：把 Λ 判据推到四级以上

2026-09-17。立项文档。本文记录第 0 阶段（文献扫除）的结论、第 1 阶段（五级运算
原型）已得到的数，以及后续阶段的定义。**本文不声称任何新定理**；新的只有

## 0. 一句话

四级以上的每一级运算，**都同时存在两种构造**（实不动点的 Koenigs，与复共轭
不动点对的 theta/Kneser），文献里**没有任何人测过两者之差**。本仓库把它测出来了。

**当前状态（2026-09-17）**：五级运算两个解都已构造，差已测到：

```
e↑↑↑½  正则 / Koenigs 解  = 1.63232474043606...
e↑↑↑½  Kneser 型解        = 1.63235385715702...
D(1/2) = 2.9117e-5        两组独立参数吻合 6 位有效数字
```

⚠ 立项时的定量预言（`D ~ Λ = 6.46e-10`）**被自己的测量证伪**，差 4.7 个数量级（§4.5）。
定性结论（两解必不同）反而被加强为结构性论证（§4.4a）。
四个底数扫完后得到的经验律 `h = 0.4217·(T+1)`（§4.8d）含一次样本外命中
（底数 5，差 1.0%），但**第六个底数把它破掉了**（底数 1.7，差 9.6%，§4.9）。
§4.10 查清了原因：`b_c ≈ 1.634` 处复共轭不动点对 `z*, conj(z*)` **撞到实轴**
变成两个实不动点；`b < b_c` 时 Kneser 型五级运算**不存在**。底数 1.7 离这个
退化最近，所以它是破坏者。`h` 不是 `T` 的单变量函数——同 `T` 的对照底数上
`h` 甚至没有定义。碰撞底数已精确测定：**`b_c = 1.63532449671528`**，
它是 `η = e^{1/e}` 在上一级的对应物（五级塔的收敛边界、抛物不动点），见 §4.11。
六级 `b_c6 = 1.73735592515169`、七级 `b_c7 = 1.79912060`（§4.12、§4.16）——
但它们**依赖于用哪个五级运算**，五级的非唯一性一层层往上传染。

## 1. 阶梯的结构（已知，非本仓库发现）

命名归 Goodstein 1947，箭头记号归 Knuth 1976，`Adv. Math.` 上的
Blakley–Borosh 1979 讨论 Knuth 迭代幂。第 `n` 级运算是第 `n-1` 级的超函数：

```
P_n(z+1) = P_{n-1}(P_n(z)),     P_n(0) = 1
```

关键结构事实是**不动点的实/复交替**（Tetration Forum thread 1177，
sheldonison；本仓库在第五级上独立复核了实不动点那一半）：

| 级 | 名称 | 被迭代的映射 | 该映射的最低不动点 | 可用构造 |
|---|---|---|---|---|
| 4 | tetration | `E_b(w)=b^w` | `b>η` 时**复共轭对** | Kneser / theta |
| 5 | pentation | `sexp_b` | **实**，排斥 | Koenigs / Schröder |
| 6 | hexation | `pen_b` | **复共轭对** | theta |
| 7 | heptation | `hex_b` | **实** | Koenigs |
| 8 | octation | `hep_b` | 复共轭对 | theta |

所以难度是**交替**的：奇数级便宜（实双曲不动点 ⟹ Koenigs 直接给典范解），
偶数级回到 Kneser 难度。sheldonison 用这个交替算到了 heptation，25–30 位。

## 2. 文献扫除（第 0 阶段）的结论

**已经做掉的：**

- Kouznetsov 的 "natural pentation"（Citizendium）：复平面图、割线、周期，
  构造就是"tetration 最低实不动点处的正则迭代"。给出三个常数（见 §3 对照）。
- sheldonison（Tetration Forum thread 1177）：pentation / hexation / heptation
  到 25–30 位。hexation 用 pentation 的复共轭不动点
  `−2.2597543772948619217694227344490 ± 1.3844243840414798988939409459371i`

## 3. 第 1 阶段：五级运算原型（已完成）

脚本 [`demo_pentation.py`](demo_pentation.py)。设计要点是**不做迭代式外推**：
`sexp` 在 `x*` 处的 Taylor 级数由库里 150 项 0 点系数**解析地**平移＋复合 `log`
得到（`sexp(x*+t) = log(sexp(x*+1+t))`，而 `x*+1 = −0.850…` 深在收敛圆内）。
这避开了 `λ^n` 放大——即 [base-separation-zh.md §3](base-separation-zh.md)
那个 `dps=30` bug 的同类陷阱。朴素做法 `σ(x)=lim λ^n(slog^n(x)−x*)` 在 `n=40`
就被 `λ^40 ≈ 10^32` 吃光，实测确认。

**自洽检验**：`P(z+1)=sexp(P(z))` 在本设计下是**同义反复**（求值本身就是往前
迭代 `sexp`），不能用。真检验是"级数/迭代分界点无关性"：把级数求值多推
1 步和 3 步、再多迭代同样步数，结果必须不变。实测 `dps=55` 下最差 `1.77e-45`。

### 3.3 分裂尺度：这一级为什么便宜

同一机制（两个 Abel 函数之差是 1-周期函数，第一 Fourier 模被强迫，见
[base-separation-zh.md §2](base-separation-zh.md)）：

```
Λ = exp(-4π² / log λ) = exp(-2π·|P|)
```

第二种写法值得记：**分裂尺度就是 `exp(−2π × 周期)`**。

| | `\|log λ\|` | `Λ` |
|---|---|---|
| 四级，`b=√2` | 0.3665 | **1.66e-47** ← Paulsen 用 120 位才看见 |
| 四级，`Re b=1.10` | 0.6459 | 2.30e-08 |
| **五级，base e** | **1.8657** | **6.4632e-10** |
| **五级，base 2** | **1.6432** | **3.68e-11** |

`λ` 越大，`4π²/log λ` 越小，分裂越**不**指数小。

⚠ **2026-09-17 更正：下面这句话是错的，已被 §4.5 的测量证伪。**

### 4.1 通用 Koenigs 引擎（已完成，2026-09-17）

`src/kneser/_koenigs.py`。输入是**映射在双曲不动点处的 Taylor 级数**，输出是
超函数。这是"任意级"的前提：每往上一级，被迭代的映射就换一个，但这一步不变。

关键设计是**两种双曲性统一处理**，二者的差别只在怎么离开收敛圆：

| | `\|λ\| < 1` 吸引 | `\|λ\| > 1` 排斥 |
|---|---|---|
| `\|λ^z\|` 小的方向 | `z` 大 | `z` 很负 |
| 平移 | 向**上** | 向**下** |
| 走回来用 | **逆**映射 | **正**映射 |
| 实例 | 四级 `1<b<η`（`_regular.py`） | 五级（`sexp` 在 `x*`） |

两种情形下级数都只在收敛圆内求值，离开收敛圆的每一步都是映射的精确应用，
所以没有任何东西被 `λ^n` 放大。

**`_regular.py` 已改为委托。** 原来那份 Schröder 递推（用 `exp(lb·u(s))` 的
指数递推写的）被删掉，改调 `_koenigs.inverse_schroeder`——`b^w` 只是
`τ(t) = α(e^{t log b} − 1)` 这一个特例。这样库里**只有一份**这套数学，
四级和更高级不可能各自漂移。全套 **118 项测试在委托后仍全绿**。

新测试 `tests/test_koenigs.py`：吸引侧逐系数、逐值对齐 `_regular.py`（`<1e-25`）；
`τ(u(s)) = u(λs)` 的直接代入检验；排斥侧锚点 `P(-2)=-1, P(-1)=0, P(0)=1, P(1)=e`；
分界点无关性；非双曲（`λ=0`、`|λ|=1`）与缺映射时报错而不是给错答案。

⚠ 尚未做：复 `λ`。递推、`smax`、走位逻辑都写成了 `abs()` 判断、不假设实数，
但**没有测过**——六级运算（`pen` 的复共轭不动点对）会第一次真正用到它。

### 4.2 第 2 阶段开工日志（2026-09-17）：找到不动点，撞上数据边界

**(a) `sexp` 的复不动点对已定位。**

```
z*  = 0.76486671805370274 + 1.52989742339457665 i        (约 17 位可信，见下)
mu  = sexp'(z*) = -0.015695466920280 + 0.672397316701763 i
|mu| = 0.67258047785345        ->  吸引
log mu = -0.39663350499543 + 1.59413463700997 i
周期 2 pi i / log mu = 3.71166716946453 - 0.92349261136591 i   （不是纯虚）
exp(-4 pi^2 / |log mu|) = 3.656e-11
```

矩形 `Re[0.4,1.3] × Im[1.30,1.72]` 上的辐角原理给绕数 **1**，即其中**恰好一个**零点；

### 4.3 上半平面求值器（已完成，2026-09-17）：§4.2 的阻塞已解除

[`demo_upper_half.py`](demo_upper_half.py)。用 Kneser 自己的表示

```
sexp(z) = superf(z + theta(z)),    theta 1-周期、只含非负 Fourier 模
```

`superf` 是 `exp` 在 `L = 0.3181315052047641353 + 1.3372357014306894089i` 处的
Schröder 超函数（`mu = e^L = L`，`|mu| = 1.3746`，排斥）——由 §4.1 的通用引擎
直接给出，`tau_m = L/m!` 就是 `tau_of_exponential(e, L, K)`。
`theta` 在库可靠的高度 `delta = 1.2` 采样、Fourier 分解，然后往上用。
**模在上半平面衰减，所以越往上这个表示越准——与表的行为正好相反。**

**三条验证，没有一条是循环的：**

1. **负模必须是噪声。** 理论说 `theta` 只有非负模。实测最大负模幅度 `3.5e-32`，
   而 `|a_0| = 1.04`，比值 `3.4e-32`。这是对整个构造的结构性检验。
2. **在一个高度拟合，在另一个高度对照。** `delta = 1.2` 拟合，与 `hp.sexp` 比：

   | Im | 与 `hp.sexp` 之差 |
   |---|---|
   | 1.25 | 6.17e-30 |
   | 1.30 | 1.31e-27 |
   | 1.35 | 2.08e-25 |
   | 1.40 | 2.85e-23 |
   | 1.45 | 3.39e-21 |

   ⚠ **差值随高度增长，增长的是 `hp.sexp` 不是求值器。** 表的截断误差按
   `(|z|/2)^150` 走：从 Im 1.40 到 1.45，`(1.534/1.4866)^150 = e^{4.71} ≈ 111`，
   实测比值 `3.39e-21/2.85e-23 = 119`。对上了。所以这张表是 **`hp.sexp` 的误差上界**，
   不是求值器的。求值器自身误差由丢掉的第一个模定：
   `|a_8| e^{-2π·8·1.2} ≈ 4.3e-29`，且向上递减。

### 4.4 第 2 阶段（2026-09-17）：定性问题被结构定死，定量问题仍开着

[`demo_pentation_theta.py`](demo_pentation_theta.py)。

**(a) 两个解不同，是被乘子强迫的，不需要数值。**

`P_K`（`x*` 处 Koenigs）的 `log λ = 1.8657` **纯实** ⟹ `|λ^w|` 只依赖 `Re w`
⟹ `P_K` 沿虚方向**恰好周期**（`2πi/log λ = 3.3677i`），`Im w → ±∞` 时**无极限**。
`Q`（`z*` 处 Koenigs）的 `log μ_c = −0.3966 + 1.5941i` 复 ⟹ `Q(w) → z*`。
一个竖直周期、一个有竖直极限，**必然是不同的函数**。

这正是 [base-separation-zh.md §5.5](base-separation-zh.md) 在四级上认出的机制
（"实段上 `arg λ_up = 0`，这一项与 `y` 无关，`R` 沿虚方向恰好周期"），在五级重现。
所以 sheldonison 那句 "doesn't seem particularly unique" 的定性部分可以结案：
**确实不唯一，而且理由是结构性的。**

**(b) 一个让实验可做的偶然：`z*` 是吸引的。**

若 `z*` 是排斥的，这一步就得先写复 `slog`。

**(c) `ρ(w) = Q^{-1}(P_K(w)) − w` 已算出并验证。**

| 检验 | 结果 |
|---|---|
| `P_K(w+1) = sexp(P_K(w))` | 1.5e-36 |
| `Q^{-1}(sexp(x)) − Q^{-1}(x) = 1` | 精确到 1.9e-37 |
| **`ρ(w) = ρ(w+1)`（真 1-周期性）** | **1.5e-36** |

最后一条是决定性的，而且它在**落盆步数不同**（7 步 vs 6 步）时仍成立——
这排除了迭代计数带来的系统偏差。`N=16` 与 `N=24` 给出完全相同的模（8 位全同），无混叠。

**(d) `ρ` 的解析带：`0.246 < Im w < 1.683`。** 由两侧模衰减读出

`e^{-2π|n|(b−y₀)}`（`n<0`）；采样线 `y₀=1.0` 在带内）。

`|c_{-1}|/Λ = 7.8e6` 这类数字**没有意义**，因为分子是 `y₀=1.0` 处的量。

`ρ` 这个对象有了 1e-36 的计算；以及一条把路堵住的具体事实（`ρ` 够不着实轴）。

### 4.5 五级 theta 迭代跑通，`D` 测到了，而 Λ 预言**被证伪**

[`demo_pentation_build.py`](demo_pentation_build.py)。照 `kneser.build` 的骨架上移一级：

#### ⚠ Λ 预言被证伪

本纲领 §3.3 写的是"五级运算的两个候选解如果不同，差在 `1e-10` 量级"。
**测量结果是 `2.91e-5`，即 `D/Λ = 4.5e4`，差了 4.7 个数量级。这条预言是错的。**

一个自洽的解释（**推测，未验证**）：四级 base-separation 里 `D` 之所以指数小，
是因为那里在取**极限**（`Im b → 0`），而 Kneser 的两端极限刻画恰在实段上退化
（[base-separation-zh.md §5.5](base-separation-zh.md)）——指数小来自这个退化。
五级这里**没有极限、没有小参数**：`sexp` 同时拥有一个实不动点和一对可用的复不动点，
两种构造就是各自成立、直接不同。`Λ` 约束的是同一个周期差**在不同高度之间的比值**，
不是这个差本身的大小；四级在退化极限下模的大小被压到 `Λ` 尺度，五级没有东西压它。

这个解释可证伪：它预言若让底数 `b` 变化、逼近使结构退化的那个底数，
五级的 `D` 才会显出 `Λ` 行为。

⚠ **已做，见 §4.6：这个解释的前提不成立——那个退化底数不存在**
（`λ(b)` 有极小值 4.78，从不接近 1）。修正后的说法在 §4.6(e)。

### 4.6 扫底数：§4.5 那个解释的**前提就不成立**

§4.5 给的解释是"四级的指数小来自退化极限，五级没有小参数；若逼近某个退化底数，
`D` 才会显出 `Λ` 行为"。本节去找那个退化底数。**没有找到——它不存在。**

**(a) `λ(b)` 有极小值，从不接近 1。** `sexp_b` 最低实不动点的乘子：

**(b) 副产品：确实有一个退化，但不是这个不动点的。** 上方实不动点在

**(c) 换一个更合适的观测量。** `D(z)` 受相位影响（底数 3 上

正确的量是 `P_K` 自己的 Abel 坐标下的周期差


它的**第一 Fourier 模**才是 `Λ` 该标定的东西。实测（`nt=28, ncirc=128, modes=12, dps=38`）：

| base | `Λ` | `\|eps_1\|` | `\|eps_1\|/Λ` | 离散化噪声底（fe.res） |

| e | 6.463e-10 | **9.4381e-6** | 14603 | 4.7e-10 |

⚠ `eps_2..eps_4` 落在 `3e-10 … 2.6e-9`，**与 fe 残差同量级——那是噪声底，不是信号**。
它们碰巧和 `Λ` 同量级，容易被误读成"高阶模坐落在 Λ 尺度上"。不要这么读。
真信号只有 `eps_0`、`eps_1`，都在 `1e-5`。

**(d) 判定。** `Λ(3)/Λ(e) = 2.67`，而 `|eps_1|(3)/|eps_1|(e) = 1.51`。不吻合。

这是一个方法论错误，不是一个算错的数。

### 4.7 底数 2 为什么跑不出来：不是性能，是那个绕法有适用边界

§4.6 把底数 2 的失败归给"阻尼 Newton 太贵"。**归错了。** 优化并重测后：

**(a) 求解器优化是有效的，但不解决问题。** 改成沿圆周延拓 + 割线法
（每步 1 次 `Q^{-1}` 而不是 3 次）。底数 e 逐位复现原结果
（`max|dc|` = 0.00093398 / 4.3946e-5 / 6.7853e-6，与优化前完全一致），
每点 9.6 次 `Q^{-1}`。底数 2 则是每点 24.4 次、73 秒，而且 loop 0 一步就把系数
移动 **0.378**（底数 e 是 0.00094，差 400 倍），fe 残差 0.25——**这是错，不是慢。**

**(b) 逐项排除。**

| 嫌疑 | 检验 | 结论 |
|---|---|---|
| 圆周半径 1 碰到 `P` 的奇点 | `r = 0.5/0.8/1.0` 的 Cauchy 系数 | 三个半径一致到 `1.6e-28`，**安全** |
| `θ` 的 unwrap 绕圈 | 绕数 | `wind = 0`，**正常** |
| `θ` 的模不衰减 | 模表 | 负模 `6.5e-5 → 2.2e-16`，正模光滑衰减，**正常**；底数 2 的 `\|θ_{-1}\|` 比底数 e **还小** |
| 实轴带分支 | 与 `P_K` 对照 | 底数 e `1.6e-11`、底数 2 `1.6e-13`，**正常** |
| **上半分支** | 与 `P_K` 对照 | 底数 e 残差 `2e-31` 正常；**底数 2 即使用正确初值 `P(z)` 也解不出，残差 5483（≈1400 个周期）** |

**(c) 根因：§4.4(b) 那个"幸运"是有边界的。** 当时的绕法是——`Q` 要从 `z*` 往外走
需要复 `slog`，于是改成"对 `Q^{-1}` 求解"，因为 `Q^{-1}` 只需正向 `sexp`。
但这只在**目标值仍落在 `z*` 的吸引域内**时成立。底数 e 落在域内；
底数 2 不落在域内——`θ_0` 从 1.05 涨到 **1.85**，把目标推到了吸引域外，
于是方程在可达范围内**根本没有解**，跟初值好坏、Newton 阻尼都无关。

**所以底数 2 需要真正的复 `slog` 外走**，也就是 §4.4(b) 当初庆幸避开的那件事。
这不是调参能过的坎。

**后续**：这项基础设施已在 §4.8 做出来，底数 2 通了，四个底数的扫描完成。

### 4.8 复 slog 做出来了，底数 2 通了，而且扫出一条经验律

**(a) 外走轨道 + 分支跟踪。** §4.7 定位的根因是"`Q` 往外走需要复 `slog`"。
现在做了：`q_chain(w, nsteps, prev)` 从 `z* + u(mu_c^{w+n})`（在 `u` 的收敛圆内）
出发，逐步用 `slog_c`（对 `sexp` 做 Newton）往外走 `n` 步。三个设计要点：

1. **用真实收敛半径，不用 `smax`。** `Q.u` 的比率检验给 `Ru ≈ 0.85`（base e）、
   `1.03`（base 2），而 `_koenigs` 的 `smax` 被 `_SMAX_CAP` 压在 0.05——保守了 17–20 倍。
   改用 `0.5·Ru` 后步数从十几步降到 6–7 步。
2. **沿圆周做轨道级延拓。** 相邻圆周点的整条轨道都接近，所以第 `i` 步的初值取
   上一个圆周点第 `i` 步的值。超出 `u` 圆盘之后这是唯一靠谱的初值来源。
3. **从最容易的点起扫，向两侧走。** ⚠ 这一条是踩坑踩出来的：一开始按 `j=0,1,2,…`
   顺序扫，第一个点没有 `prev`，远端几步只能用线性化猜测，**分支跟丢并沿圆周传播**，
   底数 e 的 `max|dc|` 从 0.00093 变成 **0.858**。改成从 `|mu_c^w|` 最小的点起扫即修复。

**验证**：底数 e 的 `max|dc|` 三轮为 `0.00093398 / 4.3946e-5 / 6.7853e-6`，

**幅度由 `P_K` 的竖直周期决定，不由 `Λ` 决定**，而 `Λ = exp(−2πT)` 只是 `T` 的
另一个函数——两者都由 `log λ` 决定，但依赖方式不同（`h` 线性于 `T`，
`−ln Λ` 也线性于 `T`，斜率分别是 `0.4217` 和 `2π`）。

### 4.9 第五、六个底数：律**不是恒等式**，在 `T` 的折点处破掉

§4.8(d) 的 `h = κ(T+1)` 是四点一参数、四位有效数字。加两个底数检验。

**(a) 先要解决一个结构障碍：`z*(b)` 会下沉。**

| b | 2 | e | 3 | 5 | **1.7** | **20** |
|---|---|---|---|---|---|---|
| `Im z*` | 1.66 | 1.53 | 1.47 | ~1.3 | **1.214** | **0.948** |

有效区之外**——底数 1.7 和 20 都卡死在 `z*` 求根那一步（进程 0% CPU，不是在算）。
把 `δ_U` 做成可调即解决；`δ_U` 必须低于 `Im z* − r`（`r=0.3` 是 Cauchy 圆半径）。

**(b) 底数 20 作废。** `Im z* = 0.948`，Cauchy 圆探到 `Im 0.648`，即使
`δ_U = 0.70` 也不够。跑出来 `max|dc| = 0.139`、`fe.res = 0.138`、`ε₂ > ε₁`

**(d) 对照实验排除了混淆。** 底数 1.7 用 `δ_U = 0.80`，前四个用 `1.20`。
把底数 e 用 `δ_U = 0.80` 重跑：`|eps_1| = 9.4380523e-6`，与原来**逐位相同**。

**(e) 五点全表。**

**(f) 为什么偏偏是 1.7：它坐在折点上。** §4.6(a) 测到 `λ(b)` 有**极小值**

样本外命中（底数 5，1.0%）和这次失手合起来的意思是：律在远离折点处好用，

⚠ **一条操作教训**：底数 1.7 跑 3 轮（粗设置）时 `|eps_1| = 1.8229e-6`，

（`λ` 吻合 9.7e-12）。结果比预想更强：`b'` 上**根本没有复共轭不动点对**，
Kneser 型解不存在，所以不是"同 `T` 而 `h` 不同"，是"同 `T` 而 `h` 未定义"。
折点的机制也查清了：`b_c ≈ 1.634` 处复对撞上实轴变成实不动点。

### 4.10 折点另一侧：检验做不成，而**做不成正是答案**

§4.9(g) 提的检验是：在折点另一侧找同 `T` 的底数，看 `h` 是否不同。

**(a) 匹配底数找到了，精度很高。** `T` 由 `λ` 唯一决定，所以只需匹配 `λ`：

```
b  = 1.7              lambda = 4.844816970908589    x* = -1.663135725151147
b' = 1.39517587855    lambda = 4.844816970918261    x* = -1.536022531767544
                      两者差 9.7e-12,  T = 3.98196818999 相同到 12 位
```

同 `T`，`x*` 却完全不同——正是需要的对照。而且 `b' < η`，走 `_regular` 路径，
**没有 Taylor 半径上限、复参数直接可算、不用建表**（为此给脚本加了 `b<η` 分支：
`sexp_any` 直接用 `hp.sexp`，`x*` 与 `z*` 处的级数一律用 Cauchy 积分取）。

**(b) 但 `b'` 没有复共轭不动点对。** `sexp_{b'}` 是正则解，沿虚方向周期
`2π/|log λ_α| = 13.035`。扫满一整个周期（`Re ∈ [−1.9, 7.1]`，`Im ∈ [0.1, 13.5]`）
只找到**两个实**不动点：

```
-1.536022531767544   |mu| = 4.844816971   排斥   <- 就是 x*（匹配值，符合设计）
 1.510808681788187   |mu| = 0.190967706   吸引
```

**没有复共轭对 ⟹ 没有可拼接的一对 ⟹ Kneser 型五级运算在这个底数上不存在。**
所以不是"同 `T` 而 `h` 不同"，是**同 `T` 而 `h` 根本没有定义**。
这比原计划的检验更强：`h` 当然不可能是 `T` 的单变量函数。

**(c) 顺带查清了折点的机制。** 追踪 `z*(b)` 随 `b` 下降：

这和 §4.6(b) 里"上方那对实不动点在 `b ≈ 1.635` 湮灭"是**同一个事件**：

它是 `h(T)` 律的破坏者——毫不意外：构造本身正在退化。

### 4.11 `b_c` 精确测定：它是**五级运算的 η**

`b_c` 的定义方程是**双重不动点**（碰撞时乘子为 1，即抛物）：

```
sexp_b(x) = x        且        sexp_b'(x) = 1
```

等价地，`m(b) := min_{x>1} (sexp_b(x) − x)` 过零。`m` 对 `b` 光滑，
所以割线法收敛快，每步只需一次建表（`b` 每变一次就要重建 tetration 表，约 65 秒）。

```
m(1.60)  = -0.43869019
m(1.645) = +0.09027113
it0  b=1.6373204198316   m= 1.9477e-2    x_c=3.054576290264
it1  b=1.6352076026472   m=-1.15517e-3   x_c=3.090538773192
it2  b=1.6353258966326   m= 1.38244e-5   x_c=3.088508254106
it3  b=1.6353244976954   m= 9.67898e-9   x_c=3.088532254991
it4  b=1.6353244967152   m=-7.54464e-13  x_c=3.088532271808
末步修正 (m' = 9.8753):
```

```
b_c = 1.63532449671528            (约 13 位，受 20 位表限制)
x_c = 3.088532271808028           (双重不动点位置)
```

**独立验证**：在 `b_c` 处
`sexp'(x_c) − 1 = 2.21e-24`（抛物条件，由 `x_c` 的定义精确成立）、
`sexp(x_c) − x_c = −7.54e-13`（不动点条件，即残余的 `m`）。
两侧结构：`b=1.6300` → `m=−0.0543`，`x>1` 有实不动点（`2.713174186`）；
`b=1.6400` → `m=+0.0449`，`x>1` **无**实不动点（即复共轭对）。

**这个常数是 `η` 在上一级的对应物。** 形式完全平行：

| | 四级 | 五级 |
|---|---|---|
| 被迭代的映射 | `b^x` | `sexp_b(x)` |
| 临界底数处 | 双重（抛物）不动点在 `x = e` | 双重（抛物）不动点在 `x_c = 3.0885322718` |
| 临界底数 | `η = e^{1/e} = 1.44466786100977` | `b_c = 1.63532449671528` |
| 闭形式 | 有 | **不知道** |
| 低于它 | 四级塔 `b, b^b, …` 收敛 | 五级塔 `1, b, b↑↑b, …` 收敛 |
| 高于它 | 四级塔发散；`b^x` 有复共轭不动点对 ⟹ Kneser 构造存在 | 五级塔发散；`sexp_b` 有复共轭对 ⟹ Kneser 型五级运算存在 |

数值确认（五级塔从 `P(0)=1` 出发迭代 `sexp_b`）：
`b=1.63` 收敛到 `2.71317376407`；`b=1.6353`（刚好在 `b_c` 下方）收敛到 `3.02707507065`；
`b > b_c` 时 `m > 0` 意味着 `sexp_b(x) > x` 对所有相关 `x` 成立，塔单调发散。

**归属**：Tetration Forum 上 sheldonison 说过"底数 ≲1.635 时 `sexp(z)` 有上不动点、
五级运算有界"——**存在性是已知的**。本轮的贡献是把它定到 13 位、给出抛物刻画
（`x_c` 也一并定出），并指出它就是 `η` 的上一级对应物。

⚠ 未做：`b_c` 的闭形式（`η = e^{1/e}` 有，`b_c` 未必有）；更高位数
（受表的 20 位限制，不是方法限制）。**六级的对应常数已算，见 §4.12**——
并且在那里发现了一件重要的事：`b_c5` 典范而 `b_c6` **不典范**。

#### ⚠ `b_c6` 不是唯一确定的，`b_c5` 是

这一条是本纲领整条线索的汇合点，必须写清楚：

- **`b_c5` 典范**。它只依赖 tetration，而 tetration 是唯一的
  （Kneser 存在性 + Trappmann–Kouznetsov 唯一性）。所以 `b_c5` 是一个确定的常数。
- **`b_c6` 不典范**。它依赖**五级运算**，而五级运算**不唯一**——这正是
  §4.4–§4.9 测出来的事：正则/Koenigs 解与 Kneser 型解相差 `|eps_1| ~ 1e-5–1e-6`。

上表的 `b_c6` 用的是**正则 / Koenigs 五级运算**（Kouznetsov 的 "natural pentation"）。
换成 Kneser 型解，`b_c6` 会移动约 `|eps| / m6' ≈ 1.7e-6 / 16.54 ≈ 1e-7`——
**即第 8 位起就不同了**。（`1.7e-6` 取自 §4.9 测得的底数 1.7 的 `|eps_1|`；

### 4.13 五级运算的上半平面求值器（六级的前置，已完成）

[`demo_upper_half_pen.py`](demo_upper_half_pen.py)。七级常数要六级运算，
六级在交替表里是 theta 侧，必须建在**五级运算的复共轭不动点对**上，
所以第一步是能在 `z*_5`（`|z*_5| = 2.65`，远在 `demo_pentation_build.py`
所产半径 1 的圆盘之外）取到五级运算的 Taylor 数据。

**它比四级的同级物轻得多，原因值得写下来。** 正则五级运算是

```
P(z) = x* + u(C·lam^z),     lam = sexp'(x*) = 6.4607  是实数
```

`|lam^z| = exp(Re z · log lam)` **完全不依赖 Im z**——外走步数只由实部决定。
限制可达性的只是中间轨道 `w_{k+1} = sexp(w_k)` 会不会跑出 `sexp` 能算的范围，
而那正是 §4.3 的求值器解决的事。**把 §4.3 接进来当 `sexp` 后端就是全部技巧。**

实测可达性表（行 `Im`，列 `Re`，格内是所需 `sexp` 步数）：

| Im \ Re | −3.0 | −2.0 | −1.0 | 0.0 | 1.0 |
|---|---|---|---|---|---|
| 0.5 … 5.0 | 1 | 2 | 3 | 4 | 5 |

**六行完全相同——没有虚部上限**，步数只随实部走，与上面的推理一致。
分界点无关性（`extra = 1, 3`）最差 `3.886e-38`，含 `z = −2.5 + 2.4i`。

**外部验证：sheldonison 的 31 位全对。** 把他公布的五级运算复不动点

```

```

代入**本仓库独立搭的**五级运算，残差 `|P(z) − z| = 1.64e-31`；精化后与公布值
差 `5.39e-32`，即 31 位全部吻合，精化后残差 `4.54e-40`。

### 4.19 临界底数的上界是 2，不是 e；极限不普适（2026-10-02）

### 4.21 包络陷阱：什么迫使下一级塔收敛（2026-10-02）

**命题 D [证].** `f` 在 `[0, L]` 上不减，`f(1) = b ∈ (1, 2)`，`L = 1/(2−b)`，
并且 `f(x) ≤ 1+(b−1)x` 对 `x ∈ [1, L]`。则 `1, f(1), f(f(1)), …` 收敛，
所以这个 `b` 不超过下一级的临界底数。斜率不增加上 `f(0) = 1` 推出该包络。
证明与四级上的数值在 [rank-tropical-limit-zh.md](rank-tropical-limit-zh.md) §7。

四级（Kneser `sexp`）把命题用到底：包络在 `b ≤ 1.62` 成立，`b_c5 = 1.6353`，
只松 `0.015`。`b = 1.65` 时包络超出 `0.133`，与塔发散一致；同时
`sexp(1/2) = 1.340 < 1.5`，所以「不越过 `1+z`」救不了它。

七级上同一条包络没有给出新的下界。`b = 1.845`（只比 `b_c8` 高 `0.005`，
`m8 = +0.169`）时 `Hep` 在 `z = 4.75` 就已经越过 pentation 的截断（值是超过 6 的塔），
而包络直线在那里只有约 `5.0`，`L = 6.45` 还没走到。`b = 1.86, 1.90, 1.94`
溢出更早（`z = 4.26, 3.53, 2.96`）。`b_c9 ≥ 1.83976` 仍然只靠单调性。数据 [`rank9-trap.json`](rank9-trap.json)。

### 4.22 后继缺陷的主项，以及模型的 `b_∞ = 2`（2026-10-02）

软化折线对温度的导数是 `L^{−2} ψ(L(β−z))`，`ψ(0) = log 2` 且 `ψ > 0`。因此 `L` 增大时它逐点上升，又不超过 `F_b`，收到折线 **[证]**。后继缺陷的峰在 `z = b−2`，高度

```
log 2 · (L_s − L_{s−1}) / L_s²  ∼  (b−1) log 2 / (s [log(s/a)]²).
```

底数 1.3 上，`s = 24, 48, 100, 500` 的实测比是 `1.049, 1.014, 1.004, 1.0004`。§2.6 里「`s² Δ` 的预因子还没稳住」撤回：主项不是 `1/s²`。阶梯离软化折线的距离另有主项 `u_0/L ∼ 1/(s log(s/a))`（§2.10），`s^{−1.3}` 同样撤回。离折线本身的速率是 `log 2 / L_s`。

主项速率律 `q_s = a/s` 定出的闭式对数 `Φ` 满足 `Φ(1) = b`、`Φ'' < 0`，并且 `Φ'(1) ∼ (a/s)^a → 0`。一旦斜率不超过 `b−1`，命题 D 的包络成立，塔收敛。每个固定的 `b ∈ (1, 2)` 都有足够大的 `s`，所以这条模型的 `b_∞ = 2` **[证]**。`b = 1.99`、`s = 20`：斜率 `0.6056 < 0.99`，区间 `[1, 100]` 上包络超出为 0。解析阶梯要沿用这个结论，需要某一级真实的函数满足同一条斜率界。七级在 `b = 1.845` 已经冲出包络，解析 `b_∞` 仍是 `[1.83976, 2]`。证明在 [rank-tropical-limit-zh.md](rank-tropical-limit-zh.md) §2.9、§3、§7。

### 4.23 八级没有实不动点可借（2026-10-02）

§4.20 把七级建在六级的实不动点上。八级要照同一条路走，七级自己得先有一个实不动点。底数 `1.85`（`b_c8 = 1.83976` 之上，`m8 = +0.296`）上没有。

## 5. 不主张什么

1. 五级运算的构造、`x*`、`k`、`P` **都不是新的**——Kouznetsov 早有，
   sheldonison 算到 25–30 位。新的只是精度（+20 位）和**误差来源受控**。
2. ~~`Λ` 在五级上的数只是代入公式，还没有测到任何真实的 `D`。~~
   **已测（§4.5）：`D(1/2) = 2.9117e-5`，两组参数吻合 6 位。
   而 `Λ = 6.46e-10`——预言错了 4.7 个数量级，本纲领 §3.3 的那句话已作废。**
   §4.5 给的解释（四级的指数小来自退化极限）**前提已被 §4.6 证伪**——
   那个退化底数不存在。现在的说法是 §4.6(e)：**`Λ` 是比值不是幅度**。
   ⚠ 支持它的只有两个底数（e 与 3），杠杆最大的底数 2 超时未完成，证据薄。
