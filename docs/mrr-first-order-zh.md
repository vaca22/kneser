投稿稿 `paper-submission/main.tex` 的 Open problem 2 要求给出缺陷一阶系数 κ⁽ⁿ⁾ 的公式。
原稿里写着“逐项对 p 求导发散”，只能靠 b<η 一侧的拟合得到 11 位。
**本轮给出一个完全在 b=η（s=0）上计算的绝对收敛级数，数值上和拟合的 11 位全部吻合，
自身稳定到 20 位。** 脚本是 `mrr_derivative.py`（一阶）和 `mrr_second.py`（二阶交叉检验），

## 1. 发散的原因与修正（MRR 的 prepared form 思想）

记号：`f_s(u)=exp(μ−1+μu)−1`，`μ=1−s`，`s=1−e·log b`，其中 s>0 对应 b<η。
两个不动点记为 u₁<0<u₂，`A_j=1/log λ_j`，`q=(u−u₁)(u−u₂)`，`p=−logλ₁·logλ₂`。

旧的模型时间是 `Ψ=A₁log(u−u₁)+A₂log(u−u₂)`，它的一步误差 `F=Ψ∘f−Ψ−1` 只有 O(q)。
沿轨道 u_k≈−2/k，对 s 求导后，单项 `Ḟ(u_k)+F′(u_k)u̇_k` 是 O(1)（因为 u̇_k≈k/3），所以求和发散。

**修正**：取一致模型 `Ψ_s = A₁Log(u−u₁)+A₂Log(u−u₂)+P_s(u)`，其中 deg P_s = 2N−2。
P_s 由两个不动点处的 Hermite 条件确定，使 **F_s = O(q^N)**
（实现方式：Taylor 级数对 q^N 取余，再做最小二乘，残差为 1e-50 量级）。
Ψ_s 关于两根对称，因此在固定的 u≠0 处关于 s 解析。
按 `ν log u + Σ A_j Log(1−u_j/u) + P` 的写法计值，不会碰到分支问题。
此时求导后的单项是 O(k^{−2N+2})，N≥2 时绝对收敛：

```
Φ_att,s(u) = Ψ_s(u_m) − m + Σ_{k≥m} F_s(u_k),
Φ_rep,s(u) = Ψ_s(v_m) + m − Σ_{k>m} F_s(v_k),      v_k = f_s^{−k}(u)
δT(z) = δΦ_att(u) − T₀′(z)·δΦ_rep(u),    u = Φ_rep,0^{−1}(z)，Φ_att(u*)=0，u*=1/e−1
d log τ_n/ds = δt_n/t_n − 2πi n δt₀,     κ⁽ⁿ⁾ = (d log τ_n/ds)/(dp/ds)，dp/ds=2
```

s 导数用 s=±h 的中心差分实现，两侧都是有限表达式的解析取值。
这里 s<0 只是一个数学上的取值点，并不代表 Lavaurs 侧的动力学。

**注意**：
- 公式与“Hadamard 有限部分正则化”不同。朴素有限部分的常数项一般并不等于真导数，因为内外匹配时会有额外贡献。
- 一致模型把正则化做成了**精确恒等式**，不存在这种歧义。

## 5. 单侧可微的证明（2026-09-27，已写入投稿稿 §sec:first，Thm D / 主定理 D）

- **Lemma model**（一致模型）：
  - Weierstrass 预备定理给出 f_s−u = q_s k_s，判别式 D(s)=8s+O(s²)，令 t=√D。
  - a_s(x,y) 的奇部是可去的（差商），且关于 t 为偶函数，因此对 s 解析。
  - 线性系统 M(0) 下三角，对角元 i/2，所以 e(s) 解析，F_s=q_s^N Γ_s。
- **Lemma finite**（复参数有限轨道）：在 ζ=−2/u 坐标下对 |σ|≤c/J² 做归纳，得到 Re ζ_k ≥ Re ζ₀+k/2，从而 |u_k|≤2/(R+k/2)。
- **Lemma derbounds**：|u̇_k|≤C(k+1)，由 Cauchy 估计得到。
- **Prop diff**：
  - 头部 k<J 在复盘 |σ|<c/J² 上一致有界，于是二阶导 ≲J⁴。
  - 尾部由 Lemma petal 的逐点界给出 ≲J^{1−2N}，导数尾部 ≲J^{3−2N}。
  - 取 J=s^{−2/9}、N≥3，误差为 O(s^{10/9})。
- **Thm D**：
  - 用 Rouché 求逆，再与 item (a)–(c) 的门线傅里叶系数衔接。
  - κ⁽ⁿ⁾ = δt_n/(2B_n) − πi n δt₀，p = 2s + (10/9)s² + …

## 6. 二阶及任意阶（2026-09-27，§sec:higher，Prop higher + Thm E）
- m 阶展开需要模型阶 N ≥ m²+m+1，余项为 O(s^{m+γ})，其中 γ = 1 − 2(m+1)²/(2N+2m+1)。
- 证法：第 k 项在 |σ|≤c/(k+1)² 上有界，由 Cauchy 估计得 j 阶导数 ≲ k^{2j−2N}；头部 Taylor 余项 ≲ (sJ²)^{m+1}；尾部 ≲ J^{1−2N}；取 J = s^{−(m+1)/(2N+2m+1)}。
- 系数与 N 无关，由渐近展开的唯一性直接得到。
- 二阶系数 κ₂⁽ⁿ⁾（N=7 与 N=10 两组比较）：

  - n=3：一致 13 位。
