## 命题 B1. V 不可加

**陈述.** 不存在区间 `I ∋ 0` 使 `V(x+y) = V(x)+V(y)` 对所有 `x,y,x+y ∈ I` 成立。

**证明.** 连续(甚至可测)的可加函数满足 `V(0) = 0`。但
`V(0) = S'(A(0)) = S'(-1)`。移位关系 `S'(z+1) = S(z+1) S'(z)` 在 `z = -1`
给出 `S'(0) = S(0) S'(-1) = S'(-1)`,而 `S'(0)` 是烘焙级数的一次系数
`a_1 = 1.09176… > 1`。更弱地,Kneser 的 `S` 严格递增故 `S' > 0`,因此
`V(0) > 0`。与 `V(0) = 0` 矛盾。

(函数方程 `V(e^x) = e^x V(x)` 在 `x = 0` 还给出 `V(1) = V(0)`,于是 Rolle
保证 `(0,1)` 内存在临界点。这是最小值 `x*` 的存在性,不依赖凸性。)

## 命题 B2. 自对偶对强迫内部极值

**陈述.** 映射 `t ↦ 2 +_t 2` 在 `[0,1]` 上不恒等于 4,因此有内部极值。
特别地它在 `t = 1/2` 处严格大于 4。

**证明.** 两端点: `2 +_0 2 = 4`,`2 +_1 2 = 4`。若路径恒为 4,则端点斜率
`s0(2,2) = V(4) - 2 V(2)` 为零。用 `V(e^u) = e^u V(u)`:

```
V(4) = 4 V(log 4) = 4 V(2 log 2)
2 V(2) = 2 · 2 V(log 2) = 4 V(log 2)
s0(2,2) = 4 (V(2 log 2) - V(log 2))
```

故 `s0 = 0` 当且仅当 `V(2 log 2) = V(log 2)`。`log 2 > x*`(证书:差
`0.215` 超出 `ρ` 约 `10^{50}` 倍;存在性只用 `x* ∈ (0,1)` 不够,此处用
`S''` 的唯一实零点落在 `(-1,0)` 且 `S(a*) = x* < log 2`,见 demo)。
在 `[x*, ∞)` 上 `V'` 不改变号(命题 V1 的推论:唯一临界点是最小值),
于是 `V` 在该区间严格递增,`V(2 log 2) > V(log 2)`,`s0 > 0`。
路径从 4 向上离开并必须回到 4,故有内部极大。

`demo_lemma_b.py` 给出间隙:

```
V(2 log 2) - V(log 2)  ≈  0.077
s0(2,2)               ≈  0.31
2 +_{1/2} 2           ≈  4.523
```

间隙与 `ρ` 之比为 `10^{47}` 量级:这是数值证书,不是浮点幻觉。

## 命题 B3. (2,3) 的符号证书

**陈述.** `s0(2,3) > 0` 且 `s1(2,3) < 0`,因此 `t ↦ 2 +_t 3` 在 `[0,1]`
上非单调。

**证明.** 端点公式(findings §2.1,由 `dE_t/dt = V(E_t)` 与畸变律微分,
六对数值符合到 8 位)是恒等式,不依赖凸性:

```
s0(x,y) = V(x+y) - V(x) - V(y)
s1(x,y) = xy [ V(log xy) - V(log x) - V(log y) ]
```

代入 `(2,3)` 并由烘焙级数求值:

```
s0 = V(5)-V(2)-V(3)                    >  0    (间隙 / ρ  > 10^{47})
s1 = 6(V(log 6)-V(log 2)-V(log 3))     <  0    (同样)
```

连续函数在左端导数为正、右端导数为负,故非单调。内部最大值
`2 +_{0.75} 3 ≈ 6.293 > 6`,即越顶。

**弱猜想 B(定理).** 存在正测度的正数对 `(x,y)` 使 `t ↦ x +_t y` 在
`[0,1]` 上非单调。因而连续运算级别不是加法与乘法之间的单调插值。

(强形式——用 `s0,s1` 的符号对完全分类单调性——仍待把"同号 ⇒ 单调"
写成定理;网格 28 对上已全部吻合。)

## 命题 V1. V 凸 ⟺ sexp' 对数凸

**陈述.** 对所有实 `x` 有 `V''(x) > 0`,当且仅当 `φ = log S'` 在 `(-2, ∞)`
上满足 `φ'' > 0`。

**证明.** `V(x) = S'(A(x))`,`A' = 1/V`。链式法则:

```
V'(x)  = S''(A(x)) / V(x)
V''(x) = (S'(a) S'''(a) - S''(a)^2) / S'(a)^3     (a = A(x))
```

`S' > 0`,故 `sign V''(x) = sign(S' S''' - (S'')^2) = sign φ''(a)`。
`A: ℝ → (-2, ∞)` 是双射,结论得证。

**移位恒等式.** 对 `z > -1`(此处 `S(z+1) > 0`):

```
S'(z+1) = S(z+1) S'(z)
φ(z+1)  = S(z) + φ(z)
φ''(z+1) = φ''(z) + S''(z)
```

`S''` 在 `a*` 变号且仅变号一次(`S''(z) = V'(S(z)) V(S(z))`,`V'` 的零点
即 `x*`,`S` 严格递增故只对应一个 `a*`)。因此 `φ''` 的危险步只有
`z ∈ (-2, a*)`,此时 `S'' < 0`,`φ''(z+1) = φ''(z) - |S''(z)|`。
只要该区间上 `φ'' > -S''`(即 `φ''(z+1) > 0`),正性向右无限传播。
向左,`x → -∞` 时 `V(x) ∼ V(0) e^{-x}`,二阶导 `V(0) e^{-x} > 0` 是显式的。

`docs/certify_phi_log_convex.py` 把这件事做成了区间定理,对象就是仓库里
那条已发布的 Taylor 级数(50 位,150 项,残差 `2.618e-52`)。它在
`(-2, +∞)` 上证明 `(log S')'' > 0`,间隙约 `0.9`,相对残差有几十个
数量级;唯一拐点的上界 `x* < 1/2`。于是 `V'' > 0` 在整条实轴上成立,
`V'` 严格递增。早先的 401 点扫描只保留为复现,不再承担证明。

**推论(谷的 Abel 不对称).** `a* + 1/2 ≈ -0.02176`。若 `φ` 关于 `-1/2`
对称则 `a* = -1/2` 且 `f'(0) = V_min / V(0)` 成为恒等。实测

```
f'(0)        = 0.87633613…
V_min / V(0) = 0.876122…
相对差         2.4 × 10^{-4}
```

精确式始终是 `f'(0) = V(f(0))/V(0)`(畸变律,`t = 1/2`,`x = 0`)。

## 命题 C. 虚时间误差界,以及 I 即唯一性

**陈述.** 令 `c(x) = exp(L · A(x))`。存在 `t_0(x)` 与 `C(x)` 使对所有
`t ≥ t_0(x)`,

```
|E_{it}(x) - L - c(x) e^{i t L}|  ≤  C(x) e^{-2 t Im L}
```

因而

```
I(x) := lim_{t→+∞} d/dt log(E_{it}(x) - L)  =  i L
```

对所有实 `x` 成立,与起点无关。

**证明(构造性,对本仓库的 Kneser 解).** 正规超函数在不动点处的 Koenigs
展开为

```
superf(z) = L + L^z + c_2 L^{2z} + c_3 L^{3z} + ⋯
```

`e^L = L` 蕴含主值 `Log L = L`,故 `L^z = e^{z L}`。二次项
`L^{2z} = e^{2 z L}` 在 `z = A(x) + i t` 上的模为 `e^{-2 t Im L}`。

Kneser 的 `S(z) = superf(z + θ(z))`。正频 Fourier 模使 `θ(z)→θ_∞`
(常数模;若只保留 `m≥1` 则 `θ_∞=0`) 当 `Im z→+∞`。因此首项系数是

```
c(x) = exp(L (A(x) + θ_∞))
```

而不是裸的 `exp(L A(x))`。数值上从轨道尾段拟合 `c(x)` 自动吸收 `θ_∞`。
二次项仍是 `O(e^{-2 t Im L})`,因为 `2π > 2 Im L`,theta 的非常数模更小。

`demo_lemma_i.py` 在 `t ∈ [4, 16]`、`x ∈ {0,1,2}` 上测量
`|remainder| / e^{-2 t Im L}`,比值有界;同时
`|d/dt log(E-L) - i L|` 随 `t` 进入该制度而下降。

**唯一性读法.** Trappmann–Kouznetsov (2010) 的全纯 Abel 函数唯一性,
挑选的正是"上半平面全纯且趋向 `L`"的那一个迭代。非 Kneser 的
`C^∞` 分数迭代不提供全纯虚时间流,极限 `I` 对它们无定义。因此在
`exp` 的分数迭代中:

```
I 存在  ⟺  该解是 Kneser 解
```

左到右是 TK2010;右到左是本命题。这不是新的唯一性定理,是把它改写成
可测量的渐近。

## 命题 K. Carleman 主支的两端标定

**Schröder 端.** `g(x) = λ x`(`λ = 4`)。Carleman 矩阵对角,
`M_{ij} = λ^i δ_{ij}`。主支平方根对角元 `λ^{i/2}`,第 1 行恰好是
`2x` 的 Taylor 行。截断在每一阶都是精确的——主支选择在线性可解情形
就是正确的函数平方根。

**抛物端.** `g(x) = e^x - 1`。`g(0)=0` 使 Carleman 矩阵三角,特征分解
在 0-特征块上退化,不是正确工具。正确的标定是字典本身:形式半迭代
`f` 的 Carleman 满足 `C_f^2 = C_g`(截断多项式代数里精确,与
`demo_infinite_system.py` 的三角化解是同一件事)。分支在这里唯一,
因为对角元 `μ + μ^k` 非零。分析门(零半径发散)与选择层无关。

**Kneser 端.** `g(x) = e^x`。mpmath 下 `n = 8,12,16,20,24` 对 Kneser
参考值的误差继续按代数阶下降;findings 中 `n = 32` 的 float64 回弹是
特征基条件数,不是换支。主支在没有实不动点时仍然落在 Kneser 上,
两端标定排除了"偶然选对分支"的解释。

**识别定理,而不是速率.** 若主支截断在某个实区间上局部一致收敛到一个
实解析、导数为正的 `f`,则 `f` 就是 Kneser 半迭代。理由是
Trappmann–Kouznetsov (2010):在这条正则性下,`exp` 的半迭代唯一。
观测到的下降大致是 `n^{-3}` 到 `n^{-4}`(`n ≤ 24`);float64 特征基的
条件数在 `n ≈ 28–32` 炸掉。对 `n` 一致的速率没有证明,这里也不补一个。

## 机制 κ(δ). theta 迭代的收缩从何而来

单位圆 `|z| = 1` 被高度 `δ` 切开:

```
theta 弧:  Im z ≥ δ,  调和测度  1 - μ(δ)
FE 带:    Im z <  δ,  μ(δ) = 2 arcsin(δ) / π
```

每轮用 `superf(z+θ)` 替换弧上的值,用当前级数的函数方程填充带。
更小的 `δ` 意味着更大的 theta 弧、更快的收缩——这与四次测量同向
(`1.61 / 1.48 / 1.31 / 1.20` 位每轮,`δ = 0.05/0.10/0.20/0.30`)。

朴素模型"新误差 = μ × 旧误差"给出 `-log10 μ(δ)` 位每轮,方向对,
但系统性低估:FE 带在 `z ∼ ±1` 处求的是 `z±1 ∼ 0`,即展开点,
级数在那里最准,带并不注入满额残差。

真正被 Cauchy 步衰减的,是界面 `Im z = δ` 上、大小为当前残差的跳跃;
缝点 `z = ±1/2` 主要透过该界面看见圆周。经验律

```
残差 ×= (0.017 + δ / 2π)     每轮
```

仍是最紧的标量拟合。`δ/2π` 有角度的量纲,大小与界面张角同阶
(`δ = 0.1` 时 `δ/2π = 0.016`,总因子 `0.033`);`0.017` 是与 `δ` 无关的
地板(Cauchy 离散 + 默认 `n_modes` 预算下第一个被截断的 theta 模)。

`1/(2π)` 不是 Poisson 核推出来的。单位圆上 `r = 1/2`、`φ = 0` 的
Poisson 核等于 `3`,一个单位跳跃被 `dα` 扫过会给出 `3/(2π) ≈ 0.477`,
比拟合斜率大约三倍。函数方程弧的调和测度斜率是 `10/(3π)`,也不对。
理想 theta 线性化的谱半径更是过收缩大约两个数量级:
`δ = 0.05/0.10/0.20/0.30` 时第一特征值约
`3e-5 / 3e-4 / 2.7e-3 / 9e-3`,而测得的 `κ` 是
`0.025 / 0.033 / 0.050 / 0.064`。

斜率对得上的是单界面转角:`d(arcsin δ)/(2π dδ)` 在 `δ = 0` 处等于
`1/(2π)`。地板 `0.017` 是被省略的 theta Fourier 模,不是谱半径。
拟合本身是实的;Poisson 推导没有成立。`demo_kappa_mechanism.py`
保留几何和被排除的模型。被排除的仍有常数 `e^{-π}` 和纯采样
`e^{-2π δ}`。

## 定理. 端点斜率分类单调性

设 `x, y > 0`,`W(t) = x +_t y`,`p = E_{-t} x`,`q = E_{-t} y`,
`rho(t) = V(p+q) - V(p) - V(q)`。`sign W' = sign rho`。

`docs/certify_phi_log_convex.py` 给出 `V'' > 0`,所以 `V'` 严格递增,
`V > 0`。于是 `p, q > 0` 时 `rho' < 0`,`p, q < 0` 时 `rho' > 0`。
`rho'` 的零点只出现在混合象限。在每个这样的零点上 `rho'' > 0`
(下面的证书),所以 `rho'` 至多变号一次,而且只能从负到正。
轨道从开第一象限出发,故 `rho'(0) < 0`:`rho` 先降后升,是一个谷。

两个符号事实只用到 `V'' > 0` 和 `x* < 1/2 < log 2`
(`certify_log_two` 证明 `exp(1/2) < 2`):

- `0 < x, y ≤ 1` 时 `rho(0) < 0`。固定 `x > 0`,`h(y) = V(x+y) - V(y)`
  严格递增;`k(x) = V(x+1) - V(x)` 也严格递增。
  `k(1) = 2 V(log 2) - V(0)`。`log 2 ∈ (x*, 1)` 且这里 `V' > 0`,
  所以 `V(log 2) < V(1) = V(0)`,`k(1) < V(0)`。于是
  `h(y) ≤ h(1) = k(x) + V(x) - V(0) < V(x)`。
- `y ≤ 1 ≤ x` 时 `rho(1) < 0`。令 `u = log x ≥ 0`,`v = log y ≤ 0`,
  `r(u) = V(u+v) - V(u) - V(v)`,`r'(u) = V'(u+v) - V'(u) ≤ 0`,
  最大值在 `u = 0`,等于 `-V(0) < 0`。

若 `x > 1` 且 `y > 1`,则对 `t ∈ [0, 1]` 有
`E_{-t} x ≥ log x > 0`(因为 `A(x) - t ≥ A(x) - 1 = A(log x)`),
`y` 同样。整条轨道留在开第一象限,`rho' < 0`,`rho` 严格递减,没有谷。

因此,轨道的正坐标 `q` 留在 `[1e-4, 24]` 内时(负坐标 `p` 可以任意负),两端点同号或有一端为零,则 `W` 在 `[0, 1]` 上单调;两端点严格反号时不单调。
`Δ = 0` 的谷若不是恒零,积分只能靠正负两段抵消,端点仍然严格反号。

混合象限上「零点处 `rho'' > 0`,其余地方 `rho'` 不变号」由这些脚本合在一起覆盖,
对象都是已发布级数:

- `certify_rectangle`:`q ∈ [0.03, 0.55]`,`p ∈ [-5, 0)`,`rho'` 不含 0 或 `rho'' > 0`
- `certify_complement`:`q` 更大或 `p ≤ -5` 时 `rho' < 0`,直到 `q = 6`
- `certify_large_q`:`q ∈ [6, 24]`
- `docs/strong_b_asymp.py`:`q ≤ 0.03` 上沿 `p = log q + s q` 的管子
  `q rho'' > 1`(`s ∈ [0.5, 1.5]`),左侧 `rho' < 0`,右侧 `rho' > 0`,
  以及右支 `a = -p/q ∈ [0, 2.6]` 的符号
- `certify_positive_gap`、`certify_far_left`、`certify_deep_left`:
  `q ∈ [1e-4, 0.03]` 上,左支射线和右支之间 `rho' > 0`,
  `s ≤ -12` 与 `p ≥ -40` 的外侧 `rho' < 0`
- `certify_mid_left`:`p ∈ [-40, -5]`、`q ∈ [2, 24]` 上 `rho' < 0`
- `certify_past_minus_40`:`p ≤ -40`、`q ∈ [1e-6, 24]` 上 `rho' < 0`。
  这里 `e^{p+q} ≤ e^{-16}`,用 0 处的泰勒余项,不再调用会在 `e^p` 上溢出的商
- `certify_large_return`:在 `p = -1` 上,`q = 3000` 时 `rho' < 0`,
  `q = 4000` 时 `rho' > 0`。所以 `q > 24` 并不是补集里那种一律为负。

## 定理. `D_t` 的两条零曲线

设 `t ∈ (0, 1)`,`x, y > 0`,`p = E_{-t} x`,`q = E_{-t} y`,
`D_t(x, y) = x +_t y - xy`。记

```
p_min = S(-1 - t) < 0,    x_-(t) = S(t - 1) ∈ (0, 1),    f = E_{t-1}.
```

`slog` 把 `ℝ` 映到 `(-2, ∞)`,所以 `t ∈ (0, 1)` 时 `E_t` 在整个实轴上有定义。
`x > 0` 给出 `p > p_min`。`f` 的定义域正是 `(p_min, ∞)`:再往左会碰到
`z = -2` 的奇点。在这个区间上

```
f(p) = log E_t(p),    E_t(p) > 0.
```

因此只要 `p + q > p_min`,三个值都是正的,`D_t` 与 Cauchy 差同号:

```
sign D_t = sign( f(p + q) - f(p) - f(q) ) = - sign k,
k(p, q) = f(p) + f(q) - f(p + q).
```

若 `p + q ≤ p_min`,则 `x +_t y = E_t(p + q) ≤ 0 < xy`,`D_t < 0`。

**引理.** `f` 在 `(p_min, ∞)` 上严格递增、严格凹,并且 `f'(p) → 0`(`p → ∞`)。

**证明.** `E_r'(z) = V(E_r(z)) / V(z)`。`V > 0`(因为 `S' > 0`),故 `f' > 0`。
再求导:

```
sign f''(z) = sign( V'(f(z)) - V'(z) ).
```

`V'' > 0` 已经是 `docs/certify_phi_log_convex.py` 的定理,所以 `V'` 严格递增,
`sign f'' = sign(f(z) - z)`。对固定的 `z > p_min`,`r ↦ E_r(z)` 在 `r = 0`
处等于 `z`,对 `r` 的导数是 `V(E_r(z)) > 0`。于是 `r = t - 1 < 0` 时
`f(z) < z`,`f'' < 0`。

剩下 `f' → 0`。记 `δ = 1 - t ∈ (0, 1)`,`z = slog(q)`,则
`f'(q) = S'(z - δ) / S'(z)`。`S''` 与 `V' ∘ S` 同号,所以 `S'` 在
`(a*, ∞)` 上严格递增,这里 `a* = A(x*)` 是 `V'` 的唯一零点所对应的高度。
对 `w - 1 > a*` 和 `α ∈ (0, 1]`,

```
S'(w + α) / S'(w) = exp(S(w + α - 1) - S(w - 1)) · S'(w + α - 1) / S'(w - 1)
                 ≥ exp(S(w + α - 1) - S(w - 1)).
```

中值定理加上 `S'` 在该区间递增,给出
`S(w + α - 1) - S(w - 1) ≥ α S'(w - 1)`。取 `w = z - δ`,`α = δ`,
`z` 足够大时

```
S'(z) / S'(z - δ) ≥ exp(δ S'(z - δ - 1)).
```

`S'(w + 1) = exp(S(w)) S'(w)` 且 `S(w) → ∞`,故 `S' → ∞`。指数趋于无穷,
`f'(q) → 0`。

**定理.** 每个 `t ∈ (0, 1)` 的正象限里,`D_t = 0` 恰好是两条严格递减的光滑对合。

1. 小支。`x ∈ (0, x_-(t))` 有唯一的 `y = η_t(x) ∈ (0, x_-(t))`。
   `η_t` 是这个区间的对合,`η_t' < 0`。`x → 0+` 时 `η_t(x) → x_-(t)`,
   `x → x_-(t)-` 时 `η_t(x) → 0`。曲线下方 `D_t < 0`,上方 `D_t > 0`。
   对角上恰好一个不动点。
2. 间隙。`x ∈ [x_-(t), 1]` 时,对每个 `y > 0` 都有 `D_t(x, y) > 0`。
3. 大支。`x > 1` 有唯一的 `y = γ_t(x) > 1`。`γ_t` 是 `(1, ∞)` 的对合,
   `γ_t' < 0`。`x → 1+` 时 `γ_t(x) → ∞`,`x → ∞` 时 `γ_t(x) → 1`。
   `1 < y < γ_t(x)` 时 `D_t > 0`,`y > γ_t(x)` 时 `D_t < 0`。
   对角上恰好一个不动点。

两条曲线都解析。`docs/demo_dt_zero_curve.py` 里 `t = 1/2` 的四条切片
落在这两支上:`x = 0.1, 0.25` 在小支,`x = 2, 5` 在大支,`x = 1` 落在间隙里。

**证明.** `k` 对 `q` 的导数是 `f'(q) - f'(p + q)`。`f'` 严格递减,所以
`p > 0` 时 `k` 对 `q` 严格递增,`p < 0` 时严格递减,`p = 0` 时
`k(0, q) = f(0) = log x_-(t) < 0`。

`q → ∞` 时,`f(p + q) - f(q) = ∫_0^p f'(q + s) ds ≤ p f'(q) → 0`,
故 `k(p, q) → f(p)`。

- `p > S(-t)` 时 `f(p) = log x > 0`。`k` 从 `q ↓ p_min` 的 `-∞`
  增到 `log x > 0`,恰好一个根。再看 `q = S(-t)`:
  `k(p, S(-t)) = f(p) - f(p + S(-t)) < 0`,所以这个根落在
  `(S(-t), ∞)`,对应的 `x = E_t(p) > 1`,`y > 1`。
- `0 ≤ p ≤ S(-t)` 时 `f(p) ≤ 0`,`k` 的上极限不是正数,没有根。
  这就是间隙 `x ∈ [x_-(t), 1]`。
- `p ∈ (p_min, 0)` 时,`q` 的下界是 `p_min - p ∈ (p_min, 0)`。
  `k` 从该端的 `+∞` 减到 `f(p) < 0`。而 `k(p, 0) = f(0) < 0`,
  所以唯一根在 `(p_min - p, 0)` 内,对应的 `x, y` 都落在 `(0, x_-(t))`。

伴侣映射连续:隐函数定理的分母 `f'(q) - f'(p + q)` 只在 `p = 0` 为零,
而零点不在 `p = 0` 上。对称性使它成为对合。求导

```
q' = (f'(p + q) - f'(p)) / (f'(q) - f'(p + q)).
```

小支上 `q < 0`,故 `p + q < p` 且 `p + q < q`:分子为正、分母为负,
`q' < 0`。大支上 `q > 0`,分子为负、分母为正,`q' < 0`。
`E_t` 严格递增,所以 `η_t` 和 `γ_t` 都严格递减。

小支的端点:伴侣在 `(p_min, 0)` 里严格递减,`p ↓ p_min` 时极限 `L` 存在。
`L ∈ (p_min, 0)` 时,对合在 `L` 处取值 `p_min`,但像留在开区间里。
`L = p_min` 时,严格递减会把像推出 `(p_min, 0)`。故 `L = 0`。另一端同样,
`p → 0-` 时伴侣趋于 `p_min`。
翻译回 `x = E_t(p)` 就是 `η_t` 的两个端点极限。大支同样:
`p ↓ S(-t)` 时 `f(p) ↓ 0`,任何固定的 `Q` 上都有 `k(p, Q) → k(S(-t), Q) < 0`,
根被推出任何紧集,`q → ∞`;反过来 `p → ∞` 时若伴侣的极限 `λ > S(-t)`,
则 `k(p, λ) → f(λ) > 0`,与 `k = 0` 矛盾,故 `q → S(-t)`,`y → 1`。

不动点看 `d(p) = 2f(p) - f(2p)`。`d'(p) = 2(f'(p) - f'(2p))`。
大支上 `p > S(-t)`,`d` 严格递增,`d(S(-t)+) = -f(2S(-t)) < 0`,
而 `f(2p) - f(p) ≤ p f'(p) → 0`,`f(p) → ∞`,故 `d(p) → ∞`,恰好一个根。
小支上限制在 `(p_min / 2, 0)`,这里 `2p > p_min`,`d` 严格递减,
`d → +∞` 于左端点,`d → f(0) < 0` 于 `0`,恰好一个根。

**渐近.**

小支,`x → 0+`。记 `ζ(p) = slog(p) + 1 + t`,`λ(ζ) = S(-1 + ζ) / ζ`
(`λ(0) = V(0)`)。则 `f(p) = log ζ(p) + log λ(ζ(p))`,并且
`x = ζ(p) λ(ζ(p))`。沿曲线 `q → 0`,`ζ(p)` 和 `ζ(p + q)` 都趋于 `0`,
Cauchy 方程变成

```
ζ(p + q) / ζ(p) → exp(f(0)) = x_-(t).
```

`ζ(p_min) = 0`,`ζ'(p_min) = 1 / V(p_min)`,故
`(p + q - p_min) / (p - p_min) → x_-(t)`。再用来
`x / (p - p_min) → V(0) / V(p_min)` 和
`(η_t(x) - x_-(t)) / q → E_t'(0) = V(x_-(t)) / V(0)`,得到

```
(η_t(x) - x_-(t)) / x  →  C_-(t)
C_-(t) = (x_-(t) - 1) V(x_-(t)) V(S(-1 - t)) / V(0)^2  < 0.
```

另一端由对合对称得到同一条线性式。

大支,`x → ∞`。先证明在长度有界的区间上 `f'` 相对平坦:
`V'(z) / V(z) = (1 + V'(log z) / V(log z)) / z`(`z > 1`)。
迭代对数直到落进紧区间。`V` 在紧区间上有正下界,`|V'/V|` 有界,
因此 `z` 充分大时 `|V'(z) / V(z)| ≤ 2 / z`。`|V'/V|` 在 `[x*, ∞)` 上也有界:
远处按 `2/z` 衰减,紧的一段连续。于是被积函数

```
(V'(f(p + u)) - V'(p + u)) / V(p + u)
```

的绝对值不超过 `|V'(p + u)| / V(p + u)` 再加上
`|V'(f) / V(f)| · V(f) / V(p + u)`。第一项是 `O(1/p)`。第二项里
`V(f) / V(p) = f'(p) → 0`,系数有界。故对固定的 `s`,

```
log(f'(p + s) / f'(p)) = ∫_0^s (V'(f(p + u)) - V'(p + u)) / V(p + u) du
```

在 `p → ∞` 时趋于 `0`,对 `s ∈ [0, 2 S(-t)]` 一致。
伴侣 `q → S(-t)`,故 `f(q) = ∫_0^q f'(p + s) ds = S(-t) f'(p) (1 + o(1))`。
左端又是 `f'(S(-t)) (q - S(-t)) (1 + o(1))`,而
`f'(S(-t)) = V(0) / V(S(-t))`,`f'(p) = V(log x) / V(E_{-t} x)`,
`E_t'(S(-t)) = V(0) / V(S(-t))`。乘起来:

```
(γ_t(x) - 1) · V(E_{-t} x) / ( S(-t) V(log x) )  →  1.
```

`x → 1+` 时 `p → S(-t)`,`q → ∞`,同一平坦性给出
`log x = S(-t) f'(q) (1 + o(1))`,也就是

```
V(log γ_t(x)) / V(E_{-t} γ_t(x))  ∼  (log x) / S(-t).
```

**端点.** `t → 0+` 时 `f = E_{t-1}` 点态收敛到 `log`,`E_{-t} x → x`。
对固定的 `x > 1`,`k_t` 在极限双曲线根 `x / (x - 1)` 的两侧变号,唯一根
不能逃出紧区间,所以 `γ_t(x) → x / (x - 1)`。这正是 `D_0 = 0`,即
`(x - 1)(y - 1) = 1`。大支不动点随之趋于 `2`。同时
`x_-(t) = S(t - 1) → 0`,小支被挤进原点角。
`t → 1-` 时 `x_-(t) → 1`,间隙缩成这一点;`D_1` 则在整个象限上为零。

## 定理. 每个负的 `p` 在 `q > 24` 之后至少还有一个 `rho'` 零点

记 `D = V + V'`。`V'(e^u) = D(u)`,并且 `q > 1`,`p + q > 1` 时

```
rho'(p, q) = q V(log q) (D(log q) - D(log(q + p)))
             - V(p) (D(log(q + p)) - V'(p)).
```

因此在这个区域里,`rho' = 0` 当且仅当两侧相等。记这个比为 `R(q)`。
`V(p) > 0`。`V'' > 0` 且 `V'(x*) = 0`,故 `p < 0 < x*` 时 `V'(p) < 0`,
从而 `D(log(q + p)) - V'(p) > 0`。
于是 `sign rho' = sign(R - 1)`。

**`R(24) < 1`.** 证书在 `q = 24` 上对每个 `p ≤ 0` 给出 `rho' < 0`:
`p ≤ -1e-3` 由 `certify_large_q`、`certify_mid_left`、`certify_past_minus_40`
覆盖,`p ∈ [-1e-2, 0]` 由 `certify_q24_near_zero` 覆盖。轴上的恒等式
`rho'(0, q) = V(0)(V'(0) - V'(q))` 是同一结论在全体 `q > 0` 上的特例
(`V'(0) < 0 < V'(q)`)。

**`R(q) → ∞`,因而 `rho' → +∞`.** 下面只用恒等式于
`q > max(24, 2|p|)`。这时 `p + q > 1`,`|p/q| < 1/2`。
令 `L = log q`,`δ = log(1 + p/q) < 0`。`u ∈ (-1/2, 0)` 时 `log(1 + u) < u`,
故 `-δ > |p|/q`。并且 `L + δ = log(q + p) > log 12 > x*`,这段上
`V' > 0`,`D' = V' + V'' > 0`,`D` 严格递增。中值定理给出
`D(L) - D(L + δ) = -δ D'(ξ)`,所以

```
q V(L) (D(L) - D(L + δ)) > |p| V(L) D'(ξ).
```

`D'(u) > V'(u)`。`u > e^{x*}` 时 `V'(u) = D(log u) ≥ V(log u)`,
而 `V(t) → ∞`(`t → ∞`),故 `D'(u) → ∞`。`ξ` 夹在 `log(q + p)` 与
`log q` 之间,随 `q` 走向无穷。

减掉的那一项是 `V(p)(D(L + δ) - V'(p))`。`V'(p) < 0`,所以它不超过
`V(p) D(L) + V(p) |V'(p)|`。`D(L) = V(L) + V'(L)`,而 `|V'/V| ≤ 2/z`
在高度充分大时成立(`D_t` 定理里同一条对数迭代)。于是 `D(L)` 与
`V(L)` 同阶,`V(L) D'(ξ)` 相对 `D(L)` 走向无穷。固定 `p < 0` 后
`rho' → +∞`,`R → ∞`。

连续函数从 `R(24) < 1` 走到无穷,所以每个 `p < 0` 在 `(24, ∞)` 里至少有一个
`rho' = 0`。`p = -1` 上 `q = 3000` 为负、`q = 4000` 为正,只是这条存在性的一个点。
