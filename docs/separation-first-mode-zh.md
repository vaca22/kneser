> **先说结论（数值，非证明）**
>
> 1. **`(1,η)` 上的整个分离塌缩成一个复数。** 把 `K` 与 `R` 都按 `F(0)=1` 归一化，
>    则 `K(z) = R(z + P(z))`、`P` 1-周期、`P(0)=0`，而实测 `P` **只有第一模**：
>    $$D(z) = K(z)-R(z) = c_1\,R'(z)\,\bigl(e^{2\pi i z}-1\bigr) + O(c_1^2)$$
>    四个 `z`（含 `z = 0.5−0.5i`，那里第一模被放大 `e^π = 23`）给出的 `c₁`
>    **一致到 7 位**（离散度 1.0000）。缺了那个 `−1`（即常数模 `c₀ = −c₁`）
>    就差 1.917 倍——旧稿 §4.4 的 `E` 曲线正是漏掉它的产物。
> 2. **归一化之后，`E` 曲线是平的。** 令 `ĉ₁ = c₁/Λ`、`Λ = exp(4π²/log λ)`：
>    在 `|D|` 横跨 **45 个数量级**（`1e-3` 到 `1e-48`）、两套完全独立的实现
>    （本仓库 θ-映射 / PARI 的 fatou.gp / Paulsen 2019 的围道积分）上，
>    `|ĉ₁|` 只在 **0.0850 … 0.0889** 之间变化（4.6%）。旧的 `|E|` 在同一批点上跨 12 倍。
> 3. **高阶模的衰减比不是 Λ，而是 c₁ 本身。** 直接测 `P` 的谱：`|c₂/c₁| ≈ 2.9e-9`，
>    而 `Λ = 2.3e-8`（b=1.1）。实际上 `c₂ = κ₂c₁²`，`|κ₂| ≈ 1.37…1.48` 是 **O(1)**，
>    且 `κ₂` 在原点平移下**不变**，是一个真正的规范复不变量。
>    ⟹ `P` 的最近奇点深度是 `h + log(1/|ĉ₁|)/2π`，**不是** `h = 2π/|log λ|`。
>    **这否掉了一个很自然的证明思路**（"P 在高 h 的条带上有界 ⟹ 第一模 ≤ e^{−2πh}"）：
>    条带确实存在，但它比 h 深，且深度是被 `c₁` 自己决定的，不能用来**推出** `c₁ ~ Λ`。
>    Λ 的来源只能在**排斥不动点那一侧**的匹配里找。

## 1. 模型：两个超函数之差

`b ∈ (1,η)`，`E(w) = b^w`。`R` 是吸引不动点处的正则（Koenigs/Schröder）超函数，
`K = lim_{ε→0⁺} κ_{b+iε}` 是 Kneser 沿基底延拓的边界值。两者都是同一映射的超函数，
都按 `F(0) = 1` 归一化。于是 `α := R^{-1}∘K` 满足 `α(z+1) = α(z)+1`，
`P := α − id` 是 1-周期的，且

$$K(z) = R\bigl(z+P(z)\bigr),\qquad P(z+1)=P(z),\qquad \boxed{P(0)=0}.$$

`K` 在上半平面有界 ⟹ `P` 没有负模，`P(z) = c_0 + \sum_{n\ge1} c_n e^{2\pi i n z}`。
**归一化 `P(0)=0` 把常数模钉死**：`c_0 = -\sum_{n\ge1}c_n`。于是一阶展开

$$D(z) = K(z)-R(z) = R'(z)\,P(z)+O(P^2) = c_1 R'(z)\bigl(e^{2\pi i z}-1\bigr)+O(c_1^2).$$

`D` 在整数点为零是自动的（两边都归一化到 1，再用函数方程），这是模型的第一个自洽检验。

### 3.1 一个被否掉的证明思路

很自然的想法是：`P` 1-周期、在某条带上有界 ⟹ `|c_n| ≤ M e^{−2πn·(条带深度)}`；
若条带深度恰是 `R` 的虚周期 `h = 2π/|log λ|`，就直接得到 `|c₁| ≤ MΛ`，Λ 律证完。
**这条路不通**：实测深度是 `h + log(1/|ĉ₁|)/2π`（比 h 深 0.39），
而且这个深度**由 c₁ 自己决定**（`|c₁|e^{2π·深度} = O(1)`），
所以"条带 ⟹ c₁ 小"是循环论证，推不出任何东西。

结构上原因也清楚：由 `σ(K(z+1)) = λσ(K(z))` 得 `p(z) := λ^{−z}σ(K(z))` 是 1-周期的，
而 `P = log(p/c)/log λ`。`P` 的奇点是 `p` 的**零点**，零点位置当然由 `p` 的模的相对大小
（即 `c₁`）决定，与 `h` 无关。`c_n = κ_n c₁^n`（`κ_n = O(1)`）正是这个 `log` 结构的表现。

⟹ **Λ 的来源必须到排斥不动点那一侧去找**：`K` 与 `R` 的区别全在下端条件
（`R` 沿虚方向严格 `2πi/log λ`-周期、不趋于极限；`K` 要在另一个不动点处正规），
`4π²/log λ = −2π·h` 里的那个 `h` 应当是两个 Abel 坐标在"闸门"区域的重叠虚高度。
本文没有把这条写成证明。

## 4. `(1,η)` 的精确参数化与 η 端的鞍结律

顺手记一条应该早就写下来的事实。`L = b^L`、`λ = L log b` 消去 `b`：

$$\log L = L\log b = \lambda \;\Longrightarrow\; \boxed{L = e^{\lambda},\qquad \log b = \lambda e^{-\lambda}}$$

`λ ∈ (0,1)` 给吸引支、`λ > 1` 给同一个 `b` 的排斥不动点（`λe^{−λ}` 在 λ=1 取最大值 `1/e = log η`）。
于是整族 `(1,η)` 被 `λ` 精确参数化，`Λ(λ) = exp(4π²/\log λ)` 是 λ 的初等函数。

**η 端**（`λ = 1−ε`）：`log b = e^{-1}(1 - ε^2/2 - ε^3/3 + \cdots)`，故

$$\varepsilon = \sqrt{2e\,(\log\eta-\log b)}\,(1+O(\varepsilon)),\qquad
|\log\lambda| = \varepsilon+\tfrac{\varepsilon^2}{2}+\cdots$$

数值核对（`|log λ|` 精确值 vs 上式）：`η−b = 1e-2 / 1e-3 / 1e-4 / 1e-6` 时比值
1.0386 / 1.0108 / 1.0033 / 1.0003。于是

$$\boxed{\;|K(b;z)-R(b;z)| \asymp \exp\!\Bigl(-\frac{C_\eta}{\sqrt{\eta-b}}\Bigr),\qquad
C_\eta=\frac{4\pi^2}{\sqrt{2e^{\,1-1/e}}}=20.3508008\ldots}$$

这是**鞍结分岔的指数小分裂**的标准形状 `exp(−C/√ε)`：`b → η⁻` 时两个实不动点
`e^{λ}` 与 `e^{λ₂}` 合并成抛物点 `e`（`b=η`），`Λ → 0`，`D → 0`——
即 `K` 在 `η` 处**回到**正则解（那里只有 Kouznetsov–Trappmann 的两个抛物超指数）。

**这给出一条明确的猜想，而本轮已经把它验证了**：`lim_{b→η⁻}|ĉ₁|` 等于抛物映射的
Écalle–Voronin / horn map 第一 Fourier 系数模。

### 4.1 抛物端的独立计算（2026-09-17，`docs/parabolic_horn.py`）

`b=η` 时令 `w = e(1+u)`，映射变成抛物芽 `f(u) = e^u − 1`，吸引花瓣在 `Re u<0`、
排斥花瓣在 `Re u>0`，形式 Abel 函数就是仓库 `ParabolicEngine` 里那条
`α(u) = −2/u + log(−u)/3 + Σ c_k u^k`。**两个 Fatou 坐标用同一个 α 归一化**：

```
Φ_att(u) = lim [α(f^n(u)) − n]      Φ_rep(u) = lim [α(f^{−n}(u)) + n]
```

（`log(−u)` 的分支沿轨道连续延拓。）上闸门上的过渡映射
`h = Φ_rep ∘ Φ_att^{-1}` 与 `z↦z+1` 交换、且 `Im z→+∞` 时趋于恒等（两个坐标同渐近于 α），
所以 `h(z) − z = Σ_{n≥1} A_n e^{2πinz}`。数值给出

| | 值 |
|---|---|
| **\|A₁\|** | **0.08905843641221** |
| \|A₂\| | 0.037349258777 |
| \|A₃\| | 0.02246384 |
| A₀ | 0（到 1e-47 以下，理论上必须为零）|

工作精度 30–50 位、α 项数 20–60、匹配半径 0.005–0.02、DFT 点数 16/24/32、
采样高度 Im z = 1/1.5/2 —— **所列位数全部不变**。

## 5. 证了什么 / 没证什么

**证了（初等）**：§4 的参数化 `L=e^λ, log b = λe^{−λ}` 与 η 端的 `C_η`；
`P` 1-周期且 `c₀ = −Σ_{n≥1}c_n`（由 `P(0)=0`）；
`D = c₁R'(e^{2πiz}−1) + O(P²)` 作为**一阶展开**的形式恒等式。

**没证**：
1. `P` 只有非负模（用了"K 在上半平面有界"，本仓库没有对 `(1,η)` 边界值证过）。
   ⚠ 但这条已被数值验证到 `|c₋₁|/|c₁| ≲ 5e-15`（§1.1）。
2. `|ĉ₁|` 有极限、非零、或在 `(1,η)` 上解析。
3. Λ 律本身——§3.1 说明最自然的一条路是**假的**，新的路（排斥侧匹配）还没走。
4. η 端极限 = Écalle–Voronin 不变量（§4 的猜想）。

**数值的可信度**：`|ĉ₁|` 的 7 位是**跨设置一致性**，不是误差界；
