## 1. 一般设定与假设

设 `f_μ(w)` 是一个单参数族，在鞍结点 `(μ₀, w*)` 附近满足：

| 编号 | 假设 | 在 tetration 中 |
|---|---|---|
| **(H1)** | `f_μ(w)` 对 `w` 是整函数，对 `μ` 在 `μ₀` 附近全纯，`(μ, w)` 都为实数时取实值 | `E(w) = b^w` |
| **(H2)** | 鞍结：`f_{μ₀}(w*) = w*`，`f'_{μ₀}(w*) = 1`，`a₂ := f''_{μ₀}(w*)/2 > 0`（必要时用 `w ↦ −w` 翻转） | `w* = e`，在 `w = e(1+u)` 坐标里 `a₂ = 1/2` |
| **(H3)** | 横截：`γ := −∂_μ f_μ(w*)\|_{μ₀} > 0`（必要时翻转参数方向）。于是 `μ < μ₀` 时 `w*` 附近有两个实不动点 `p < q`，`p` 吸引、`q` 排斥 | `μ = e log b`，`γ = 1` |
| **(H4)** | 基点：`w₀ < w*` 为实数，`[w₀, w*)` 上 `f_{μ₀}(w) > w` 且 `f_{μ₀}` 递增。于是对 `μ` 接近 `μ₀`，`w₀ < p` 落在 `p` 的直接吸引域里，并且 `σ(w₀) < 0` | `w₀ = 1`，`F(0) = 1` |
| **(H5)** | （仅用于比值和对数陈述）逆上 horn 映射的第一个系数 `B₁ ≠ 0`；对定理 D/E 的第 `n` 条，`B_n ≠ 0` | 论文 Prop. horn-nonzero |

记 `s = μ₀ − μ > 0`，芽 `g(u) = f_{μ₀}(w* + u) − w* = u + a₂u² + a₃u³ + …`，
**迭代留数** `ρ = 1 − a₃/a₂²`。

**说明。**

- (H1) 里的「整函数」只用来保证排斥正则坐标 `S` 是整函数（论文 Prop. weld 后的注）。
  其余所有论证都只发生在 `w*` 的一个固定小圆盘里。
- **没有任何全局假设。** 这与数值检验的观察一致：采样闸门的位置因族而异，
  但证明里的闸门 `𝒢(Y*)` 本来就取在 Y* 充分大的位置，因此是局部的。见 §4.2。

**归一化。** 解的归一化从 `F(0) = 1` 改为 `F(0) = w₀`；`R⁻¹(w₀) = 0`；`u* := w₀ − w*`；`a := Φ_att(u*)`（实数）。

## 2. 一般陈述

下面的 A′、B′、C′、D′、E′ 分别对应论文的定理 A、B（含 W2）、char、D、E。

### 2.1 尺度（论文 Lemma param、Prop. saddle 的一般形式）[证，改常数]

```
|log λ| = 2√(a₂γ s) (1 + O(√s)),    log λ₂ = 2√(a₂γ s) (1 + O(√s)),
Λ = exp(4π²/log λ) = exp( −2π² / √(a₂γ s) · (1 + o(1)) ),
p := |log λ| · log λ₂ = 4a₂γ s + O(s²)，并且 p 是 s 的全纯函数。
```

推导：Weierstrass 预备式 `f_s(u) − u = (u² − σ₁u + σ₂) k_s(u)`，其中 `k_0(0) = a₂`，
`σ₂ = f_s(0)/a₂ + O(s²) = −γs/a₂ + O(s²)`，判别式 `D(s) = 4γs/a₂ + O(s²)`，
`λ_{1,2} = 1 ∓ a₂√D + O(D)`。

检验：

- tetration：`a₂ = 1/2`，`γ = 1`，`s = 1 − e log b`，代入后正好得到论文的 `C_η = 4π²/√(2e^{1−1/e})` 和 `p = 2s + …`。
- 三个新族在 λ = 0.97 处，`p` 与 `4a₂γ s` 的差在 `O(s²)` 以内（quad 0.000900 对 0.000900，sine 0.000900 对 0.000900，expq 0.000928 对 0.000928）。

论文里所有写成「`A_1 + A_2 → 1/3`」「`1 − 4k'_η(0)`」的地方，一般形式为

```
ν := lim (A₁ + A₂) = 1 − k'_{μ₀}(0)/k_{μ₀}(0)² = 1 − a₃/a₂² = ρ,     A₁(u₁ − u₂) → 1/a₂.
```

由此得到两个推论：

- 吸引与排斥周期之差 `h₂ − h = 2π(A₁ + A₂) → 2πρ`。λ = 0.97 处 exp、quad、sine、expq 的实测值分别为 2.0942、6.2837、6.2837、−0.0004，对应的 2πρ 为 2.0944、6.2832、6.2832、0。
- 带估计（Lemma band (ii)）里的 `π/3` 应改为 `π|ρ|`，因为它就是 `(A₁ + A₂) · arg(u − u₂)` 的上界。

### 2.2 定理 A′（汇流）[证，原样 + 改常数]

> 设 (H1)–(H4) 成立。对每个 `n ≥ 1`，当 `μ → μ₀⁻` 时有 `τ_n(μ) → B_n e^{2πina}`，其中 `τ_n = t_n e^{−2πint₀}` 取在 `Im t₀ = h/2` 的分支上。
> 若再加 (H5)，则 `t_n/t₁ⁿ → B_n/B₁ⁿ`。

需要的改动：

- §proofC 的模型时间、Lemma F、Lemma petal：`α₂(u) = −2/u + (1/3)log(−u)` 改为 `−1/(a₂u) + ρ log(−u)`；Apollonius 盘的极限改为 `{Re(−1/(a₂u)) > R}`；`A₁(u₂ − u₁) → −1/a₂`。证明逐字照搬。
- Thm C(2) 的反射族 `G_s(v) = −f_s⁻¹(−v)`：它的芽是 `v + a₂v² + (2a₂² − a₃)v³ + …`，迭代留数为 `−ρ`（论文中是 `−1/3`），预备形式同样成立。
- (c) 分支：沿 `u₁` 上方绕行，`Im R⁻¹` 的增量 `A₁·π + A₂·0 = h/2` 不依赖于族。由 Lemma realT′（下面），恰好落在 `Im t₀ = h/2` 这一支上。
- (d) `B₀ = 0`：只用到 `f^{±k}u ≈ −1/(a₂(x ± k + iY))`，原样成立。

**Lemma realT′ [证，原样]**：对实的 `μ < μ₀`，`S` 把 ℝ 递减地映到 `(p, q)` 上，在那里 `σ > 0`；而 `σ(w₀) < 0`（这正是 (H4) 的作用）。因此在实轴上 `Im T ≡ h/2 (mod h)`。

> 「缝口在实轴下方半个周期」这一结构，来自 (H4) 要求基点在 `p` 远离 `q` 的那一侧。基点取在 `(p, q)` 里会是什么情形，没有检验。

### 2.3 定理 B′（缝合解与 O(Λ) 估计）[证，原样 + 改常数]

> 设 (H1)–(H4) 成立。存在 `μ₁ < μ₀`，使得对 `μ ∈ (μ₁, μ₀)`：缝合解 `K^W_μ`（`R` 的上半柱面与 `S` 的下半柱面沿 `T − ih` 共形缝合，并归一化为 `K^W(0) = w₀`）存在，在类 `𝒞_μ(Y)` 中唯一（定理 C′），且
> ```
> | c_n/Λⁿ − τ_n(μ) | ≤ C_n Λ,     C_n = C M(M+1) e^{2π(n+2)(Y₀+D+2)}.
> ```
> 这里 `Y_B`、`Y₀`、`D`、`M` 都依赖于族，其中 `Y_B` 通过 `π|ρ|` 和 Lemma F 的常数 `M` 依赖于族；`C` 是绝对常数。

需要的改动：

- Lemma band (ii) 的单射性论证原来写的是「`f_b` 的非单射周期 `2πi/log b` 远大于圆盘」。一般地，由 `f'_{μ₀}(w*) = 1`，缩小 `r'` 之后 `f_μ` 在 `D_{r'}` 上一致单叶。
- Lemma band (i)：`h₂ = h + 2π/3 + o(1)` 改为 `h₂ = h + 2πρ + o(1)`。
- Prop. weld：`R` 的奇点集 `(−∞, −2] + ikh` 改为一般的闭集 `Σ_R`，即 `f` 的奇异值经逆分支拉回得到的集合。「解」按论文的约定理解为「在一个闭奇异集之外全纯」。
- Prop. weld-parameter：「`f'` 在 `[p, q]` 上为正」在 `μ₀` 附近自动成立。Fischer–Grauert 的论证原样适用。
- Wiener 代数中的压缩（W2 (1)–(4)）只用到 Lemma modes 的模估计，原样成立。

### 2.4 定理 C′（刻画）[证，原样]

`𝒞_μ(Y)` 的定义只需把 `F(0) = 1` 改为 `F(0) = w₀`。证明 (i)–(iv) 用到的是 `σ∘R(w) = σ(w₀)λ^w`、
Noshiro–Warschawski 判据，以及「`ℂ*` 上固定两端、局部度为 1 的真全纯映射是线性的」。这些都与族无关。

### 2.5 W1′（参数全纯依赖）[证，(2) 需要新论证]

(1)、(3) 原样成立。

(2) 原来的论证用 `λe^{−λ} = log b` 算 `∂λ/∂b` 的符号。一般的论证如下：
`λ_{1,2} = 1 ∓ a₂√D(s) + O(D)`，`D(s) = 4γs/a₂ + O(s²)`，`s = μ₀ − μ`，
所以 `∂_μ λ₁ = −∂_s λ₁ = a₂D'(s)/(2√D) ∼ √(a₂γ/s) > 0`，同理 `∂_μ λ₂ < 0`。
因此 `Im μ > 0` 时 `arg λ₁ > 0 > arg λ₂`，与 tetration 的 `Im b > 0 ⇒ arg λ > 0 > arg λ₂` 相同（那里 `μ = e log b` 随 `b` 增大）。
后半段论证（`R(w) → p` 当 `Im w → +∞`）原样成立。这里用到 (H3) 的符号约定 `γ > 0`；若翻转了参数方向，上下半平面互换。

### 2.6 定理 D′、E′（一阶项与全阶展开）[证，改常数]

> 设 (H1)–(H5) 成立。对每个 `n ≥ 1` 且 `B_n ≠ 0`，有
> ```
> log( τ_n / (B_n e^{2πina}) ) = κ⁽ⁿ⁾ p + O(p^{10/9}),
> κ⁽ⁿ⁾ = δt_n / (4a₂γ B_n)  −  2πin · δt₀ / (4a₂γ),
> ```
> 其中 `δt_m` 与论文定理 D 的定义相同（在一般芽的轨道上取级数）。全阶渐近展开（定理 E′）同样成立，其系数是同类收敛级数的多项式。

需要的改动：

- Lemma model 里 `d_i = (i/2)u^{i−1} + …` 改为 `i a₂ u^{i−1} + …`，三角矩阵 `M(0)` 的对角元为 `i·a₂ ≠ 0`。
- Lemma finite 里的 `ζ = −2/u` 改为 `−1/(a₂u)`。
- 定理 D 里的「`p = 2s + (10/9)s² + …`」只用到「`p` 关于 `s` 全纯且 `p'(0) ≠ 0`」，一般情形下 `p'(0) = 4a₂γ`。
- 反射族不再有显式公式，改为局部逆分支 `G_s(v) = −f_s⁻¹(−v)`。它对 `(s, v)` 联合全纯，这就是证明所需的全部性质。

### 2.7 新命题：模长不变量与基点无关 [证，新]

> **命题 G.** 设 `w₀, w₀′` 都满足 (H4)。用 `′` 表示以 `w₀′` 为基点算出的量，则对每个 `μ < μ₀` 和每个 `n ≥ 1`：
> ```
> τ_n′(μ) = τ_n(μ) e^{2πinΔ(μ)},    Δ(μ) := R_μ⁻¹(w₀′) ∈ ℝ,
> B_n e^{2πina′} = B_n e^{2πina} e^{2πinΔ₀},    Δ₀ := Φ_att(u*′) − Φ_att(u*) ∈ ℝ.
> ```
> 因此：
> 1. `|τ_n(μ)|` 与基点无关，并且对每个 μ 精确成立；缝合解的 `|c_n|`、`|ĉ_n|` 也与基点无关。
> 2. `Re log(τ_n/(B_n e^{2πina}))` 与基点无关，所以定理 E′ 的全部系数的实部 `Re κ⁽ⁿ⁾_j` 都与基点无关；虚部只相差一个基点规范。

**证明。** 由 (H4)，`σ(w₀)` 和 `σ(w₀′)` 都是负数，所以
`Δ = log(σ(w₀′)/σ(w₀))/log λ` 是实数（取主对数）。
新的吸引坐标为 `R′⁻¹ = R⁻¹ − Δ`，所以 `T′ = T − Δ`：`t_n′ = t_n`（`n ≠ 0`），`t₀′ = t₀ − Δ`。
由于 Δ 是实数，`Im t₀′ = Im t₀`，分支约定不变，于是 `τ_n′ = t_n e^{−2πin(t₀ − Δ)} = τ_n e^{2πinΔ}`。
抛物一侧，`u*` 和 `u*′` 都在实负轴上的吸引花瓣轨道里，`Φ_att` 在那里取实值，所以 `Δ₀` 是实数。
缝合解在两个基点下只差一个实平移，由论文 Remark invariance，`|c_n|` 不变。∎

**数值印证**（[generality-check-zh.md](generality-check-zh.md) §2.3）：quad 族取 `w₀ = 0, 0.2, 0.35`，`|τ₁|/|B₁|` 在三个基点下都等于 0.999986451728（λ=0.97），Re κ 都等于 −0.01504809108。

**推论（开折的解析不变量）[证，概要]。** 设 `φ_μ` 是两个满足 (H1)–(H4) 的实开折之间的局部实解析共轭（在 `w*` 的一个邻域上保持定向），参数允许重新参数化。
在该邻域内取基点。由于 Koenigs 坐标按 `R̃ = φ∘R`、`S̃ = φ∘S` 自然变换，`T̃` 与 `T` 只差归一化平移。再由命题 G，作为 `p` 的函数，`|τ_n|(p)` 是共轭不变量；`p` 只依赖于乘子，是内蕴的。
所以 **`|B_n|`（芽的不变量）和 `Re κ⁽ⁿ⁾_j`（开折的不变量）都是实开折在局部实解析共轭下的不变量**。

quad 与 sine 的芽都是 `ρ = 1`，形式上共轭，但它们的 `|B₁|` 不同（0.0598 对 0.0724），Re κ 也不同（−0.01505 对 −0.01421）。
这与 Écalle–Voronin 的结论一致：形式上共轭的两个芽未必解析共轭。
这些不变量与 Mardešić–Roussarie–Rousseau 开折模之间的确切关系，本文没有推导。

## 3. B₁ ≠ 0：唯一真正依赖于族的地方

论文 Prop. horn-nonzero 的证明用了三件事：

1. `f|_A` 的奇异值集合含于 `A ∩ SV(f)`（Chéritat Lemma 87）；
2. `eᵘ − 1` 在直接吸引域 `A` 里恰好只有一个奇异值（渐近值 −1），因此属于 Chéritat 的单奇值一花瓣类 `S_∞`；
3. Chéritat 的抛物重整化定理给出一个只有一个吸引花瓣的重整化，所以 `B₁ ≠ 0`。

一般陈述是：**若 `f_{μ₀}|_A` 恰有一个奇异值（Chéritat 意义下的单奇值类），论文的证明原样给出 `B₁ ≠ 0`。**

| 族 | `A` 中的奇异值 | `B₁ ≠ 0` 的状态 |
|---|---|---|
| exp | 渐近值 −1，只有一个 | [证]（论文） |
| quad `w² + c` | 临界点 0（临界值 1/4），只有一个；多项式属于有限型 | [证]（Epstein 有限型论证适用） |
| sine `v − sin v + c` | 临界值为 `2πk + 1`，全是实数；`A ∩ ℝ = (−3π/2, π/2)`，只含 `k = 0` 那一个；另有无穷多个临界值，所以 `f` 不是有限型 | **[推]**：需要确认 Chéritat 的单奇值框架适用于这类无穷型整函数 |
| expq `w + w²eʷ` | 临界点都是复数，哪些落在 `A` 里没有分析 | **[数]**：只有数值 `\|B₁\| = 2744 ≠ 0` |

> 因此 (H5) 保留为假设。在一般理论里，A′、B′、C′ 以及命题 G 的第 1 条都**不需要** (H5)；只有比值 `t_n/t₁ⁿ`、对数形式的一阶律，以及 `c₁ ≠ 0` 需要它。

### 4.2 证明中的闸门与数值中的闸门

[generality-check-zh.md](generality-check-zh.md) §3 发现：采样线 `Im z = −h₂/2 + Y₀` 的可用范围因族而异（quad、sine 需要 `Y₀ ≈ 3`，exp 用 `1.5` 就够）。

这与证明一致，并不构成反例。§proofC (b) 要求采样线满足 `|Im(z − s)| < h/2 − Y_B − 2`，而 `Y_B` 是族相关的常数（经由 `π|ρ|` 和 Lemma F 的 `M`）。
quad 和 sine 的 `ρ = 1`，比 exp 的 `1/3` 大，`Y_B` 相应更大，与数值上需要更大的 `Y₀` 方向一致。
这只是方向上的一致，**不是**定量的预测：`Y_B` 的显式值没有算。

## 5. 结论

1. 论文定理 A、B、C（char）、D、E 的证明，在 (H1)–(H4)（比值和对数陈述另加 (H5)）下对一般实鞍结开折成立。需要修改的只是常数，以及 W1(2) 一处方向论证。
2. 唯一真正依赖于族的输入是 `B₁ ≠ 0`。对单奇值的族它可以证明，一般情形下作为假设。
3. 新的严格结果：**命题 G**，即 `|τ_n|` 与基点无关，`Re κ⁽ⁿ⁾_j` 是开折的解析不变量。它把 [generality-check-zh.md](generality-check-zh.md) 的数值观察升级成了定理，并部分回答了 Q11（Re κ 是开折不变量；闭式仍未知）。
4. 以上是审查结论，不是重新写出的完整证明。真正写进论文时，建议把 §2 的 A′–E′ 作为一节「一般开折」，把论文现有的证明改写成以 `a₂, γ, ρ` 为参数的形式，tetration 作为 `a₂ = 1/2, γ = 1, ρ = 1/3` 的特例。
