# 连续迭代纲领:把运算级别变成几何对象

> 本仓库已经有一个坚硬的数值核心:Kneser 的实解析半指数,
> 以及由它给出的 `sexp`、`slog`、`exp^[t]`。
> 这份文件尝试把它从"一个会算半指数的库"推进为一条可以继续工作的
> 数学纲领。

先把边界说清楚:**这里不声称重新发现 Kneser 定理。** Kneser 1950 年已经
证明了满足

```
f(f(x)) = e^x
```

的实解析单调解存在;后来的唯一性工作也说明,在自然条件下这就是那条
正确的半指数。本仓库的新意不应放在"半指数存在"上,而应放在:

1. 把 Kneser 解变成可复现、可实验的计算对象;
2. 把连续迭代次数 `t` 当成新的几何参数;
3. 研究由这个参数诱导出的运算、流线、常数和无限方程组;
4. 找出哪些问题只是旧定理的换装,哪些问题真正落在现有工具之外。

一句话:

> **新数学不在于多造一个函数,而在于把"迭代次数"本身变成结构。**

---

## 0. 基本对象

记

```
S(z) = sexp(z)
A(x) = slog(x)
E_t(x) = exp^[t](x) = S(A(x) + t)
```

则在定义域内有

```
E_0(x) = x
E_1(x) = e^x
E_{1/2}(x) = half_exp(x)
E_s(E_t(x)) = E_{s+t}(x)
```

这是一个由指数函数生成的连续迭代流。`A` 是 Abel 坐标,因为

```
A(e^x) = A(x) + 1
```

在这个坐标里,指数函数不再是非线性爆炸,而只是平移一步。整个仓库可以
浓缩成一句话:

> **Kneser 坐标把指数迭代直线化。**

这给出第一条原则:

> 凡是关于 `exp` 迭代的困难问题,先搬到 Abel 坐标里看它是否变成了平移、
> 线性方程或边界条件。

---

## 1. 第一层结构:连续迭代流

### 1.1 已知事实

由定义立即得到一参数群律:

```
E_s o E_t = E_{s+t}
```

这意味着 `exp` 不再只是一个离散操作,而是一条流上的整数时刻:

```
... E_{-1}, E_{-1/2}, E_0, E_{1/2}, E_1, E_{3/2}, ...
... log,   half-log, identity, half-exp, exp, ...
```

本仓库已经把这条流算到 50 位左右,并用测试验证了:

- `E_{1/2}(E_{1/2}(x)) = e^x`;
- `E_{1/4}` 连续作用四次等于 `exp`;
- `E_s(E_t(x)) = E_{s+t}`;
- 高精度路径与独立实现的 50 位参考值一致。

### 1.2 无穷小生成元

连续流应当有一个速度场。形式上定义

```
V(x) = d/dt E_t(x) |_{t=0}
     = S'(A(x))
```

于是

```
d/dt E_t(x) = V(E_t(x))
```

并且由于 `E_t` 与 `exp` 可交换,

```
V(e^x) = e^x V(x)
```

这条函数方程很重要:它把"半指数"换成了一个更微分几何的对象。
`V(x) d/dx` 是指数函数的迭代生成元。它不是初等函数,但本仓库可以数值计算
它,也可以用它研究流线的速度、奇点和渐近。

### 1.3 可工作问题

**问题 1.1** 生成元 `V` 在实轴上的凸性、渐近展开、零点和增长率是什么?

**问题 1.2** 是否能给出 `V` 的高精度表,并把 `half_exp` 的性质改写成
关于 `V` 的常微分方程性质?

**问题 1.3** 在 Abel 坐标中平凡的平移,拉回实轴后产生了怎样的度量畸变?
例如比较

```
|E_t(x) - E_t(y)|
```

随 `t` 的变化。

这些问题不是"证明半指数存在",而是研究 Kneser 流本身的几何。

## 2. 第二层结构:连续运算级别

### 2.1 定义

对每个实数 `t`,在共同定义域上定义一个二元运算

```
x +_t y = E_t(E_{-t}(x) + E_{-t}(y))
```

这里"共同定义域"指上式中 `E_{-t}(x)`、`E_{-t}(y)` 以及最后的 `E_t`
都存在的区域。特别地,当 `t > 0` 时,它不应被默认为无条件定义在全部
`R^2` 上;任何数值实验都要同时写明使用的取值区域。

当 `t = 0` 时:

```
x +_0 y = x + y
```

当 `t = 1` 且定义域合适时:

```
x +_1 y = exp(log x + log y) = xy
```

当 `t = 1/2` 时,得到加法与乘法之间的半级运算:

```
x +_{1/2} y = half_exp(half_log(x) + half_log(y))
```

它交换、结合,单位元为

```
0_t = E_t(0)
```

逆元在存在时为

```
-_t x = E_t(-E_{-t}(x))
```

所以每个 `+_t` 都是加法经由 `E_t` 共轭出来的运算。

### 2.2 Aczel 墙

Aczel 的结合运算分类告诉我们:在实区间上,连续、结合、可消去的二元运算,
本质上都可以写成

```
x star y = phi^{-1}(phi(x) + phi(y))
```

因此 `+_t` 并不是在一维实数上突破了旧代数律。乘法本来就是加法经由
`exp` 共轭得到的;半级运算也是加法经由 `half_exp` 共轭得到的。

这堵墙反而给出了正确的研究方向:

> 绝对地看,所有 `+_t` 都同构于加法;
> 相对地看,`t -> +_t` 是嵌在通常实数结构中的一条非平凡路径。

### 2.3 新问题在哪里

如果只问"它是不是结合",答案太容易,因为共轭保证结合。真正的问题是:

**问题 2.1** `+_t` 相对于通常加法、乘法、序、距离的畸变如何变化?

例如定义相对乘法偏差

```
D_t(x,y) = x +_t y - xy
```

当 `t` 从 0 到 1 滑动时,`D_t` 的符号、极值、零点集是否有稳定结构?
已知数值现象是 `2 +_{1/2} 3` 略大于 `2 * 3`,所以它不是简单地在加法和
乘法之间单调插值。

**问题 2.2** 单位元路径

```
t -> 0_t = E_t(0)
```

是否携带可见的几何信息?它从 `0` 连续移动到 `1`,中点是
`half_exp(0) = sexp(-1/2)`。

**问题 2.3** 能否把 `{+_t}` 看成一条"运算空间"中的测地线、流或
正规形路径?如果能,它的自然坐标是什么?

这个方向的口号是:

> **不是创造第四个实数运算,而是研究运算之间的连续变形。**

## 3. 第三层结构:复数时间

### 3.1 定义

Kneser 构造本质上是复分析对象。因此 `t` 不必是实数,可以取复数:

```
E_tau(x) = S(A(x) + tau),    tau in C
```

例如

```
exp^[i](1) = sexp(i)
```

本仓库已有数值实验表明,这不是形式符号,而是可以直接算出的复数。

### 3.2 为什么这里可能真有新东西

实数时间的轨道是一维流。复数时间把轨道面扩成二维:

```
tau -> E_tau(x)
```

在 Abel 坐标里这只是复平面平移;拉回原坐标后,它变成指数迭代的复流线。
这些流线与以下对象相遇:

- 复不动点 `L`,满足 `e^L = L`;
- Schroder/Koenigs 线性化;
- 指数映射的复动力系统;
- Kneser 解的边界修正和 theta 函数;
- 可能的奇点、分支和自然边界。

### 3.3 可工作问题

**问题 3.1** 对实数初值 `x`,曲线

```
t -> E_{i t}(x)
```

是否有可分类的几何形态?它们是否自交?是否围绕复不动点呈现稳定绕转数?

**问题 3.2** `E_tau(x)` 的奇点集合在 `tau` 平面如何分布?

**问题 3.3** 能否画出 `E_tau(0)`、`E_tau(1)` 的相图,并把可见结构与
Kneser 构造中的 theta 修正联系起来?

**问题 3.4** 是否存在自然的复时间不变量,能区分 Kneser 解与其他
`C^\infty` 分数迭代解?

这个方向最像真正的"新地形":它不是仅仅把已有代数律重写一遍,而是在复平面
里探索一个很少被系统绘制的流。

## 4. 第四层结构:无限复合方程

### 4.1 字典

函数复合可以用 Carleman 矩阵表示:

```
C_{f o g} = C_g C_f
```

因此

```
f o f = exp
```

可以看成一个无限维矩阵方程:

```
C_f^2 = C_exp
```

但这里有一个关键限制:不是每个无限矩阵都是某个函数的 Carleman 矩阵。
所以真正的问题不是"给矩阵开平方",而是:

> 在复合算子的非线性流形里开平方。

### 4.2 可解性的三道分界

从本仓库和姊妹项目的实验看,无限复合方程的可解性至少受三层结构控制:

1. **代数层:** 是否有不动点让方程组分级三角化?
2. **分析层:** 形式级数是否收敛?若发散,是否 Borel-Écalle 可和?
3. **选择层:** 多个形式或光滑解中,哪一个满足实解析、单调、对称和边界条件?

`exp` 在实轴无不动点,所以 Kneser 方案绕到复不动点,再用 theta 修正把
解拉回实轴。这是本仓库最值得抽象化的经验。

### 4.3 可工作问题

**问题 4.1** 对一般解析函数 `g`,方程

```
f o f = g
```

什么时候有实解析单调解?

**问题 4.2** Carleman 截断的矩阵平方根何时收敛到真正的复合平方根?
分支选择怎样反映 Kneser 唯一性条件?

**问题 4.3** 对方程

```
P(f) = g
```

其中 `P` 是由复合、逆、迭代生成的多项式表达式,是否能建立一套
"复合代数方程"的判别理论?

**问题 4.4** Kneser 的 theta 迭代为什么数值上呈现稳定压缩?
能否给出可证明的误差界,解释本仓库构建中每轮约 1.4 位十进制精度的增长?

这一层的口号是:

> **无限方程组能解,往往是因为它在某个隐藏坐标里是逐阶有限的。**

## 5. 第五层结构:Kneser 常数

### 5.1 常数族

连续迭代自然产生一批常数:

```
K_t = E_t(0) = S(t - 1)
H_t = E_t(1) = S(t)
V(0) = S'(A(0)) = S'(-1)
f'(0) = E_{1/2}'(0)
```

其中包括:

```
sexp(1/2)
half_exp(0) = sexp(-1/2)
f'(0)
```

这些常数由指数函数的半次迭代产生,但不属于常见的初等常数库。

### 5.2 已知边界

目前没有已知方法能证明这些常数的无理性或超越性。它们不直接落入
Lindemann-Weierstrass、Gelfond-Schneider、Mahler 方法或 Baker 理论的
标准形态。Schanuel 猜想主要控制一次指数关系,也不会直接吞下
`exp^[1/2]` 的值。

这不是结论,只是定位:

> Kneser 常数处在现有超越性工具的边缘外侧。

### 5.3 可工作问题

**问题 5.1** 为 `sexp(1/2)`、`sexp(-1/2)`、`f'(0)` 建立 200、500、
1000 位高精度表,并记录构建残差。

**问题 5.2** 对标准常数基

```
pi, e, log 2, gamma, sqrt(2), W(1), e^{1/e}, ...
```

做系统 PSLQ 阴性实验,并把搜索高度、精度、失败范围写成可复现实验报告。

**问题 5.3** 是否能定义"Kneser 周期"或"迭代周期"一类更大的常数类,
使这些常数自然属于其中?

**问题 5.4** 若将 Schanuel 风格的公理扩展到一个带有 `E_{1/2}` 的结构,
最小合理公理应该是什么?

这个方向的口号是:

> **如果半指数常数没有旧钥匙,那就先把锁的形状画清楚。**

## 6. 一组谨慎猜想

下面不是定理,只是可以被数值实验和后续证明推动的猜想。它们故意写得保守,
避免把哲学直觉伪装成数学结论。

### 猜想 A:Kneser 流的相对刚性

在满足实解析、单调、Kneser 对称和适当增长条件的连续迭代流中,
`E_t` 由 `E_1 = exp` 唯一确定。

这基本是已知唯一性思想的流版本。真正要做的是把"适当条件"整理成
最小、可检验、适合计算的条件组。

### 猜想 B:运算路径的非单调性是普遍现象

对于

```
x +_t y = E_t(E_{-t}(x) + E_{-t}(y))
```

多数固定正数对 `(x,y)` 而言,函数 `t -> x +_t y` 在 `[0,1]` 上不满足
简单单调插值图像。也就是说,连续运算级别不是从加法平滑"走向"乘法的
数值混合,而是沿着共轭几何弯曲前进。

### 猜想 C:复时间轨道含有可见的绕转不变量

对典型实初值 `x`,曲线

```
t -> E_{i t}(x)
```

围绕指数函数的复不动点呈现可测的平均绕转行为,该行为可由复不动点处的
Schroder 乘子解释。

### 猜想 D:Kneser 常数代数独立于标准常数库

`sexp(1/2)`、`sexp(-1/2)`、`f'(0)` 与常见初等/特殊常数之间不存在低复杂度
代数关系。

这是实验猜想,不是证明猜想。可接受的近期目标只是不断扩大 PSLQ 阴性范围。

## 8. 不该声称什么

为了让这条路走得远,必须保留几条纪律。

1. **不要声称发明了半指数。** 半指数的存在与 Kneser 解属于已有数学。
2. **不要声称突破了 Aczel 定理。** 一维实数上的好结合运算已经被分类;
   `+_t` 的意义是相对几何,不是绝对新代数。
3. **不要把 PSLQ 阴性结果写成无理性证明。** 它只是证据,不是定理。
4. **不要把数值图像当成复动力系统定理。** 图像用于发现问题,证明要另做。
5. **不要把"更高层运算"说成必然存在。** Goodstein 塔和 Bennett/Aczel
   塔是两条不同路线,不能混在一起。

这些限制不是降温,而是让真正的新东西露出来。

## 9. 核心定义草案

可以把这条路线暂名为:

> **Kneser 迭代几何**  
> 研究由 Kneser 连续迭代流 `E_t = exp^[t]` 诱导的实/复流、运算路径、
> 复合方程和迭代常数的结构。

它的基本对象是五元组:

```
(S, A, E, +_t, V)
```

其中:

- `S = sexp` 是 Kneser 超指数;
- `A = slog` 是 Abel 坐标;
- `E_t = S(A + t)` 是连续迭代流;
- `+_t` 是由 `E_t` 共轭加法得到的运算路径;
- `V = S' o A` 是流的无穷小生成元。

基本问题是:

> 当指数迭代被直线化后,再拉回通常实数/复数坐标,会产生哪些可证明、
> 可计算、可分类的新结构?

这个问题足够谦虚,因为它承认 Kneser 定理在前;也足够大,因为它同时通向
运算分类、复动力系统、无限维方程、超越数和计算实验。

---

## 10. 当前仓库的角色

本仓库已经能承担三件事:

1. **计算器:** 提供 `half_exp`、`sexp`、`slog`、`exp_iter`。
2. **证据机:** 用测试和 demo 验证函数方程、群律、参考值和失败模式。
3. **问题发生器:** 把少年直觉翻译成可计算、可反驳、可引用的问题。

因此下一步最自然的建设不是立刻追求大定理,而是把它做成一个小型实验室:

- `docs/` 写清定义和开放问题;
- `docs/demo_*.py` 生成复现实验;
- `tests/` 锁住所有数学恒等式和数值参考值;
- `README.md` 给外部读者一条进入路线。

如果这条路成立,它的标志不是一句"我们发明了新数学",而是更朴素的东西:

> 别人拿到这个仓库后,可以复现数值、看见结构、提出问题,并且知道哪些地方
> 已被旧定理封住,哪些地方仍然真正开放。
