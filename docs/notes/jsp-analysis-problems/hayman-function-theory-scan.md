# Hayman《Research Problems in Function Theory》超运算相关性核查

抓取日期：2026-09-18
文本来源：Hayman & Lingham, *Research Problems in Function Theory*（50 周年版，含 1967 原版与 1974「new problems」的全部条目及 Update），arXiv:1809.07200，`pdftotext -layout` 转出 13048 行。
起因：孙宇晨奖题库里「整函数增长」一簇（见 [jsp-entire-function-growth.md](jsp-entire-function-growth.md)）五条的文献栏都指向 `[Ha74] Research problems in function theory: new problems`，所以直接查源头问题集。

## 结论

**没有超运算 / 分数次迭代相关问题。** 检索词：tetration、hyperoperation、fractional iteration、continuous iteration、iterative root、Abel (functional) equation、Schröder equation、embedding into a flow、iteration semigroup、Kneser、e^e、tower of exponentials。全部零命中（"Kneser" 唯一命中是 7826 行的 Kneser–Rado–Choquet 定理，位势论，与 H. Kneser 的超指数无关；"functional equation" 的三次命中都是 f^n+g^n=h^n 型的 Fermat 函数方程）。

即：**整数次迭代的复动力系统在这本问题集里是重头戏，但实/复解析的分数次迭代一条都没有。**

## 对孙宇晨奖题库的意义

题库对 `Julia`、`Fatou`、`Mandelbrot`、`wandering domain`、`Siegel`、`Herman ring` 的检索**全部零命中**（1022 条逐文件 grep）。也就是说：策展方从 Hayman 问题集里只挑走了增长阶/值分布那几条（JSP-000926/927/928/929/930），**整个复动力系统章节被跳过了**。

这说明题库的取舍不是"按问题集整本搬"，而是逐条挑选，且明显偏向陈述能写成一句话、可判定、能对上 Lean 形式化的类型。迭代/动力系统这种需要大量前置结构（Fatou 集、正规族、共形测度）的方向被系统性排除——这对把超运算方向推进题库是个不利信号，比"题库里恰好没有"更强：同一源头里更成熟、更经典的迭代问题都没被收。
